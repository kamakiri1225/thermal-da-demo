## 記事構成

### リード文（H1下）
```
「モデルの計算値と現実の観測値、どちらを信じればよいのか？」

この問いに答えるのが**データ同化**という技術です。
気象予報の精度向上、海洋モデルのキャリブレーション、
工業シミュレーションのリアルタイム補正まで——
データ同化は「計算」と「観測」の橋渡しをする数学的フレームワークです。
```

### H2-1：データ同化が必要な理由
**キーワード**：データ同化 必要性, シミュレーション 誤差

**内容**
- モデルには初期値誤差・境界条件誤差・物理モデル誤差がある
- 観測には空間的疎さ・センサーノイズがある
- 両者を「最良推定」に統合するのがデータ同化

**アナロジー**：カーナビの例
```
GPS（観測）だけでは誤差がある
地図＋走行モデル（シミュレーション）だけでは実際の渋滞を知らない
→ 両方を統合して「今の自分の位置」を最良推定する = データ同化
```

### H2-2：データ同化の数学的フレームワーク

**キーワード**：データ同化 数式, 状態ベクトル, ベイズ推定

#### H3：ベイズ推定としてのデータ同化

ベイズの定理：
$$p(\mathbf{x}|\mathbf{y}) \propto p(\mathbf{y}|\mathbf{x}) \cdot p(\mathbf{x})$$

| 項 | データ同化での対応 | 意味 |
|---|---|---|
| $p(\mathbf{x})$ | 背景場の確率分布 | モデル予測の不確かさ |
| $p(\mathbf{y}\|\mathbf{x})$ | 観測の尤度 | 観測誤差の評価 |
| $p(\mathbf{x}\|\mathbf{y})$ | 解析場の確率分布 | 融合後の最良推定 |

#### H3：基本的な変数定義

| 記号 | 名称 | 説明 |
|---|---|---|
| $\mathbf{x} \in \mathbb{R}^n$ | 状態ベクトル | モデルの全グリッド点の物理量 |
| $\mathbf{y} \in \mathbb{R}^m$ | 観測ベクトル | センサーで得られた観測値 |
| $H : \mathbb{R}^n \to \mathbb{R}^m$ | 観測演算子 | モデル空間→観測空間への写像 |
| $\mathbf{B} \in \mathbb{R}^{n\times n}$ | 背景誤差共分散 | モデル予測の誤差の空間構造 |
| $\mathbf{R} \in \mathbb{R}^{m\times m}$ | 観測誤差共分散 | センサー誤差の大きさ |

### H2-4：データ同化手法のロードマップ

**キーワード**：データ同化 種類, OI法, カルマンフィルタ, EnKF, 粒子フィルタ, 4D-Var

```
データ同化手法
│
├─ 逐次型（Sequential）
│   │
│   ├─ 線形・厳密解
│   │   ├─ OI（最適補間法）            → 静的・線形・シンプル           [記事01]
│   │   └─ KF（カルマンフィルタ）      → 動的・線形・厳密解             [記事02]
│   │
│   ├─ 弱非線形（ヤコビアン線形化）
│   │   └─ EKF（拡張カルマンフィルタ） → 動的・弱非線形                 [記事02補足]
│   │
│   ├─ 非線形・アンサンブル系
│   │   ├─ EnKF（Stochastic）         → 動的・非線形・観測摂動あり      [記事03]
│   │   ├─ ETKF / LETKF              → 安定化・局所化・大規模対応      [記事04]
│   │   └─ IEnKF                     → 強非線形・反復更新              [記事04補足]
│   │
│   └─ 非線形・非ガウス
│       └─ 粒子フィルタ（PF）         → 分布の仮定なし・完全非線形      [記事05]
│
└─ 変分型（Variational）
    ├─ 3D-Var                         → 静的・コスト関数最小化          [記事06]
    ├─ 4D-Var                         → 動的・随伴法                    [記事06]
    └─ En-4DVar（ハイブリッド）        → アンサンブル×変分・現在主流    [記事06補足]
```

> このシリーズでは **OI → KF → EnKF → ETKF/LETKF → 粒子フィルタ → 3D/4D-Var** の順に解説します。

### FAQ セクション

```
Q1: データ同化と機械学習の違いは何ですか？
A: データ同化は物理モデルの方程式を明示的に使い、
   誤差の統計的構造（共分散）をモデル化します。
   機械学習はデータから関係式を学習しますが、
   物理制約を自動では満たしません。
   近年は両者を組み合わせた研究も増えています。

Q2: データ同化はどんなソフトウェアで使えますか？
A: DART（NCAが開発）、OpenDA、PDAF などのオープンソースフレームワークがあります。
   OpenFOAMと組み合わせた研究も進んでいます。

Q3: データ同化を学ぶのに必要な前提知識は？
A: 線形代数（行列演算）と基礎的な確率・統計（正規分布、条件付き確率）が
   あれば十分です。偏微分方程式の知識があるとより深く理解できます。

Q4: EnKF・粒子フィルタ・4D-Varはどう使い分けるのですか？
A: EnKF/LETKFはガウス近似のもとで高次元問題に対応します（気象・海洋で標準的）。
   粒子フィルタはガウス性を仮定しない完全非線形ですが、高次元が苦手です。
   4D-Varは随伴モデルが必要ですが時間窓内の全観測を使えます。
   現在のトレンドはEnKFと4D-Varを組み合わせたハイブリッド（En-4DVar）です。
```
