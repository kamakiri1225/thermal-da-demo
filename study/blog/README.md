# データ同化ブログ シリーズ計画

## シリーズコンセプト

**テーマ**：数値シミュレーション × 観測データ融合の技術「データ同化」を、数式・図・Pythonコードで理論と実践の両面から体系的に解説する。

**ターゲット読者**
- 数値シミュレーション（CFD・気象・海洋）に携わるエンジニア・研究者
- 機械学習は知っているがデータ同化を知らない人
- カルマンフィルタ・EnKF・粒子フィルタを実務で使いたい人

## データ同化手法の全体マップ

```
データ同化手法
│
├─ 逐次型（Sequential）
│   │
│   ├─ 線形・厳密解
│   │   ├─ OI（最適補間法）            → 静的・線形・シンプル         [記事01]
│   │   └─ KF（カルマンフィルタ）      → 動的・線形・厳密解           [記事02]
│   │
│   ├─ 弱非線形（ヤコビアン線形化）
│   │   └─ EKF（拡張カルマンフィルタ） → 動的・弱非線形               [記事02補足]
│   │
│   ├─ 非線形・アンサンブル系
│   │   ├─ EnKF（Stochastic）         → 動的・非線形・観測摂動あり    [記事03]
│   │   ├─ ETKF / LETKF              → 行列変換・局所化・大規模向け  [記事04]
│   │   └─ IEnKF                     → 強非線形・反復更新            [記事04補足]
│   │
│   └─ 非線形・非ガウス
│       └─ 粒子フィルタ（PF）         → 仮定なし・完全非線形          [記事05]
│
└─ 変分型（Variational）
    ├─ 3D-Var                         → 静的・コスト関数最小化        [記事06]
    ├─ 4D-Var                         → 動的・随伴法                  [記事06]
    └─ En-4DVar（ハイブリッド）        → アンサンブル×変分            [記事06補足]
```

## シリーズの流れ（記事間の接続）

```
[記事00] データ同化の全体像・動機・手法マップ
        ↓ 「最もシンプルな手法から」
[記事01] OI法：静的・線形・解析解あり
        ↓ 「時間発展を加える」
[記事02] KF：動的・線形・誤差共分散が自動更新
        ↓ 「高次元・非線形に対応する」
[記事03] EnKF（Stochastic）：アンサンブルで共分散を近似
        ↓ 「観測摂動をなくしてより安定に」
[記事04] ETKF/LETKF：行列変換で安定化、局所化で大規模対応
        ↓ 「ガウス分布の仮定を外す」
[記事05] 粒子フィルタ：重み付きサンプルで任意分布に対応
        ↓ 「逐次型とは異なるアプローチ」
[記事06] 3D-Var / 4D-Var：コスト関数最小化による変分型
```

## 手法比較表（シリーズ通じて参照）

| 手法 | 時間発展 | 非線形 | 非ガウス | 計算コスト | 大規模対応 |
|---|---|---|---|---|---|
| OI | なし | 不可 | 不可 | 低 | △ |
| KF | あり | 不可 | 不可 | $O(n^3)$ | ✗ |
| EKF | あり | 弱非線形 | 不可 | $O(n^3)$ | ✗ |
| EnKF | あり | 可 | 近似的 | $O(Nn)$ | △ |
| ETKF/LETKF | あり | 可 | 近似的 | $O(Nn)$ | ○ |
| 粒子フィルタ | あり | 可 | 可 | $O(Nn)$〜高 | ✗（次元の呪い） |
| 3D-Var | なし | 可 | 不可 | 中 | ○ |
| 4D-Var | あり | 可 | 不可 | 高（随伴法） | ○ |

## 共通執筆ルール

### 構成テンプレート
1. **リード文**（150字以内）：記事で解決できる読者の悩みを明示
2. **この記事でわかること**（3点箇条書き）
3. **本文**：H2 → H3 で階層化、1セクション300〜600字
4. **数式ブロック**：記号の意味 → 式 → 直感的解釈の順
5. **Pythonコード**：コピペで動く完全コード、出力グラフあり
6. **手法比較**：前後の手法と何が違うかを表で整理
7. **まとめ**：次の記事への誘導
8. **FAQ**（3〜5問）：検索意図に直接答える

### 文章スタイル（参考記事から）
- **「数学が苦手な人でも読める」を前提に書く**：途中計算を省略しない、式変形を1ステップずつ示す
- **機械学習との対比**で概念を説明する（読者の既存知識に橋渡し）
- **期待値・分散などの統計量は記号を導入する前に言葉で説明する**
- 読者に「自分で手を動かして確かめてほしい」という姿勢で書く
- 正直に「ここは難しい」「自分も最初はわからなかった」と書いてよい（親近感）
- 変数名は数式記号と対応させる（例：`var_o`, `x_a`）

### SEO・AI検索対策
- タイトルにメインキーワードを含める（前半に置く）
- H2見出しに関連キーワードを自然に含める
- 冒頭200字以内にメインキーワードを配置
- 数式・コードを使い「一次情報」としての権威性を高める
- FAQ セクションで質問形式のクエリに対応（AIの引用元になりやすい）
- 内部リンクでシリーズ記事を相互接続

### Pythonコード方針
- 依存ライブラリ：`numpy`, `matplotlib` のみ（原則）
- 変数名は数式記号と一致させる（`var_b` = $\sigma_b^2$、`x_a` = $\mathbf{x}^a$ など）
- 理論値と数値実験の結果を**同じグラフで比較**して理論を「体感」させる
- コードは各記事フォルダの `python/` サブフォルダに保存（後でGitHubリポジトリと合流）
- 関数化して再利用しやすくする

### SEOキーワード戦略（シリーズ全体）

| カテゴリ | メインキーワード | 関連キーワード |
