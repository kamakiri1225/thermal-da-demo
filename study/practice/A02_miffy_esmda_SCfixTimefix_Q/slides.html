A02_miffy_esmda_SCfixTimefix_Q

ESMDA 入門
ミッフィー熱源同定でわかるアンサンブルスムーザー

目的

形状を知らない状態から、固定温度センサの観測だけで温度場と熱源場を復元する（静的逆問題のデータ同化）。

やったこと

ESMDA で温度場を復元 → さらに状態変数を熱源 q に変えて L⁻¹ 順問題を組み込んだ完全逆問題へ拡張。

結論

固定センサ×静的場では ESMDA が最も安定・実用的。EnKF は発散、OI は 1 回更新の特殊ケース。

完全逆問題版 ESMDA — 上段: 推定熱源からの温度場 / 下段: 推定熱源場（反復とともにミッフィーが現れる）

01 — Problem Setup

目的: センサ温度だけで「見えない場」を当てる

ツイン実験 — 正解（ミッフィー温度場）を自分で作り、そこから センサ観測を合成して、逆推定がどこまで正解に迫れるかを測る枠組み。 実務前の手法検証の定番。
  • 格子: 30×30 = 900 セル（未知数 900 個）
  • 観測: 固定温度センサ m = 30〜400 点 + ノイズ σr = 3 °C
  • 初期推定: 全セル 20 °C 一様 — ミッフィー形状の事前知識はゼロ
  • センサ配置も真値を見ずに決める（格子座標だけの空間充填配置）
本質的な難しさ: 900 未知数 > 観測数。問題は劣決定で、 「観測に合う場」は無数にある。事前分布（滑らかさの仮定）で残りを埋めるのが データ同化の役割。

固定センサ配置（色 = センサ数 m のケース別）。背景がミッフィー温度場の正解。

02 — What We Did

ステップ 1: 温度場を ESMDA で復元（うまくいった）

  • 状態変数 = 温度場 x（900 セル）
  • 観測演算子 H = センサ位置の抜き出しだけ
  • N = 300 メンバー、30 反復
結果: m=300 で RMSE 19.8 °C。 一様 20 °C から始めてミッフィーの輪郭・服・目がはっきり復元。 センサ数 10〜400 のスイープで必要点数も定量化 （概形 75 点 / 実用 150 点 / 高精度 300 点）。

最終推定温度場（m = 30 / 100 / 200 / 300）。緑 + がセンサ。

02 — What We Did

しかし熱源場の「後付け逆算」は失敗

推定温度場から熱源を逆算すると…

\( \mathbf{q}_{\text{derived}} = -\alpha \, \mathbf{L}\, \bar{\mathbf{x}} \)
ノイズ増幅 — ラプラシアン L は差分オペレータ。 推定温度場に残るセルスケールの誤差を微分して強烈に増幅する。 結果はノイズが支配的で、熱源図として読めない。

これが「うまくいっていなかった部分」。 HANDOFF に残されていた次課題 =「状態変数を Q にして順問題を組み込む」へ。

後付け逆算した熱源場。ノイズだらけでミッフィーは読み取れない。

02 — What We Did

ステップ 2: 完全逆問題 — 状態変数を熱源 q に

STEP 1
熱源アンサンブル qi
0 中心の滑らかなランダム場 × 300 本（形状知識なし）
→
STEP 2
順問題を解く
x(q) = L⁻¹(−q/α)。各メンバーの温度場を計算
→
STEP 3
センサ温度と比較
予測センサ温度と観測の差（イノベーション）
→
STEP 4
q を ESMDA 更新
×30 反復。温度は見るだけ、直す対象は熱源
ポイント: 観測されるのは温度、推定したいのは熱源。 両者を順モデル（物理）がつなぐ。「観測と推定対象が別物」なのが完全逆問題で、 パラメータ推定・履歴マッチングと同じ構図。
\( \mathbf{y} = \mathcal{H}(\mathbf{q}) + \boldsymbol{\varepsilon} = \left[\mathbf{L}^{-1}(-\mathbf{q}/\alpha)\right]_{\text{sensors}} + \boldsymbol{\varepsilon} \)

実装は python/esmda_qfull.py。L は一度だけ LU 分解し、毎反復は後退代入のみ（1 ラン数秒）。

03 — What is ESMDA?

ESMDA とは — 一言でいうと

ESMDA (Ensemble Smoother with Multiple Data Assimilation)
= 同じ観測を「弱め」に「何回も」同化するアンサンブル法 （Emerick & Reynolds 2013、油層の履歴マッチングが出自）

1 回で強く引っ張ると（EnKF 的更新）

  • 観測誤差 R をそのまま使い、観測に一気に寄せる
  • 1 ステップの更新量が大きい → アンサンブルが潰れる・発散する
  • 非線形な順モデルでは線形化誤差が一度に効く

ESMDA は分割払い

  • 観測誤差を Na 倍に膨らませて（R → NaR）弱い更新にする
  • その代わり Na 回繰り返す
  • 毎回、順モデルを解き直してから更新 → 非線形でも壊れにくい
理論保証: 線形・ガウスの場合、「R を Na 倍にして Na 回更新」は 「R のままの 1 回更新（ベイズ更新そのもの）」と同一の事後分布になる。 分割しても答えは変わらず、安定性だけが手に入る。
03 — What is ESMDA?

理論: 更新式

アンサンブル \( \{\mathbf{q}_i\}_{i=1}^{N} \) と膨張係数 \( \alpha_k \)（ここでは全反復一定 \( \alpha_k = N_a \)、\( \sum_k 1/\alpha_k = 1 \)）に対し、反復 k で:

\[ \mathbf{q}_i \leftarrow \mathbf{q}_i + \mathbf{K}_k\left(\mathbf{y} + \boldsymbol{\varepsilon}_i - \mathcal{H}(\mathbf{q}_i)\right), \qquad \boldsymbol{\varepsilon}_i \sim \mathcal{N}(\mathbf{0}, \alpha_k \mathbf{R}) \] \[ \mathbf{K}_k = \mathbf{C}^{qy}\left(\mathbf{C}^{yy} + \alpha_k \mathbf{R}\right)^{-1} \]
  • \( \mathbf{C}^{qy} \): 状態とセンサ予測値のアンサンブル共分散（q の偏差 × 予測温度の偏差から推定）
  • \( \mathbf{C}^{yy} \): センサ予測値どうしのアンサンブル共分散
  • \( \boldsymbol{\varepsilon}_i \): 摂動観測。メンバーごとに観測へノイズを足し、事後分散が過小にならないようにする（確率的 EnKF と同じ工夫）
  • 随伴コード（アジョイント）も接線形モデルも不要 — 順モデルを N 回呼べれば動く
共分散局所化: サンプル数 N が有限なので、遠く離れたセル・センサ間には偽の相関が乗る。 距離に応じたテーパー \( \rho \)（ガウス関数）をゲインに掛けて偽相関を殺す: \( \mathbf{K} \to \mathbf{K} \circ \rho \)。ただし半径の選び方に落とし穴がある（後述）。
03 — What is ESMDA?

「スムーザー」と「フィルタ」の違い

フィルタ（KF / EnKF）

  • 時間を前に進めながら、観測が来るたびに状態を逐次修正
  • リアルタイム追跡・予報が目的
  • 過去の観測は「現在の状態」に集約済み

スムーザー（ES / ESMDA）

  • 観測を全部まとめて一括で使い、静的な場やパラメータを推定
  • 時間発展の追跡はしない（今回の定常熱伝導にぴったり）
  • 「一括」を安定にするための反復版が ESMDA
今回の問題は「定常温度場を作る熱源はどれか」という静的な逆問題。 時間発展がないのでフィルタの逐次性は不要 — スムーザー系が自然な選択。

実際、このリポジトリでは EnKF を固定センサに使ったケース （A02_miffy_enkf_SCrandomTimefix_T）が発散している。同じ観測を毎サイクル使い続けると 誤差共分散が現実とずれていき、インフレーション調整が暴走した。ESMDA は设计上この問題が起きない。

05 — When to Use

ESMDA はどういう場合に使えるか

向いている問題

  • 静的な逆問題・パラメータ推定
    熱源・透水係数・材料定数・境界条件の同定。油層の履歴マッチングが出自
  • 順モデルがブラックボックス
    OpenFOAM / FrontISTR など商用・既存ソルバーをそのまま使える（随伴コード不要）
  • 順モデルが高コストでも並列可能
    N メンバーは完全に独立 → クラスタで同時実行
  • 穏やかな非線形
    反復のたびに順モデルを解き直すので、1 回線形化の EnKF 更新より頑健

向いていない問題

  • リアルタイムの逐次追跡
    時々刻々の状態推定・予報はフィルタ（EnKF/KF）の領分
  • 強い非ガウス・マルチモーダル
    更新式がガウス前提。粒子フィルタ等の領分
  • 不連続・エッジの復元
    ガウス事前分布は滑らかな場しか表現できない（今回の教訓でも実証）
  • 順モデル呼び出しが N×Na 回も許されない
    その場合は決定論的 ES 1 回 or 随伴法（4DVar）を検討

06 — Math ↔ Code

数式とコードの対応 (1/2): 順モデルと事前アンサンブル

数式esmda_qfull.py補足
\( \mathbf{q}_{\text{true}} = -\alpha \mathbf{L} \mathbf{x}_{\text{truth}} \) q_true = -ALPHA * (L @ x_ss) ツイン実験の正解熱源（輪郭線状のエッジ場）
\( \mathbf{x}(\mathbf{q}) = \mathbf{L}^{-1}(-\mathbf{q}/\alpha) \) LU = spl.splu(L.tocsc())
def forward_x(Q):
  return LU.solve(-Q / ALPHA)		 LU 分解は 1 回だけ。(900×300) をまとめて後退代入
\( \mathbf{q}_i \sim \) 平滑ガウス場, \( \sigma = \) SIGMA_QB noise = rng.normal(0, 1, (NY, NX))
Q[:, i] = gaussian_filter(noise, sigma=CORR_L).ravel()
Q *= SIGMA_QB / Q.std()		 形状知識ゼロの事前分布。CORR_L が滑らかさ、SIGMA_QB が振幅
局所化 \( \rho_{ij} = \exp\!\left(-\tfrac{d_{ij}^2}{2 R_{\text{loc}}^2}\right) \) rho = np.exp(-0.5*(dy**2 + dx**2)/R_LOC**2) セル i とセンサ j の距離テーパー (900×m)
読み方のコツ: 行列式のまま numpy に写している。 アンサンブルは列方向に並べた行列 Q (n × N) なので、 「全メンバーの順問題」= 1 回の行列ソルブになり、for ループが消える。
06 — Math ↔ Code

数式とコードの対応 (2/2): ESMDA 更新ループ


SIGMA_R_EFF = SIGMA_R * np.sqrt(N_ITER)          # α_k R の平方根: R を N_a 倍に膨張

for it in range(1, N_ITER+1):
    X_temp = forward_x(Q)                        # 順問題: 全メンバーの温度場 H(q_i)
    Qp  = Q - Q.mean(axis=1, keepdims=True)      # 状態の偏差 (n × N)
    Tp  = X_temp - X_temp.mean(axis=1, keepdims=True)
    HTp = Tp[obs_idx, :]                         # センサ位置の温度偏差 (m × N)

    S   = (HTp @ HTp.T)/(N_ENS-1) \
          + SIGMA_R_EFF**2 * np.eye(m_obs)       # C^yy + α_k R
    PHt = (Qp @ HTp.T)/(N_ENS-1)                 # C^qy
    K   = np.linalg.solve(S.T, PHt.T).T          # K = C^qy (C^yy + α_k R)^-1

    eps = rng.normal(0.0, SIGMA_R_EFF, (m_obs, N_ENS))   # 摂動観測 ε_i
    innovation = x_ss[obs_idx, None] + eps - X_temp[obs_idx, :]
    Q += (K * rho) @ innovation                  # 局所化ゲインで q を更新
  • SIGMA_R_EFF² = N_ITER × σ_r² が「膨張した観測誤差 αkR」。これで 30 回更新 = 膨張なし 1 回更新と同じ事後分布（線形ガウス時）
  • np.linalg.solve(S.T, PHt.T).T — 逆行列を作らず連立方程式で解く定石
  • 温度状態版 enkf_heatid.py との違いは X_temp = forward_x(Q) の 1 行だけ。更新式は完全に共通
07 — Results

結果 1: 収束 — 安定・速い

左: 熱源 RMSE / 右: 温度 RMSE。実質 5 反復で収束し、その後も発散しない。点線は旧方式（後付け逆算）の水準。

温度 RMSE は m=300 で 20.1 °C — 温度場を直接同化した場合（19.8 °C）と同等。 「熱源を推定して温度を説明する」遠回りをしても、温度の説明能力は失われない。
07 — Results

結果 2: 熱源場 — 復元できるスケールには限界がある

左から: 正解（エッジ場）/ 正解を σ=1 で平滑化 / Q-state ESMDA / 旧方式（後付け逆算）。各パネル独自スケール。

限界: 正解の熱源はセル幅の「輪郭線」。順問題 L⁻¹ の平滑化作用で 高周波情報は温度に残らず、点温度観測からエッジは原理的に復元不可 （q RMSE は 38.8 で飽和、正解の std は 40.0）。N や反復を増やしても改善しない。
成果: 平滑化スケールなら相関 0.76（m=300）で復元。 目・鼻・輪郭が視認できる。旧方式は同じ情報を持つ（相関 0.73）が 増幅ノイズに埋もれて読めない — 差は情報量ではなく可読性。

結果 3: センサ数スイープ

センサ数 10〜400 点 × 3 シード。左: 熱源 RMSE / 右: 温度 RMSE。

07 — Results

教訓: 局所化半径の落とし穴（開発中に踏んだ）

R_LOC = 5（温度状態と同じ値）のまま使うと…

  • 反復 4〜7 で温度 RMSE が 最大 5000 °C 超へ暴走してから収束
  • センサが少ない（m=30〜50）と最終値でも同化しない場合より悪化（62 °C > 38 °C）

R_LOC = 10 に広げると…

  • 過渡暴走が完全に消滅（単調収束）
  • 少数センサでの悪化も解消、最終精度は同等以上
なぜか: 局所化はセンサ近傍の熱源だけを更新するが、更新された熱源は L⁻¹ を通じて遠方の温度まで変えてしまう。半径が狭いとこの遠隔効果が 観測で拘束されず、センサ空白域の温度場が崩れる。
一般則: 順モデルが非局所な逆問題では、局所化半径は 「観測が状態に効く物理的到達距離」に合わせて広げること。
Summary

まとめ

ESMDA とは

観測誤差を Na 倍に膨らませて同じ観測を Na 回同化するアンサンブルスムーザー。 線形ガウスなら 1 回のベイズ更新と同一の答えを、はるかに安定に得る。 随伴不要・順モデル差し替え自由・並列容易。

今回の成果

固定センサ温度だけからミッフィー温度場を復元（19.8 °C）。 状態変数を熱源に変えた完全逆問題でも同等の温度精度を保ち、 平滑化スケールの熱源構造（相関 0.76）を直接読める形で取得。

使い分けの指針

逐次追跡 → KF/EnKF ／ 一発の静的解析 → OI ／ 静的逆問題・パラメータ同定 → ESMDA。 パラメータは σr 以外すべて設計変数: 物理スケールで置き、スイープで境界を見る。
