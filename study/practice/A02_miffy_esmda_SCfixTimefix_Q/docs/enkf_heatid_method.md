## 1. このデモで何をするか

ミッフィーちゃんの温度場（= 正解）はわかっている。  
しかし**その温度を生み出している熱量分布 q** は未知。

> 「スパースな固定位置センサの温度観測だけから、**何らかの方法で** EnKF によりミッフィーの温度場を復元できるか？　そのとき q はどんな分布になるか？」

代表比較条件： m = [30, 100, 200, 300] 固定センサ

---

## 2. 支配方程式と「真の q」

### 定常拡散方程式

$$\alpha \mathbf{L} \mathbf{x} + \mathbf{q} = \mathbf{0}$$

- **x** (n=900)：温度場
- **q** (n=900)：熱源場（q>0 = 発熱、q<0 = 吸熱）
- **L**：5 点差分ラプラシアン行列（30×30）
- α = 0.5：熱拡散係数

「真の q」を x_ss（ミッフィーの温度場）から逆算：

$$\mathbf{q}_{\text{true}} = -\alpha \mathbf{L} \mathbf{x}_{ss}$$

---

## 3. q_true の分布：「なぜ内部が白い（= 0）のか」

ラプラシアン L は「周囲との温度差の総和」を計算します。

```
【ミッフィー内部の均一領域 (例: T = 100°C 全方向)】
  L @ x[i] = -4·100 + 100 + 100 + 100 + 100 = 0
  q_true[i] = -α·0 = 0  ← 白（熱源不要）

【ミッフィー高温側の境界セル (T=100、隣に T=0)】
  L @ x[i] = -4·100 + 100 + 100 + 0 + 100 = -200
  q_true[i] = -α·(-200) = +100  ← 赤（熱源）

【ミッフィー外側の背景境界セル (T=0、隣に T=100)】
  L @ x[i] = -4·0 + 0 + 100 + 0 + 0 = +100
  q_true[i] = -α·100 = -50  ← 青（熱吸収）
```

**結論：** 定常状態では、温度が均一な領域に熱源は不要です。  
熱源/吸熱は、温度が急変する「境界」に集中します。  
→ ミッフィーの q_true はパリッとした輪郭型（内部≈0、輪郭上に ±）

これは物理的に正しい分布です。  
「ミッフィーの内部に熱源がある」という直感とは異なりますが、  
「その温度分布を定常状態で維持するために必要な q」はこの形になります。

## 4. 問題設定の候補と試行錯誤

今回のセッションで検討・試行した 3 つの設定を記録します。

---

### 設定 A：q をミッフィーマスク内に限定（試行 → 失敗）

```
状態変数: q_mask (~566 セル, mask = x_ss > 0)
前進モデル: x_pred = -(1/α) Ψ q_mask
            Ψ = L^{-1}[:,mask_idx] を事前計算
観測: y = x_ss[固定センサ] + noise
```

#### 失敗の原因：前進モデルの不整合（モデル誤差 556°C）

`q_mask` のみ（背景 q = 0）でフォワード計算すると：

```
x_pred = -(1/α) L^{-1} q_mask

背景セル（T=0）の隣に q_mask > 0 のミッフィーセルがある場合:
  → 熱がミッフィー外部に自由拡散
  → 背景に必要な「熱吸収（q < 0）」が欠落
  → x_pred は x_ss（ミッフィー）と大きく異なる
  → max|x_pred(q_true_mask) - x_ss| = 556°C !!
```

DA はこの 556°C の「モデル誤差」を観測で修正しようとしますが、  
修正量が大きすぎてカルマンゲインが暴走 → **アンサンブル発散**。

```
実行結果:
  m= 1 -> xRMSE = 735°C
  m= 5 -> xRMSE = 42,148°C  ← 完全発散
  m=30 -> xRMSE = 299°C
  m=50 -> xRMSE = 161°C
```

---

### 設定 B：q を全セル（発熱/吸熱両方許容）（試行 → 成功）

```
状態変数: q_full (全 900 セル)
事前分布: q ~ N(0, σ²)
  ミッフィー内部: σ_miffy = 80  (大きな不確実性：熱源の可能性大)
  背景セル:       σ_bg    = 20  (小さな不確実性：中立近傍)
前進モデル: x_pred = -(1/α) spsolve(L, q_full)
           spsolve の毎ステップ呼び出し
観測: y = x_ss[ランダムセンサ m=30/cycle] + noise
```

#### 成功の理由

「背景セルの q < 0」も状態変数に含まれるため、  
フォワードモデルが x_ss を完全再現できる（誤差 = 5.4×10⁻¹³）。

```
実行結果 (N_CYC=100, m=30/cycle ランダム):
  初期 x_RMSE: 263°C
  Cycle  10:   25°C
  Cycle  50:   21°C
  Cycle 100:   20°C ← 安定収束
  q_RMSE:      39°C
```

GIF に 4 パネル（x_pred+センサ、q推定、x_true、q_true）を表示。

#### 問題点

センサが毎サイクル「ランダム」に移動するため、  
ユーザーから「センサ位置が動いている」と指摘 → 固定センサに変更要求。

---

### 旧設定 C：状態変数 = x、物理情報付き事前分布（廃止）

設定 A/B の問題を回避しながら「q がミッフィー内部」という知識を活かす方針：

```
状態変数: x (温度場, 900 次元) ← q ではなく x を直接推定
前進: なし（静的真値、Case 1 と同じ）
初期アンサンブル: 物理情報付き事前分布
  1. q_mask ~ N(0, σ²) をランダムサンプリング
  2. x = -(1/α) Ψ q_mask で前進解を計算
  3. x の標準偏差が SIGMA_B = 30°C になるようスケール調整
観測: y = x_ss[固定センサ] + noise
DA: 標準 EnKF（Case 1 と同じ、局所インフレーション）
q の可視化: q_derived = -α·L·x_mean（x から逆算、表示のみ）
```

#### 現時点の課題

スケール較正後も m=5 で発散が残る場合があります。  
原因：物理情報付き事前分布が作る共分散構造が、  
特定のセンサ配置と組み合わさると Kalman ゲインが大きくなりすぎる可能性。

```
実行結果（較正後）:
  m= 1 -> xRMSE = ~87°C
  m= 5 -> xRMSE = ~464°C  ← まだ不安定
  m=30 -> xRMSE = ~129°C
  m=50 -> （実行中）
```

## 6. 「全体に発熱と吸熱を許す」問題設定の物理的意味

設定 B（全セル q）は**物理的に最も自然**な設定です。

```
現実の熱伝導問題では：
  ・ヒーター（電気抵抗など）= q > 0  （発熱）
  ・冷却フィン（空気冷却など）= q < 0 （吸熱）
  ・断熱領域 = q ≈ 0

ミッフィーの定常温度場を「維持」するためには：
  ・輪郭の高温側（ミッフィー本体の境界）= ヒーター
  ・輪郭の低温側（背景との境界）= クーラー
  ・均一領域の内部 = 何もしなくてよい（q ≈ 0）
```

これは「ミッフィーの形のヒーター/クーラーシステム」を設計するような問題です。  
全セルに q を許容し、その分布をデータ同化で推定する設定 B が最も現実的です。

## 7. 設定 A の根本的な矛盾を別の角度から理解する

### 「関数の空間」の問題

前進モデル `x_pred = -(1/α) Ψ q_mask` が作れる x の集合は：

$$\mathcal{X}_A = \left\{ -(1/\alpha)\mathbf{\Psi}\mathbf{q} \mid \mathbf{q} \in \mathbb{R}^{n_q} \right\}$$

これは n=900 次元空間の中の **n_q=566 次元部分空間** です。  
x_ss（ミッフィー温度場）はこの部分空間に**属していません**（外にある）。

DA が行うのは「この部分空間内で観測に最も近い点を探す」ことですが、  
観測（y = x_ss[sensors]）は部分空間外の点から来ているため、  
収束先が不安定になります。

### 対比：設定 B（全セル q）の場合

$$\mathcal{X}_B = \left\{ -(1/\alpha)\mathbf{L}^{-1}\mathbf{q} \mid \mathbf{q} \in \mathbb{R}^{n=900} \right\}$$

L が非特異なので $\mathcal{X}_B = \mathbb{R}^{900}$（全空間）。  
x_ss は必ずこの空間に属する。→ モデル誤差ゼロ。

## 9. 現行方針と次の改善

現行コードは、ミッフィー形状を含まない一様事前分布から固定センサ温度を
ESMDAで同化する問題に変更済みです：

```python
状態変数: x (900次元)
初期平均: 全セル20 degC
事前分布: 形状非依存の等方的ガウス確率場
初期アンサンブル: ガウス平滑化した形状非依存ランダム場
センサ:   固定 m=[30,100,200,300]、格子座標だけで空間充填配置
同化:     確率的ESMDA、N_ENS=300、N_ITER=30
局所化:   Gaussian、R_LOC=5 cells
```

センサ数スイープでは75点でRMSE 30 degC未満、150点で25 degC未満、
300点で20 degC未満になりました。300点から400点ではほぼ改善しないため、
それ以上はセンサ追加よりアンサンブル・相関・物理モデルの改善が必要です。
