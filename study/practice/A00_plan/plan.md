# OpenFOAM 2D データ同化デモ：おっさんのドット絵

## プロジェクト概要

2次元温度場（おっさんのドット絵）を「正解データ」とし、
ランダムな初期状態からデータ同化（EnKF）で正解に収束させるデモ。

```
ランダム初期場 → EnKFを繰り返す → おっさんの顔が浮かび上がる！
```

## フォルダ構成

```
命名規則: A0X_[対象]_[手法]_[同定量]
  A00: 計画・設計
  A01: 正解場の生成（DA なし）
  A02: DA デモ（手法・同定量の組み合わせ別サブフォルダ）

practice/A00_plan/              ← このファイル・手法選定
practice/A01_ossan/             ← 正解温度場（おっさん）
practice/A01_miffy/             ← 正解温度場（ミッフィー）
practice/A02_miffy_enkf_T/      ← DA: ミッフィー × EnKF+OI × 温度場 T（統計的DA）
practice/A02_miffy_enkf_Q/      ← DA: ミッフィー × EnKF × 発熱量 Q（物理DA①）
practice/A02_miffy_enkf_k/      ← DA: ミッフィー × EnKF × 熱伝導率 k（物理DA②）予定
practice/A02_miffy_enkf_h/      ← DA: ミッフィー × EnKF × 熱伝達率 h（物理DA③）予定
```

|----------|-----------|-----------------|
| 背景     | 0         | 空（冷たい）     |
| 肌       | 100       | 顔・首・耳      |
| 髪       | 30        | 頭部サイド      |
| 目       | 5         | 瞳              |
| 口ひげ   | 15        | 太いひげ        |

| ベルト   | 20        | ウエスト        |

## グリッド設計

- OpenFOAM 2D: NX=40, NY=60 (セル数)
- 物理サイズ: 40m × 60m (1 cell = 1m²)
- Z方向: 1セル（2D, empty境界条件）

## データ同化パラメータ（予定）

- アンサンブルサイズ: N=50〜100
- 観測点数: ~20点（グリッドのスパースサンプリング）
- 観測誤差: σ_r = 5.0
- サイクル数: 20〜50サイクル

## ゴール

ParaViewまたはPythonのアニメーションで
「おっさん・ミッフィーが浮かび上がるプロセス」を可視化する。

## デモを面白くする切り口（アイデア）

### 1. 観測数による比較
観測数 $m$ を変えてサイクルごとの RMSE を比較する。

| 観測数 | 期待される挙動 |
|--------|---------------|
| $m = 5$ | 収束が遅い・ぼんやりした再現 |
| $m = 20$ | 標準設定 |
| $m = 50$ | 速く収束・細部まで再現 |

→「観測が多いほど速く・正確に」を定量的に示せる。

### 2. 観測配置の工夫（観測設計）
- **完全ランダム**：観測点をグリッド全体にランダム配置
- **輪郭集中**：顔・耳の輪郭付近に集中配置

→ 同じ観測数でも配置次第で収束速度や精度が変わることを示す。
観測設計（Observation Design）の問題としてブログ記事にできる。

### 3. ローカライゼーション効果の可視化
- ローカライゼーション**なし** vs. **あり** の比較
- なし：遠距離の偽相関でノイズが乗る
- あり：局所的に正しく更新される

→ 「なぜローカライゼーションが必要か」を直感的に示せる。

### 4. RMSE 収束カーブ
各サイクル $k$ で RMSE を計算してプロット：

$$\text{RMSE}_k = \frac{1}{\sqrt{n}} \left\|\bar{\mathbf{x}}^a_k - \mathbf{x}^{\text{true}}\right\|_2$$

→ 何サイクルで収束するかが一目でわかる。

### 5. おっさん vs. ミッフィーの収束速度比較
- おっさん：温度コントラスト大（黒背景 T=0、シアンレンズ T=48、肌 T=100）
- ミッフィー：背景 T=0、白ファー T=100、ドレス T=55

→ コントラスト構造が異なる2つの画像で収束挙動を比較できる。

## 物理ベース DA の計画（A03〜A05）

A02 までは「正解の温度場 $T(x,y)$ を与えて、それをスパース観測から再構成する」  
統計的 DA だった。隣接セル間の相関はガウス関数で**人為的に**与えており、物理モデルは使っていない。

A03 以降は「**前向きモデル**（熱伝導方程式 FD ソルバー）を各アンサンブルメンバーで実行」し、  
**物理量（Q, k, h）をスパース温度観測から逆推定**する本格的な物理 DA を実装する。

### 前向きモデルの共通設定

```
グリッド: NX=40, NY=60  （A02 と同じ）
支配方程式: 2D 定常熱伝導
  ∇·(k∇T) + Q = 0

境界条件（共通）:
  上辺 (y=NY): T = 0°C  （Dirichlet, 冷却壁）
  下辺 (y=0) : T = 0°C  （Dirichlet, 冷却壁）
  左辺 (x=0) : T = 0°C  （Dirichlet, 冷却壁）
  右辺 (x=NX): T = 0°C  （Dirichlet, 冷却壁）

離散化: 有限差分法（Python, scipy.sparse.linalg.spsolve）
計算コスト: 2400セル × 50メンバー = 50回 FD ソルブ/サイクル（高速）
```

---

### A03：熱源分布 Q(x,y) の推定

**問い：「温度センサの読みから、どこで熱が発生しているかを当てる」**

| 項目 | 内容 |
|------|------|
| **推定する量** | 熱源分布 $Q(x,y)$ [W/m³]（各セルの発熱量） |
| **正解の Q** | ミッフィーのパターン（体部分=高発熱、背景=0） |
| **前向きモデル** | $-\nabla^2 T = Q/k$ を FD で解いて $T(x,y)$ を生成 |
| **観測** | 温度 $T$ のスパース観測（30〜60点/サイクル） |
| **EnKF の操作** | $Q^{(i)}$ を摂動 → $T^{(i)}$ を計算 → $T$ 観測で $Q$ を補正 |
| **線形性** | $T = A Q$（線形！$A$ は Green 関数行列）→ K が解析的に求まる |
| **面白さ** | 赤外カメラで表面温度計測 → 内部発熱源を推定（実問題に直結） |

**実装ステップ：**
```
① Q_true = ミッフィーパターン（各セルに発熱量割り当て）
② k=1 固定で ∇²T = -Q/k を FD ソルブ → T_true 生成
③ アンサンブル初期化：Q^(i) = Q_mean + 空間相関ノイズ
④ 各サイクル:
    a. 各メンバーで T^(i) = solver(Q^(i)) を実行
    b. 観測 y = T_true[sensors] + ε
    c. EnKF 更新: Q^(i) ← Q^(i) + K(y - T^(i)[sensors])
    d. RMSE(Q) と RMSE(T) を記録
⑤ 最終的に Q̄ がミッフィー形状に収束すれば成功
```

### A04：熱伝導率分布 k(x,y) の推定

**問い：「温度センサの読みから、どこの材料が何かを当てる」**

| 項目 | 内容 |
|------|------|
| **推定する量** | 熱伝導率分布 $k(x,y)$ [W/mK]（各セルの材料特性） |
| **正解の k** | ミッフィーのパターン（体=高熱伝導、背景=低熱伝導） |
| **前向きモデル** | $\nabla\cdot(k\nabla T) = 0$ を FD で解いて $T(x,y)$ を生成 |
| **観測** | 温度 $T$ のスパース観測 |
| **EnKF の操作** | $k^{(i)}$ を摂動 → $T^{(i)}$ を計算 → $T$ 観測で $k$ を補正 |
| **線形性** | **非線形**（$T$ は $k$ に対して非線形） → アンサンブルが必須 |
| **境界条件** | 左辺=100°C（高温壁）、右辺=0°C（冷却壁）、上下=断熱 |
| **面白さ** | 材料の不均一性・欠陥・異材料の非破壊検査に対応 |

**A03 との違い：** $k$ への依存が非線形なので、OI・KF では対応できない。EnKF が必須。

---

### A05：熱伝達率分布 h(x,y) の推定

**問い：「温度センサの読みから、表面の冷却能力分布を当てる」**

| 項目 | 内容 |
|------|------|
| **推定する量** | 熱伝達率分布 $h(x,y)$ [W/m²K]（境界での冷却強さ） |
| **正解の h** | ミッフィーのパターン（体部分=高熱伝達、背景=低熱伝達） |
| **前向きモデル** | $\nabla^2 T = 0$、Robin BC: $-k\partial T/\partial n = h(T - T_\infty)$ |
| **観測** | 温度 $T$ のスパース観測 |
| **EnKF の操作** | $h^{(i)}$ を摂動 → $T^{(i)}$ を計算 → $T$ 観測で $h$ を補正 |
| **難易度** | ★★★（Robin BC の離散化、$h < 0$ にならない制約が必要） |
| **面白さ** | 冷却フィン設計、エンジン熱管理、電子基板冷却の逆問題 |

---

### A03〜A05 共通の技術課題

| 課題 | 対策 |
|------|------|
| アンサンブル崩壊 | 乗法インフレーション（A02 と同様 α=1.05） |
| 物理量の負値化（Q<0, k<0, h<0） | 更新後に `np.clip(X, 0, ∞)` で強制正値化 |
| 前向きモデルの計算コスト | `scipy.sparse.linalg.spsolve` で高速化（50メンバー×50サイクルでも数秒） |
| 状態ベクトルと観測の次元 | 状態 Q/k/h は n=2400、観測 T は m=60 → 次元比は A02 と同じ |
| OpenFOAM への発展 | A05 完成後、Python FD → laplacianFoam に差し替え可能な設計にする |

### 3つの問題の比較

| | A03（Q推定） | A04（k推定） | A05（h推定） |
|---|---|---|---|
| 推定する物理量 | 発熱量 | 熱伝導率 | 熱伝達率 |
| 前向きモデルの線形性 | 線形 ✓ | **非線形** | **非線形** |
| 物理的意味 | 内部熱源の場所 | 材料の分布 | 表面冷却の強さ |
| 実問題への対応 | 発熱部位推定 | 非破壊検査 | 冷却設計最適化 |
| 難易度 | ★★☆ | ★★★ | ★★★ |
