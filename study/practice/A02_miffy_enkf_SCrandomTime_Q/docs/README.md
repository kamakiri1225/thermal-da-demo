# A02_miffy_enkf_Q — 物理DA：発熱量 Q(x,y) の推定によるミッフィー温度場の再現

## 目的

「ミッフィーの温度分布 T_true を正解として与え、
熱伝導方程式 $-\nabla^2 T = Q$ を前向きモデルとして、
スパースな T 観測から発熱量 Q(x,y) をデータ同化（EnKF）で逆推定する」

→ Q_analysis を前向きモデルに代入したとき、**T_analysis ≈ T_miffy** になることを目指す。

---

## A02 との根本的な違い

| | A02（統計 DA） | A03（物理 DA） |
|--|--------------|--------------|
| 状態変数 | $T(x,y)$（温度を直接推定） | $Q(x,y)$（**発熱量を推定**） |

## 前向きモデル（Forward Model）

2D 定常熱伝導（ポアソン方程式）を有限差分法で解きます。

$$-\nabla^2 T = Q \quad \Longrightarrow \quad \mathbf{A}\,\mathbf{T} = -\mathbf{Q}$$

$\mathbf{A}$ は 2D ラプラシアン行列（$n \times n$ 疎行列）。LU 分解を 1 回だけ行い、
各アンサンブルメンバーへの適用はバック代入のみ（**50 メンバー×50 サイクル = 0.01 秒**）。

```python
A_lap     = build_laplacian()      # 2400×2400 疎行列（一度だけ構築）
solve_lap = factorized(A_lap)      # LU 分解（一度だけ）

def forward_T(Q_flat):
    rhs = -Q_flat.copy()
    rhs[bnd] = 0.0                 # 境界セルは T=0
    return solve_lap(rhs)          # バック代入（高速）
```

## 状態ベクトルの 1D ↔ 2D 変換

EnKF は行列・ベクトル演算を行うため **1次元配列（ベクトル）** を使います。
描画には **2次元配列（グリッド）** が必要です。

```python
T_true_2d = make_miffy()           # shape: (60, 40)  ← 描画用
T_true    = T_true_2d.flatten()    # shape: (2400,)   ← EnKF 計算用
```

| 操作 | メソッド | 用途 |
|------|---------|------|
| 2D → 1D | `.flatten()` | EnKF の行列積・カルマンゲイン計算 |
| 1D → 2D | `.reshape(NY, NX)` | imshow による可視化 |

インデックスの対応（行優先 C-order）：

$$\text{idx} = i_y \times NX + i_x \quad \Longleftrightarrow \quad \text{field}[i_y,\, i_x]$$

## EnKF アルゴリズム（A03 版）

```
[状態]  X^(i) = Q^(i)  ∈ ℝⁿ   (i=1,...,50)

[各サイクル]
  ① センサ選択: obs_idx ← 内部セルからランダムに 60 点
  ② 前向きモデル: T^(i) = forward_T(Q^(i))  (全 50 メンバー実行)
  ③ 観測: y = T_true[obs_idx] + N(0, σ_r²)
  ④ アンサンブル統計:
       Q' = Q - Q̄         (Q の偏差行列, n×N)
       T' = T - T̄         (T の偏差行列, n×N)
       HX' = T'[obs_idx]  (観測空間の T 偏差, m×N)
  ⑤ イノベーション共分散: S = HX'HX'ᵀ/(N-1) + R   (m×m)
  ⑥ カルマンゲイン:
       K_raw = Q'HX'ᵀ/(N-1) · S⁻¹   ← Cov(Q, T_obs)
       K_loc = K_raw ∘ ρ             ← ローカライゼーション
  ⑦ 更新: Q^(i) ← Q^(i) + K_loc(y + ε^(i) - T^(i)[obs])
  ⑧ 乗法インフレーション（α=1.05）
```

## 理論的な Q_true について

ミッフィー温度場 $T_{\rm miffy}$ を生成する「完璧な熱源分布」は次式で求まります：

$$Q_{\rm true} = -\nabla^2 T_{\rm miffy} = -\mathbf{A}_{\rm lap} \cdot \mathbf{T}_{\rm miffy}$$

この $Q_{\rm true}$ は**正負の値を持ちます**：
- 正の領域（赤）: 熱源（fur と background の境界付近）
- 負の領域（青）: 冷却源（境界 T=0 に向けて熱を逃がす）

これは物理的に意味があります：温度が 100°C から 0°C に急変する「エッジ」付近では、
片側を加熱・もう片側を冷却する源が必要になります。

初期から **93% 改善**（309°C → 21.6°C）。

### なぜ RMSE_T の下限が生じるか

T_miffy はステップ状の温度分布（0°C ↔ 100°C の急変）を持つが、
ポアソン方程式の解は連続で滑らか。
$-\nabla^2 T = Q$ の解は常に滑らかなため、
T_miffy の鋭いエッジを完全に再現することは原理的に不可能。
→ **21°C 程度の RMSE 下限** は数値的な誤差ではなく物理的な制約。

## なぜ Q が正解から遠いのに T はミッフィーに近づくのか

これは**逆問題の非一意性（ill-posedness）**と呼ばれる現象です。

### 順方向と逆方向の非対称性

```
Q（発熱量）  →  -∇²T = Q  を解く  →  T（温度）  ← 情報が"平滑化"される
                                              ↑
                               EnKF はここを逆向きに解こうとしている
```

**順方向（Q → T）**: ポアソン方程式を解くと、Q の空間的な細部（鋭いエッジ）が**拡散・平滑化**されて T になります。高周波の情報が「溶けて」いく一方向の操作です。

**逆方向（T → Q）**: T から Q を復元しようとすると、**無数の Q が同じ T を生成できる**ため一意に決まりません（不良設定問題）。

### 具体例

T_miffy の「ミッフィー輪郭部分で T が 0°C → 100°C に急変する」というエッジ情報は、
ポアソン方程式を通ると広い範囲の T 変化として現れます。逆に言えば、
**その T 変化を観測しても、Q がエッジにあるのか内部全体に分布しているのか区別できません**。

### EnKF が最適化しているもの

```python
innov = y - T_ens[obs_idx, :]   # T の残差を最小化
X_new = X + K @ innov           # Q を調整して T を合わせる
```

EnKF は「**T の観測との一致**」を最小化するように Q を更新します。Q 自体の正確さは直接の目標ではないため、T は収束しても Q は「T ≈ T_miffy を生む Q のうちの一つ」に落ち着きます。

### まとめ

| | Q（発熱量） | T（温度） |
|--|-----------|---------|
| EnKF の目標 | 直接の目標ではない | **観測と一致させる** |
| 収束先 | 「T ≈ T_miffy を生む Q の一つ」 | T_miffy に近い分布 |
| 解は一意か | **無数の正解がある** | センサで観測可能 |

これは実問題でも同じです。「内部の発熱源の場所を温度センサで特定する」のは本質的に難しく、
**スパース性・物理的上限・空間的滑らかさなどの追加制約を加えないと Q は一意に決まりません**。
A02_miffy_enkf_Q では制約なしで EnKF を動かしているため、T は収束しても Q は
「数ある正解のうちアンサンブル空間に存在する一つ」に落ち着きます。
