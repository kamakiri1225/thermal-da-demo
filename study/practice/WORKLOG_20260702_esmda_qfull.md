### 2.3 チューニングで見つかった問題と対処

| 問題 | 原因 | 対処 |
|---|---|---|
| 実行が止まる（CPU 4400%） | OpenBLAS が全コアにスレッド生成し空回り | スクリプト冒頭で BLAS スレッドを 4 に制限 |
| R_LOC=3 で3桁発散 | 非局所な順モデルの共分散を切りすぎ | — |
| R_LOC=5 で反復途中に温度 RMSE が 5000 °C 超へ暴走、m=30〜50 では同化なしより悪化 | 局所化更新の遠方への副作用が拘束されない | **R_LOC=10 に拡大**（両方とも解消） |

教訓: 順問題が非局所な逆問題では、局所化半径を
観測感度の広がりに合わせて広く取る必要がある。

## 3. 結果

### 3.1 数値

| 指標 | 値 |
|---|---|
| 温度場 RMSE（m=300, x(q_mean)） | 20.06 °C（温度場直接同化: 19.82 °C と同等） |
| 熱源 q の RMSE | 38.8 で飽和（q_true の std=40.0） |
| corr(q_est, 平滑化 q_true), m=30/100/200/300 | 0.33 / 0.59 / 0.65 / **0.76** |
| 旧方式 q_derived の同相関（m=300） | 0.74 |

### 3.2 わかったこと

1. **セルスケールの熱源エッジは点温度観測から原理的に復元できない**。
   q_true は輪郭線状のエッジ場で、L⁻¹ の平滑化作用により高周波情報が
   観測に残らない（逆問題の不適切性）。N や反復数を増やしても改善しない。
2. **平滑化スケール（σ=1）なら相関 0.76 で復元でき、目・鼻・輪郭が視認できる**
   （`fig08_qfull_vs_derived.png`）。
3. **旧方式との差は「情報量」ではなく「使いやすさ」**。線形問題なので
   取り出せる低周波情報は両者ほぼ同じ。ただし旧方式は信号が増幅ノイズに
   埋もれて図として読めず、Q-state は事前分布が q を正則化するため
   そのまま使える滑らかな熱源場が出る。
