# やったこと整理 ― 103_0 / 103_1 データ同化ケース構築の記録

作業日: 2026-09-08

## 目的

`102_0_openfoam_hollow_cylinder_heat_transfer`(中空円筒＋外周ヒータの chtMultiRegionFoam
CHT解析・輻射あり)をベースに、**数点の温度観測だけで、でたらめな初期状態から
固体温度場とヒータ発熱量が真値へ補正されていく時刻歴**を確認する
データ同化(双子実験/OSSE)を構築した。

- `103_0_openfoam_da_enkf` ― アンサンブルカルマンフィルタ(EnKF)
- `103_1_openfoam_da_pf` ― 粒子フィルタ(PF)

両者は同一の真値・同一の観測(乱数シード一致)を同化するため、直接比較できる。

## 構築したもの

### 1. 解析コア(モデル非依存・両フォルダ共通)

- `dacore/enkf.py` ― 確率的EnKF(摂動観測法)。標本共分散から低ランク更新、乗算インフレーション付き
- `dacore/pf.py` ― ブートストラップPF。系統リサンプリング＋正則化ジッタ、ESS監視

### 2. OpenFOAM 連成版(本命・field-space)

各メンバー/粒子が**実際に chtMultiRegionFoam を回す**データ同化ループ。

- `daof/of_io.py` ― OpenFOAMフィールドの読み書き(internalField・セル中心・controlDictウィンドウ設定)
- `daof/of_case.py` ― メンバーケース生成(102_0の既存メッシュを再利用)・状態書込み・直列実行・場の読出し
- `daof/of_twin.py` ― 双子実験ドライバ(真値ラン→合成観測→予報/解析サイクル→場の書き戻し)
- 状態 = **固体温度場 全20,696セル ＋ ヒータ発熱Q**(拡大状態でパラメータ同時推定)
- 観測 = hot/cold の2点温度(σ=0.3 K)

つまずきと対処:
- adjustTimeStep使用時は `writeControl adjustableRunTime` にしないと終了時刻を正確に
  踏めず、時刻ディレクトリが `2.001591` のようにずれる → 修正済み
- 輻射あり67kセルの直列実行は起動直後 約30–40 秒/(実時間1秒)と重い →
  最小実行(N=5, 0→20 s, 観測2回)を既定にし、規模は設定ファイルで拡張可能にした

### 3. ROM 高速版(プロトタイプ)

集中定数5ノード熱モデルを102_0の温度履歴に同定(残差 RMSE 0.012 K)し、
同じ解析コアで数秒で回るデータ同化を用意。アルゴリズム検証・EnKF vs PF比較用。

- `dacore/cht_rom.py` / `calibrate.py` / `ensemble.py` / `observations.py` / `twin.py`

### 4. 可視化・ドキュメント

- PyVistaによる観測点/未観測点の3D図(`run/plot_probe_locations.py`)
- 収束RMSE・パラメータ推定・温度場スナップショットの自動作図
- docs: 手法俯瞰(00)・問題設定(01)・EnKF/PF理論と連成実装(02)・実行手順(03)・EnKF vs PF比較(103_1/04)

## 結果の要点

### ROM版(完了)

| 指標 | EnKF (N=60) | PF (N=400) |
|------|-------------|------------|
| 温度RMSE 初期→最終 | 9.74 → **0.076 K** | 9.80 → 0.458 K |
| 未観測ノード最終RMSE | 0.079 K | 0.513 K |
| q_scale推定(真値1.0) | 0.976 | 1.718 |

2点観測だけで未観測ノードまで補正される(EnKF)。PFは次元の呪い・粒子貧困化で
EnKFより収束が浅い ― 手法特性がそのまま現れた。

### OpenFOAM連成版 EnKF(最小実行 N=5, 0→20 s)

- でたらめ初期場(11〜47 ℃、RMSE 約13 K)＋でたらめQ(6〜19 W)から出発
- **1回目の解析(t=10 s)で場RMSE 0.072 K まで補正**(観測は hot/cold の2点のみ)
- Q推定は 11.7 W → 真値15 Wへ向かって更新(短時間窓ではQの観測可能性が低い)

数値は `results/openfoam_enkf_summary.yaml` / `openfoam_enkf_history.csv`、
図は `docs/img/openfoam_enkf_*.png` を参照。
