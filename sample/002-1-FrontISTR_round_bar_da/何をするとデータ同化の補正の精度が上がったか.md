## 改善1: FrontISTR材料物性のITEM番号マッピング修正（最重要）

### 問題
`fistr_interface.py` の `_write_mesh()` で材料定義のITEM番号が完全に誤っていた。

**FrontISTR熱解析における正しいITEM番号の意味**（`heat_init.f90` のソースで確認）：
- `ITEM=1` → 密度 ρ [kg/m³]
- `ITEM=2` → 比熱 Cp [J/(kg·K)]
- `ITEM=3` → 熱伝導率 λ [W/(mK)]

**修正前（誤り）**：
```
!ITEM=1
 2430000     ← heat_capacity = ρ×cp = 2.43e6 → FrontISTRはρとして解釈 → 900倍大きい密度
!ITEM=2
 160, 0.0    ← conductivity = 160 → FrontISTRはCpとして解釈 → 誤った比熱
!ITEM=3
 160, 0.0    ← conductivity = 160 → λとして正しい値だが意味がない
```

**修正後（正しい）**：
```
!ITEM=1
 2700        ← ρ = 2700 kg/m³（アルミニウム密度）
!ITEM=2
 900         ← Cp = 900 J/(kg·K)（アルミニウム比熱）
!ITEM=3
 160, 0.0    ← λ = 160 W/(mK)（アルミニウム熱伝導率）
 160, 1000.0
```

### 影響
誤ったITEM定義により実効的な熱拡散率が160倍小さくなっていた：

| | 誤った設定 | 正しい設定 |
|---|---|---|
| 実効 ρcp [J/(m³K)] | 2.43e6 × 160 = 3.89e8 | 2700 × 900 = 2.43e6 |
| 実効 α [m²/s] | 160 / 3.89e8 = **4.1e-7** | 160 / 2.43e6 = **6.6e-5** |

熱拡散率が160倍小さいため、900s（15分）の計算でも熱がx=0.05m付近より先に伝わらず、
棒右側（x > 0.08m）はほぼ初期温度（20°C）のまま変化しなかった。

OIは真値とモデルが両方とも20°Cのノードに対して補正をかけ、誤差を追加してしまっていた（-4.5%の悪化）。

## 改善2: パラメータをOpenFOAM版と統一

以下のパラメータをOpenFOAM版（`002-1_laplacian_da_round_bar`）に合わせた：

| パラメータ | 修正前 | 修正後 |
|-----------|--------|--------|
| DT [s] | 1.0 | 5.0 |
| N_STEPS | 900 | 180 |
| CYCLE_ON [ステップ] | 450 | 90（= 450s） |
| CYCLE_OFF [ステップ] | 150 | 30（= 150s） |
| ASSIM_SENSOR_AXIAL_NODES | [1, 4] | [4, 16]（x=0.034m, 0.124m） |
| OBS_NOISE_STD | 0.02 | 0.05 |
| CORRELATION_LENGTH_M | 0.015 | 0.05 |
| G_TRUE / G_MODEL | 100 / 50 | 120 / 80 |

**相関長の効果**：`CORRELATION_LENGTH_M = 0.05m` はセンサ位置から±2ノード程度まで補正が広がる長さ。
短すぎると補正範囲が狭く（センサ点のみ改善）、適切な相関長が全域のRMSE改善に寄与する。

## 改善4: OpenFOAM版の境界条件をFrontISTRと統一

### 変更内容
OpenFOAMの左端境界条件を Neumann（`fixedGradient`）から Dirichlet（`fixedValue`）に変更。

**修正前**（OpenFOAM）：
```
left
{
    type  fixedGradient;
    gradient  uniform 120;   ← 熱流束 = k×G = 19200 W/m²
}
```

**修正後**（OpenFOAM）：
```
left
{
    type  fixedValue;
    value  uniform 56;   ← T = T_AMB + G×L = 20 + 120×0.3 = 56°C
}
```

### 理由
両者の境界条件が異なると以下の違いが生じてグラフの形状が全く異なる：

| BC種別 | 左端温度の挙動 | グラフの特徴 |
|--------|--------------|-------------|
| Dirichlet（fixedValue） | 最初のステップから56°Cに固定 → 矩形波 | 左端(N0)が0-56°Cの矩形波 |
| Neumann（fixedGradient） | 熱流束一定、温度は徐々に上昇 | 全ノードが20°Cからゆっくりランプアップ |

形状・解析条件・DA設定を同じにするには境界条件の種類も一致させる必要がある。

## まとめ

最も重要な改善は**材料物性のITEM番号ミス**の修正。
これにより熱拡散が正常化し、棒全体で意味のある温度変化が計算されるようになった。
OIは全域で機能し、FrontISTR-onlyに対して**62%の誤差削減**を達成した。

パラメータ統一と相関長の適切な設定も、OIが広い範囲の節点を補正するために必要な要素である。
