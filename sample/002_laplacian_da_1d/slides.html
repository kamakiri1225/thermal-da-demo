Method

手法: optimal interpolation

OpenFOAM 予測値を背景値とし、センサ観測との差を OI ゲインで全節点へ配る。

\[ \mathbf{x}^a = \mathbf{x}^f + \mathbf{K} \left(\mathbf{y} - \mathbf{H}\mathbf{x}^f\right) \]
\[ \mathbf{K} = \mathbf{B}\mathbf{H}^T \left(\mathbf{H}\mathbf{B}\mathbf{H}^T+\mathbf{R}\right)^{-1} \]

H

状態ベクトルからセンサ位置だけを取り出す行列。

B

OpenFOAM 予測誤差が空間的にどう似ていそうかを表す。

R

観測ノイズの大きさ。今回は `0.05 degC`。

Intuition

B は「誤差の広がり方」の仮定

今回の `B` は節点間距離から作る。

x = np.arange(N_NODES) * DX
distance = np.abs(x[:, None] - x[None, :])
B = BACKGROUND_ERROR_STD**2 * np.exp(
    -(distance**2) / (2.0 * CORRELATION_LENGTH_M**2)
)

近い節点ほど同じ方向に間違っていそう、という仮定。

センサからの距離重みの目安意味
0.00 m約 1.00ほぼ直接補正
0.03 m約 0.88強く補正
0.06 m約 0.61中程度
0.09 m約 0.32弱め
0.12 m約 0.14かなり弱い
相関長 `CORRELATION_LENGTH_M` は結果に効く。実験データでは感度確認が必要。

Implementation

どのファイルのどこで補正しているか

対象ファイル

`sample/002_laplacian_da_1d/oi/da_main.py`

対象関数

`run_da()`

対応する式

\[ \mathbf{x}^a = \mathbf{x}^f + \mathbf{K} \left(\mathbf{y}-\mathbf{H}\mathbf{x}^f\right) \] 
def run_da(
    ofi: OFInterface,
    truth_T: np.ndarray,
    g_model_series: np.ndarray,
    H: np.ndarray,
    B: np.ndarray,
    R: np.ndarray,
) -> tuple[np.ndarray, np.ndarray]:
    """
    laplacianFoam (G_model) + optimal interpolation で
    データ同化を実行する。
    """
    print("─── データ同化ループ (G_model + OI) ───")
    ofi.reset(initial_T=T_INIT)

    n_obs = len(SENSOR_NODES)

    # OI ゲイン:
    # K = B H^T (H B H^T + R)^-1
    gain = B @ H.T @ np.linalg.inv(H @ B @ H.T + R)

    x_current = np.ones(N_NODES) * T_INIT
    of_T = np.zeros((N_STEPS, N_NODES))
    da_T = np.zeros((N_STEPS, N_NODES))

    for k in range(N_STEPS):
        # センサ観測 y:
        # ツイン実験なので truth_T から疑似観測を作る
        y = H @ truth_T[k] + np.random.randn(n_obs) * OBS_NOISE_STD

        # OpenFOAM 予測 x_f:
        # 前ステップの補正済み温度場 x_current を書き、
        # laplacianFoam を 1 ステップだけ進める
        ofi.write_field(k * DT, x_current, gradient=g_model_series[k])
        ofi.run_step(k * DT, (k + 1) * DT)
        x_pred = ofi.read_field((k + 1) * DT)

        # innovation = y - H x_f
        innovation = y - H @ x_pred

        # OI 更新:
        # x_a = x_f + K (y - H x_f)
        x_da = x_pred + gain @ innovation

        # 補正後のセル値を次ステップの OpenFOAM 入力にする
        x_current = x_da

        of_T[k] = x_pred
        da_T[k] = x_da

    return of_T, da_T
Scalability

大規模セル数でそのまま使えるか

そのままは厳しい

現在の教材実装は全セルの密な背景誤差共分散 `B` を作る。

\[ \mathbf{B} \in \mathbb{R}^{N \times N} \]

`N = 1,000,000` なら `B` は \(10^{12}\) 要素になり、メモリだけで数 TB 規模になる。

考え方は使える

OpenFOAM を予測器にして、観測で場を補正する構造自体は大規模 CFD でも有効。

  • 局所化してセンサ周辺だけ補正する
  • `B` を疎行列・距離カットオフで近似する
  • 低ランク近似や EnKF を使う
  • 全ステップではなく数ステップごとに同化する
100 万点規模では「全セル × 全セル」の OI ではなく、局所 OI、EnKF、低ランク表現、観測近傍だけの補正などに設計を変える必要がある。

今回は未使用: `kf/`

  • 時変の誤差共分散 `P` を毎ステップ更新する

  • より本格的だが、OpenFOAM との接続設計が難しい
\[ K = P^- H^T (H P^- H^T + R)^{-1} \]
OI vs KF

OI と KF の違い

観点 OI KF 今回の判断
誤差共分散 固定の `B` 時間発展する `P` まずは固定 `B` で十分
OpenFOAM の時間発展 ブラックボックスでよい `A_d` や線形化近似が欲しい `A_d` を作らない方針を優先
ゲイン `B, H, R` から計算 `P^-, H, R` から毎ステップ計算 OI の方が実装が軽い
モデル誤差の扱い 空間相関を仮定して補正 予測誤差の時間発展も扱える 今回は接続検証なので OI
大規模計算 密な `B` は不可。局所化が必要 密な `P` は不可。EnKF などが現実的 どちらも大規模化には近似が必要
まとめ: 今回は「OpenFOAM のセル値を逐次補正して書き戻す流れ」を作ることが目的なので、KF ではなく OI を採用した。
Theory

共通の理論背景: 予測と観測をどう混ぜるか

OI も KF も、基本形は同じ。

\[ \mathbf{x}^a = \mathbf{x}^f + \mathbf{K} \left( \mathbf{y} - \mathbf{H}\mathbf{x}^f \right) \]
記号意味
\(\mathbf{x}^f\)forecast。モデルによる予測状態
\(\mathbf{x}^a\)analysis。観測で補正した解析状態
\(\mathbf{y}\)観測値。センサ温度
\(\mathbf{H}\)状態から観測位置だけを取り出す観測行列
\(\mathbf{y}-\mathbf{H}\mathbf{x}^f\)innovation。観測と予測の差
\(\mathbf{K}\)ゲイン。観測差をどこへどれだけ配るか

今回の状態ベクトル

\[ \mathbf{x} = \begin{bmatrix} T_0 & T_1 & \cdots & T_9 \end{bmatrix}^T \]

10 セルの温度を状態として扱う。実測実験では、この状態が OpenFOAM セル温度に対応する。

Theory

観測式と誤差の考え方

観測式

\[ \mathbf{y} = \mathbf{H}\mathbf{x}^{true} + \mathbf{v} \]

\(\mathbf{v}\) はセンサノイズ。平均 0、共分散 \(\mathbf{R}\) と仮定する。

\[ E[\mathbf{v}] = 0,\quad E[\mathbf{v}\mathbf{v}^T] = \mathbf{R} \]

予測誤差

\[ \mathbf{e}^f = \mathbf{x}^f - \mathbf{x}^{true} \]

OI では予測誤差共分散を固定の \(\mathbf{B}\) と置く。

\[ E[\mathbf{e}^f(\mathbf{e}^f)^T] = \mathbf{B} \]

KF ではこの共分散を \(\mathbf{P}\) として毎ステップ時間発展させる。

Theory: OI

OI の理論: 固定 B で解析誤差を最小化する

解析値を次の線形結合で作る。

\[ \mathbf{x}^a = \mathbf{x}^f + \mathbf{K} \left( \mathbf{y}-\mathbf{H}\mathbf{x}^f \right) \]

解析誤差は、

\[ \mathbf{e}^a = \mathbf{x}^a - \mathbf{x}^{true} = (\mathbf{I}-\mathbf{K}\mathbf{H})\mathbf{e}^f + \mathbf{K}\mathbf{v} \]

この解析誤差の分散、つまり \(\mathrm{tr}(\mathbf{P}^a)\) を最小にする \(\mathbf{K}\) を求める。

解析誤差共分散

\[ \mathbf{P}^a = (\mathbf{I}-\mathbf{K}\mathbf{H}) \mathbf{B} (\mathbf{I}-\mathbf{K}\mathbf{H})^T + \mathbf{K}\mathbf{R}\mathbf{K}^T \]
\[ \mathbf{K}_{OI} = \mathbf{B}\mathbf{H}^T \left( \mathbf{H}\mathbf{B}\mathbf{H}^T+\mathbf{R} \right)^{-1} \]
Theory: OI

OI の B は何を表すか

今回の OI では、OpenFOAM 予測誤差の空間相関をガウス型で仮定した。

\[ B_{ij} = \sigma_b^2 \exp \left( - \frac{d_{ij}^2}{2L^2} \right) \]
記号意味
\(\sigma_b\)背景誤差標準偏差
\(d_{ij}\)セル \(i\) と \(j\) の距離
\(L\)相関長

直感

センサ位置で「予測が +3 degC 低い」と分かったとき、近いセルも同じ方向に間違っていそうだと考える。

遠いセルは同じ誤差を持つとは限らないので、補正を弱くする。

つまり OI は「観測差を、事前に決めた誤差相関マップに従って配る方法」。
Theory: KF

KF の理論: 状態と誤差共分散を時間発展させる

状態方程式

\[ \mathbf{x}_k = \mathbf{A}_d \mathbf{x}_{k-1} + \mathbf{w}_k \]
\[ E[\mathbf{w}_k] = 0,\quad E[\mathbf{w}_k\mathbf{w}_k^T] = \mathbf{Q} \]

\(\mathbf{A}_d\) は離散時間の状態遷移行列、\(\mathbf{Q}\) はモデル誤差共分散。

観測方程式

\[ \mathbf{y}_k = \mathbf{H}\mathbf{x}_k + \mathbf{v}_k \]
\[ E[\mathbf{v}_k] = 0,\quad E[\mathbf{v}_k\mathbf{v}_k^T] = \mathbf{R} \]

KF は「状態の予測」だけでなく、「予測がどれくらい不確かか」も毎ステップ更新する。

Theory: KF

KF の予測ステップ

状態予測

\[ \mathbf{x}_k^- = \mathbf{A}_d \mathbf{x}_{k-1}^+ \]

\(-\) は観測で補正する前の予測、\(+\) は補正後を表す。

誤差共分散予測

\[ \mathbf{P}_k^- = \mathbf{A}_d \mathbf{P}_{k-1}^+ \mathbf{A}_d^T + \mathbf{Q} \]

モデルを進めると、状態だけでなく不確かさ \(\mathbf{P}\) も進む。

OpenFOAM でこの形を使うには、\(\mathbf{A}_d\) をどう作るか、またはどう近似するかが問題になる。今回そこを避けるために OI を使った。
Theory: KF

KF の更新ステップ

カルマンゲイン

\[ \mathbf{K}_k = \mathbf{P}_k^-\mathbf{H}^T \left( \mathbf{H}\mathbf{P}_k^-\mathbf{H}^T + \mathbf{R} \right)^{-1} \]

状態更新

\[ \mathbf{x}_k^+ = \mathbf{x}_k^- + \mathbf{K}_k \left( \mathbf{y}_k-\mathbf{H}\mathbf{x}_k^- \right) \]

共分散更新

\[ \mathbf{P}_k^+ = (\mathbf{I}-\mathbf{K}_k\mathbf{H}) \mathbf{P}_k^- \]
KF のゲインは毎ステップ変わる。予測が不確かなら観測を強く信じ、予測が確かなら観測を弱く反映する。
Theory

OI は KF の簡略版として見られる

式の位置 OI KF 違い
ゲイン \(\mathbf{K}=\mathbf{B}\mathbf{H}^T(\mathbf{H}\mathbf{B}\mathbf{H}^T+\mathbf{R})^{-1}\) \(\mathbf{K}_k=\mathbf{P}_k^-\mathbf{H}^T(\mathbf{H}\mathbf{P}_k^-\mathbf{H}^T+\mathbf{R})^{-1}\) OI は固定 \(B\)、KF は時変 \(P_k^-\)
予測 \(\mathbf{x}^f=\mathcal{M}_{OF}(\mathbf{x}^a)\) \(\mathbf{x}_k^-=\mathbf{A}_d\mathbf{x}_{k-1}^+\) OI は OpenFOAM をブラックボックスにできる
共分散 固定値として設計 \(\mathbf{P}_k^-=\mathbf{A}_d\mathbf{P}_{k-1}^+\mathbf{A}_d^T+\mathbf{Q}\) KF は誤差の時間発展も扱う
今回の実装 採用 未採用 まず OpenFOAM との逐次補正ループを成立させるため
今回の OI は「KF のゲイン式に似ているが、時間発展した \(P_k^-\) の代わりに、固定した \(B\) を使う方法」と理解するとよい。
KF vs EnKF

EnKF と KF は違う

観点 KF EnKF
状態の持ち方 1 つの状態ベクトル \(\mathbf{x}\) と共分散行列 \(\mathbf{P}\) 多数の状態サンプル、つまりアンサンブル \(\mathbf{x}^{(1)},\dots,\mathbf{x}^{(m)}\)
予測誤差共分散 \(\mathbf{P}\) を行列として直接持つ アンサンブルのばらつきから近似する
モデルの進め方 \(\mathbf{x}_k^-=\mathbf{A}_d\mathbf{x}_{k-1}^+\) \(\mathbf{x}_{k}^{f,(i)}=\mathcal{M}_{OF}(\mathbf{x}_{k-1}^{a,(i)})\)
`A_d` の必要性 基本的に必要 明示的な `A_d` は不要
OpenFOAM との相性 線形化や近似行列が課題 OpenFOAM をそのまま複数回走らせればよい
OpenFOAM の内部行列を知らない方法で進めたいなら、次の候補は通常 KF ではなく EnKF。
Theory: EnKF

EnKF の基本式

EnKF では、状態を 1 本ではなく \(m\) 本のアンサンブルで持つ。

\[ \mathbf{X}^f = \begin{bmatrix} \mathbf{x}^{f,(1)} & \mathbf{x}^{f,(2)} & \cdots & \mathbf{x}^{f,(m)} \end{bmatrix} \]

各メンバーを OpenFOAM で予測する。

\[ \mathbf{x}_{k}^{f,(i)} = \mathcal{M}_{OF} \left( \mathbf{x}_{k-1}^{a,(i)}, \theta^{(i)} \right) \]

ポイント

\(\mathcal{M}_{OF}\) は OpenFOAM の計算そのもの。行列 \(\mathbf{A}_d\) を作らない。

\(\theta^{(i)}\) は境界条件、物性、熱入力などをメンバーごとに少し変えたもの。

Theory: EnKF

EnKF では共分散をアンサンブルから作る

平均

\[ \bar{\mathbf{x}}^f = \frac{1}{m} \sum_{i=1}^{m} \mathbf{x}^{f,(i)} \]

偏差行列

\[ \mathbf{A}^f = \begin{bmatrix} \mathbf{x}^{f,(1)}-\bar{\mathbf{x}}^f & \cdots & \mathbf{x}^{f,(m)}-\bar{\mathbf{x}}^f \end{bmatrix} \]

予測共分散の近似

\[ \mathbf{P}^f \approx \frac{1}{m-1} \mathbf{A}^f(\mathbf{A}^f)^T \]

密な \(\mathbf{P}\) を直接作らず、アンサンブル偏差から必要な計算を行う。

100 万点規模では、それでも局所化や領域分割が必要。だが `A_d` を作らない点では KF より現実的。
Theory: EnKF

EnKF の更新式

式の形は KF と似ている。

\[ \mathbf{K} = \mathbf{P}^f\mathbf{H}^T \left( \mathbf{H}\mathbf{P}^f\mathbf{H}^T + \mathbf{R} \right)^{-1} \]
\[ \mathbf{x}^{a,(i)} = \mathbf{x}^{f,(i)} + \mathbf{K} \left( \mathbf{y}^{(i)} - \mathbf{H}\mathbf{x}^{f,(i)} \right) \]

実装上の意味

OpenFOAM を複数条件で走らせ、結果のばらつきから「どのセルがどの観測と一緒に変わるか」を推定する。

これは固定の `B` を手で設計する OI より一歩進んだ方法。

Next Method

`A_d` を知らない方針で進めるなら

候補 `A_d` は必要か OpenFOAM との相性 次にやるなら
OI 不要 よい 今回の方法。まず実測データ版へ進める
KF 必要になりやすい OpenFOAM の線形化が課題 今回の方針とは合いにくい
EnKF 不要 よい。ただし OpenFOAM を複数メンバー分走らせる OI の次の本命候補
local EnKF / local OI 不要 大規模計算向き 100 万点規模を考えるなら必要
方針: 今回は OI で実測同化の流れを作る。次に精度と不確かさの扱いを上げるなら、KF ではなく EnKF または local EnKF を検討する。
