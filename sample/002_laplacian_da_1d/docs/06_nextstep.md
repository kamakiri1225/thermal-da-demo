# nextstep: 実測温度データを使ったOpenFOAM + OIデータ同化実験

## 目的

次の段階では、現在のツイン実験を実測データに置き換えます。

現在のプログラムでは、OpenFOAMで作った真値から疑似観測を作っています。

```text
現在:
  OpenFOAMで真値を作る
  その真値からセンサ観測を作る
  OIで同化する
  真値と比較する
```

次にやる実験では、丸棒を実際に加熱して温度を測定します。

```text
次:
  丸棒を加熱する
  実測温度を取得する
  一部の温度センサをOIに入力する
  残りの温度センサで推定結果を検証する
```

この実験で確認したいことは、

```text
少数の温度センサを使って、測っていない位置の温度をどの程度推定できるか
```

です。

## 実験の考え方

センサは2種類に分けます。

| 種類 | 用途 |
|---|---|
| 同化用センサ | OIに入力する温度データ |
| 検証用センサ | OIには入れず、推定結果が正しいか確認する温度データ |

重要なのは、検証用センサを同化に使わないことです。

検証用センサまで同化に入れてしまうと、答えを見ながら補正することになり、推定精度の確認になりません。

## 推奨する実験構成

最初は、できるだけ1次元熱伝導に近い条件にします。

```text
細長い丸棒
片端を加熱
側面からの放熱はなるべく一定
温度センサを4点程度配置
```

センサ配置の例です。

```text
加熱端                                                反対端
  |------------------------------------------------------|
  S1          S2             V1             V2
```

| センサ | 用途 |
|---|---|
| S1 | 同化用 |
| S2 | 同化用 |
| V1 | 検証用 |
| V2 | 検証用 |

まずは同化用2点、検証用2点が扱いやすいです。

## 準備するもの

### 実験装置

- 丸棒
- ヒータ、または加熱端を作れる装置
- 温度センサ4点以上
- データロガー
- 断熱材、または側面放熱をなるべく一定にする治具
- 室温を測るセンサ

### 測っておく物性・寸法

- 丸棒の長さ
- 丸棒の直径
- 材料
- 密度
- 比熱
- 熱伝導率
- 初期温度
- 室温
- 加熱条件

材料物性が不確かな場合は、文献値から始めてよいです。ただし、その不確かさがモデル誤差になります。

## 実験手順

### Step 1: 丸棒とセンサ位置を決める

丸棒の長さ方向を `x` とします。

各センサの位置を、加熱端からの距離で記録します。

```text
sensor_name, x_m, usage
S1, 0.03, assimilation
S2, 0.12, assimilation
V1, 0.20, validation
V2, 0.27, validation
```

`usage` は、同化に使うか検証に使うかを示します。

### Step 2: 実測温度を取得する

全センサの温度時系列を同じ時間刻みで保存します。

CSV形式の例です。

```text
time_s,S1,S2,V1,V2,ambient
0,20.1,20.1,20.0,20.0,20.0
10,20.8,20.2,20.1,20.0,20.0
20,21.6,20.5,20.1,20.0,20.0
```

最初は `DT = 10 s` 程度にそろえると、現在のプログラムと合わせやすいです。

### Step 3: OpenFOAMモデルを作る

OpenFOAM側では、丸棒を1次元に近い形でモデル化します。

最初の候補は2つあります。

| モデル | 特徴 |
|---|---|
| 1次元相当メッシュ | 現在のサンプルに近い。まず試すのに向く |
| 軸対称または3次元丸棒 | 実験に近いが、設定と計算コストが増える |

最初は1次元相当メッシュでよいです。

目的は、最初から完璧な実験再現をすることではなく、

```text
実測センサ値をOpenFOAM予測へ同化する流れを成立させること
```

です。

### Step 4: 境界条件を設定する

加熱端の境界条件は、実験装置に合わせて決めます。

候補は次です。

| 境界条件 | 使う場面 |
|---|---|
| fixedGradient | 熱流束や温度勾配として与えたい場合 |
| fixedValue | 加熱端温度を測っていて、その温度を直接与えたい場合 |
| codedFixedValueなど | 時間変化する境界条件を入れたい場合 |

最初は簡単にするため、加熱端を `fixedGradient` または時間変化する `fixedValue` として与えます。

側面放熱を入れる場合は、熱伝達率が必要になります。初回は側面断熱に近づけるか、放熱を単純化した条件から始めます。

### Step 5: 実測データをプログラムへ読み込む

現在の `da_main.py` は、真値から疑似観測を作っています。

```python
y = H @ truth_T[k] + np.random.randn(n_obs) * OBS_NOISE_STD
```

実験データを使う場合は、ここをCSVから読んだ同化用センサ値に置き換えます。

イメージです。

```python
y = measured_assimilation_values[k]
```

検証用センサは、同化には使いません。後で比較に使います。

### Step 6: センサ位置とOpenFOAMセルを対応させる

センサの実位置 `x_m` に最も近いOpenFOAMセルを探します。

```text
S1 -> cell 1
S2 -> cell 4
V1 -> cell 7
V2 -> cell 9
```

同化用センサだけで `H` を作ります。

検証用センサ位置は、RMSE計算と図の比較だけに使います。

### Step 7: OIで同化する

OIの式は現在と同じです。

$$
\mathbf{x}^a
=
\mathbf{x}^f
+
\mathbf{K}
\left(
\mathbf{y}
-
\mathbf{H}\mathbf{x}^f
\right)
$$

$$
\mathbf{K}
=
\mathbf{B}\mathbf{H}^T
\left(
\mathbf{H}\mathbf{B}\mathbf{H}^T
+
\mathbf{R}
\right)^{-1}
$$

実験データ版では、

```text
y = 実測された同化用センサ温度
```

になります。

### Step 8: 検証用センサと比較する

検証では、同化に使っていないセンサ位置の温度を比較します。

比較するものは次です。

| 比較対象 | 意味 |
|---|---|
| 実測 V1, V2 | 検証用センサの実測温度 |
| OpenFOAM only | 同化なし計算 |
| OpenFOAM + OI | 同化あり計算 |

見る指標は次です。

- RMSE
- 最大誤差
- 温度上昇の遅れ
- 冷却時の追従性
- 加熱端に近い場所と遠い場所での違い

## 実験データ用に必要なプログラム修正

現在のコードから実測対応へ進むには、次の修正を行います。

### 1. CSV読み込み関数を追加する

例です。

```python
def load_measurements(csv_path):
    data = np.genfromtxt(csv_path, delimiter=",", names=True)
    return data
```

### 2. 同化用センサと検証用センサを分ける

例です。

```python
ASSIM_SENSOR_NAMES = ["S1", "S2"]
VALID_SENSOR_NAMES = ["V1", "V2"]
```

### 3. 実測値から `y` を作る

例です。

```python
y = np.array([data[name][k] for name in ASSIM_SENSOR_NAMES])
```

### 4. 検証用センサのRMSEを計算する

例です。

```python
rmse_valid = sqrt(mean((measured_validation - estimated_validation)**2))
```

### 5. 結果図を実測比較用に変更する

必要な図は次です。

- 同化用センサの実測値と推定値
- 検証用センサの実測値と推定値
- DAなしとDAありのRMSE比較
- 誤差時系列

## 最初の実験で無理にやらないこと

初回から複雑にしすぎない方がよいです。

最初は避けたいことです。

- 3次元の複雑形状
- 側面放熱を詳細に同定すること
- 熱入力を完全に再現すること
- センサ数を増やしすぎること
- `B` を最初から高度に設計すること

まずは、

```text
実測値を読み込む
同化用センサで補正する
検証用センサで評価する
```

という流れを完成させます。

## 成功判定

最初の成功条件は、次のようにします。

```text
検証用センサに対して、
OpenFOAM only より OpenFOAM + OI のRMSEが小さくなる
```

たとえば、

```text
V1 RMSE:
  OpenFOAM only = 2.0 degC
  OpenFOAM + OI = 0.8 degC

V2 RMSE:
  OpenFOAM only = 1.4 degC
  OpenFOAM + OI = 0.7 degC
```

のようになれば、少数センサによって未観測点の推定が改善したと言えます。

逆に改善しない場合も重要です。その場合は、次を疑います。

- センサ配置が悪い
- `B` の相関長が合っていない
- OpenFOAMモデルの境界条件が実験と違いすぎる
- 側面放熱が無視できない
- センサの取り付け誤差や応答遅れがある

## 研究の問い

この実験で最終的に整理したい研究の問いは次です。

1. 少数の実測温度センサから、未測定点の温度をどこまで推定できるか
2. OIの背景誤差共分散 `B` をどう設計すれば、丸棒の熱伝導に対して自然な補正になるか
3. センサ位置は、推定精度にどれくらい影響するか
4. 温度場を直接補正する方法と、熱入力・境界条件を推定する方法では、どちらが実験に向いているか
5. OpenFOAMを改造せずに、実験データをどこまで解析へ反映できるか

この問いに答えるための第一歩として、まずは丸棒実験で

```text
同化用センサ2点 + 検証用センサ2点
```

の構成から始めるのがよいです。
