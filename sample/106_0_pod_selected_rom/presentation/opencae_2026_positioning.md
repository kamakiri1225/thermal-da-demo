# 本研究の位置づけと新規性 ― 工作機械の熱変位対策の中でどこにいるか

オープンCAE学会シンポジウム B-16（2026年11月12日）発表の、質疑応答用の整理。
作成日: 2026-09-30

> **先に結論**：本研究の個々の要素（POD-ROM、EnKF、感度によるセンサ配置）は
> **ほぼすべて既発表**です。純粋な新規性ではなく **「統合と、オープンソースでの再現可能な実証」**
> が性格です。発表でもそう述べるのが正確で、質疑にも耐えます。

---

## 1. 工作機械の熱変位対策の全体像

### 1-1. 対策は2系統に分かれる

```
熱変位（加工誤差の最大 75 %）
├── ① 回避（avoidance）… 熱を出さない・伝えない・対称にする
│     例：主軸冷却、対称構造、低膨張材、恒温室
│     → 設計段階の話。効くが、コストと限界がある
└── ② 補償（compensation）… 出た変位を予測して指令で打ち消す
      例：温度センサ＋モデル → NC座標をリアルタイム補正
      → 実務の主役。各社が実装済み
```

**本研究は ② 補償の系統**にあります。

### 1-2. 補償の中身は3ステップ

| ステップ | やること | 各社の実装 | 本研究 |
|---|---|---|---|
| **(i) 測る** | 温度を数点〜数十点 | 経験・勘で配置 | **どこを測るかを設計論にする** |
| **(ii) 推定する** | 温度 → 変位 | **経験式・回帰・機械学習** | **CAE（CHT＋FEM）＋データ同化** |
| **(iii) 補正する** | NC指令を動かす | 実装済み | 対象外（本研究では扱わない） |

各社の実装（オークマ TAS-C/TAS-S、マザック、DMG MORI、牧野）は
**(ii) を経験式や回帰で作っている**のが実情です（詳細は
[`opencae_2026_slide02_intro.md`](opencae_2026_slide02_intro.md) §3-3・§3-4）。

### 1-3. そこに何が足りないか

経験式・回帰には次の限界があります。

1. **機械ごとに実測データを取り直す必要がある**（新機種で作り直し）
2. **条件が学習範囲を外れると外れる**（外挿できない）
3. **なぜそうなるかが分からない**（物理の裏付けがない）
4. **温度が合っていても変位が合う保証がない** ― 本研究の課題①がまさにこれ

> **本研究の狙い：(ii) を物理モデル（CHT＋熱弾性）に置き換え、
> 足りない境界条件（発熱量・熱伝達率）は観測から推定してしまう。
> ついでに (i)「どこを測るか」も設計論にする。**

## 2. 研究の連番まとめ（101 → 106）

番号が進むほど新しく、前の成果を材料にしています。

| # | フォルダ | やったこと | 得られた結論 | 次への課題 |
|---|---|---|---|---|
| **101** | `101_0`, `101_1` | 箱形状でCHT＋輻射＋熱膨張の練習 | ソルバ連携の手順を確立 | 実形状でやる |
| **102** | `102_0`, `102_1` | **中空円筒の過渡CHT**（片側15 Wヒータ、0–300 s加熱）→ FrontISTRで熱膨張 | **温度・変形・面ごとの熱伝達率**を算出。これを双子実験の**真値**にする | 観測から逆に当てられるか |
| **103** | `103_0`, `103_1` | 温度だけの観測で **EnKF** と **粒子フィルタ** を比較 | EnKFは収束。**PFは退化**（有効サンプル数 1.02/400）＝高次元では使えない | 変位も観測に使えるか |
| **104** | `104_0` | **実ソルバ（OpenFOAM＋FrontISTR）を同化ループに入れる**。温度＋変位を観測 | 温度場RMSE **7.609 → 0.01064 K**、発熱量 **14.926 W**（真値15 W）。**ただし直列実行で約13時間** | 重すぎる。どこを測るかの基準もない |
| **105** | `105_0` | FrontISTRの感度行列 **$W=K_s^{-1}H_T$** で観測点を選ぶ | 同じ変位2点でも置き場所で **2.43 K → 0.86 K**。**上端ほど高感度、底面は固定で動かない** | 温度センサ側の基準は？ ROM化は？ |
| **106** | `106_0` | **POD＋Q-DEIMで代表5点を自動選定** → 集中定数ROMを校正 → EnKFで同化 | 2モードで**99.9 %**、校正残差**0.0142 K**、0→600 s が **31 ms**（実ソルバは分オーダー）。同化なし4.59 K → **0.147 K** | 実機・実測への適用 |

### 2-1. ストーリーとして一本にすると

```
102  正解（真値）を作った
  ↓  「観測から逆に当てられるか？」
103  EnKFなら当たる（PFは退化する）
  ↓  「温度だけでなく変位も使えるか？」
104  使える。ただし実ソルバは13時間かかる  ← 課題A：重い
  ↓  「どこを測ればよいのか？」
105  熱感度Wで決まる。置き場所で3倍違う     ← 課題B：基準がなかった
  ↓  「両方まとめて解決する」
106  POD+Q-DEIMで軽くし（31 ms）、観測の価値Δで配置を設計する
```

### 2-2. 106 で新たに確かめたこと（今回の発表の中身）

| 確認項目 | 結果 | 根拠 |
|---|---|---|
| 5点から全場を復元できるか | 未観測20,691セルで **0.00081 K**（訓練外でも0.0023 K） | `run/recon_unobserved_check.py` |
| 校正に使っていない点でも合うか | 校正5点0.0142 K に対し **それ以外0.0130 K**（過学習していない） | `run/rom_unrelated_points_check.py` |
| 点の選び方は本当に効くか | Q-DEIM 0.00081 K vs **ランダム最悪 1.396 K（1,724倍）**。条件数と誤差の相関 **+0.917** | `run/make_pod_to_points_fig.py` |
| 観測していない方向・場所は直るか | $U_z$ しか測っていないのに **$U_x$ も直る**（未観測点で126倍） | `run/eval_xyz_disp_da.py` |
| 発熱量は同定できるか | **できる**（14.88 W／真値15 W） | `run/run_da_compare.py` |
| 熱伝達率は同定できるか | **できない**。応答0.049 K < ノイズ0.30 K の**可同定性の問題** | `results/h_sensitivity_check.json` |

## 3. 先行研究に対する優位性 ― 正直な評価

### 3-1. まず「既にあるもの」を認める

| 要素 | 既発表か | 代表例 |
|---|---|---|
| ROMで工作機械の熱変位を推定 | **既発表** | Teshima et al. 2024（CIRP JMST 55, 403–410） |
| ROMの感度分布でセンサ配置を決める | **既発表** | Ando et al. ICTIMT2025 |
| 変位・ひずみから温度場を逆推定 | **既発表** | ScienceDirect 2025（随伴法） |
| カルマンフィルタで熱変位補正 | **既発表** | ScienceDirect 2024（線形KF／オブザーバ） |
| OpenFOAM×EnKF の結合 | **既発表** | CONESフレームワーク等 |
| POD＋Q-DEIM（gappy-POD） | **既発表**（流体分野で広く使われる） | Drmač & Gugercin 2016 |

> **この領域は競争が激しく、「初めて」と言える部分はほとんどありません。**
> 主張を盛ると質疑で崩れます。

### 3-2. それでも差分と言える3点

| # | 差分 | なぜ差分か | 弱み（正直に） |
|---|---|---|---|
| **A** | **EnKF（アンサンブル）で、高忠実CHT＋FEMを非線形観測演算子としてループに入れた** | 先行は**線形KF／オブザーバ／随伴法**が主。アンサンブルなら随伴コードを書かずに済み、非線形のまま扱える | 計算コストが高い（104で13時間）。ROM化で回避したが、ROMは訓練条件依存 |
| **B** | **発熱量 $Q$ と放熱 $h$ を温度場と同時に推定**（joint state–parameter estimation） | 先行は温度を**入力として与える**か、場の復元だけ。**境界条件そのものを観測から決める**角度は薄い | $h$ は同定できなかった（可同定性の限界を実証した、とも言える） |
| **C** | **観測の価値 $\Delta=\mathrm{Cov}(X,y)^2/(\mathrm{Var}(y)+r)$ で、温度と変位を同じ尺度で比較** | 先行は温度センサ配置が主流。**変位ゲージ側の選定**と、**推定対象ごとに最適が変わる**ことの定量化 | 線形ガウス仮定。大域最適の証明ではなく候補内比較 |

### 3-3. 最も近い先行研究との比較表

（東京大学 木崎研 / Teshima・Ando ら）

| | Teshima / Ando ら | **本研究** |
|---|---|---|
| ROMの作り方 | 温度→TCP変位の**伝達関数・回帰** | **POD＋Q-DEIM**で代表点を選び集中定数ROMを校正 |
| 配置の基準 | **温度感度分布**（伝達関数から） | **観測の価値 $\Delta$**（＝相互情報量）。**推定対象ごとに変わる** |
| 未知パラメータ | 扱わない（温度は入力） | **$Q$・$h$ を状態に入れて同時推定** |
| 観測の種類 | 温度センサ | **温度＋変位**を同じ枠組みで |
| 実装 | ― | **OSSのみ**（OpenFOAM＋FrontISTR＋Python）で全公開 |

### 3-4. 実務・CAEコミュニティに対する優位性

学術的新規性とは別に、**オープンCAEの聴衆に対しては**こちらのほうが効きます。

1. **商用ソルバなしで一気通貫できることを示した**
   CHT → 節点補間 → 熱弾性 → データ同化 → ROM が、OpenFOAM＋FrontISTR＋Python だけで回る
2. **全部公開してある**（コード・データ・解説記事5本・スライド）
   <https://github.com/kamakiri1225/thermal-da-demo>
3. **失敗も書いてある**
   $h$ が同定できないこと、OIでは $Q$ が9 W止まりになること、
   ランダムに5点選ぶと最悪1.4 Kまで崩れること ― 追試できる形で残している
4. **「どこを測るか」を実務の設計手順に落とした**（105 の `docs/03_sensor_design_guide.md`）

## 4. 発表で言ってよいこと／言ってはいけないこと

### 言ってよい

- 「**OSSだけで、CHTから熱変形・データ同化・ROMまで一気通貫で構築した**」
- 「**境界条件（発熱量）を観測から推定できることを示した**」
- 「**観測の価値を1本の式で定義し、推定対象ごとに最適な観測が変わることを定量化した**」
- 「**熱伝達率は、この条件では同定できないことを定量的に示した**」（負の結果も成果）

### 言ってはいけない

- ❌「ROMでセンサ配置を決めるのは本研究が初めて」→ **Teshima/Ando らが先行**
- ❌「データ同化を熱変位に使ったのは初めて」→ **2024年に線形KFの例がある**
- ❌「この手法が最適である」→ **候補内比較であり大域最適の証明ではない**
- ❌「実機で有効」→ **双子実験であり、実測データでの検証は未実施**

## 5. 想定質問への短い答え

| 質問 | 答え |
|---|---|
| 「先行研究と何が違うのか」 | ①EnKFで高忠実CHT/FEMをループに入れた ②境界条件を同時推定した ③温度と変位を同じ価値尺度で比べた ― の3点。要素自体は既発表で、**統合と公開が主な貢献**です |
| 「実機で使えるのか」 | 今回は双子実験です。実機適用には実測データでの検証と、形状ごとのROM再構築が必要です |
| 「商用ツールでも同じことができるのでは」 | できます。本研究の主張は手法の独自性より **OSSで再現可能な形にしたこと** です |
| 「$h$ が当たらないのは失敗では」 | この条件では $h$ の応答（0.049 K）が観測ノイズ（0.30 K）に埋もれるためで、**フィルタの問題ではなく可同定性の問題**です。事前に感度を計算すれば実験前に分かります |
| 「なぜ $z$ 方向だけなのか」 | 注目量を上面の反りに絞ったためです。$U_x$ も同程度動きますが、**観測しなくても同化で直る**ことは確認しました（結果③-2） |
