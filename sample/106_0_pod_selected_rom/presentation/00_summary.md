# オープンCAE学会 B-16 発表内容の整理（まずこれを読む）

更新日: 2026-10-02 ／ 発表: 2026年11月12日（木） ／ スライド: [`01_slides.html`](01_slides.html)（公開版 <https://kamakiri1225.github.io/thermal-da-demo/opencae2026.html>）

## 一言でいうと

**オープンソース（OpenFOAM＋FrontISTR＋Python）だけで、少ない温度センサと変位センサから、測っていない場所の温度と熱変形を推定する仕組みを作った。センサをどこに置けばよいかも、測る前に計算で決められる。**

## 発表の流れ（スライドの7章）

### 1. 背景

- 工作機械の熱変形は加工精度を悪くする。解析だけでは、境界条件などが不確かで合わない。
- そこで、測定値で計算を補正する「データ同化」を使う。

### 2. 作ったもの

- 題材：片側にヒータ（15 W）が付いた中空円筒。
- 流れ：OpenFOAM で温度を計算 → FrontISTR で熱変形を計算 → 同化で補正。
- 同化の中身（センサの読みから数式まで）：[blog_006](../docs/blog_006_temp2_disp2_step_by_step.md)
- 真値は計算で作った模擬データ（双子実験）。

### 3. 課題

- OI（簡易な同化）では発熱量が当たらない。
- EnKF なら当たるが、計算が重い。

### 4. 解決：計算を軽くする

- POD と Q-DEIM で代表点を5点選び、小さなモデル（ROM）を作った。
- 600 秒の計算が 31 ms で終わる。

### 5. 結果（何ができたか）

| できたこと | 数値 | 詳しい説明 |
|---|---|---|
| 温度を合わせる | 同化なし 4.6 K → 温度2点＋変位2点 **0.16 K** | [blog_004 §7-6](../docs/blog_004_pod_selected_rom.md) |
| 発熱量を当てる | 真値 15 W → **14.9 W** | [blog_003 §4-0](../docs/blog_003_ensemble_kalman_filter.md) |
| 測っていない場所の反りを当てる | 中段（B/C）だけ測って、上面（A/O）の反りを誤差 **0.08 µm** | [blog_004 §7-4b](../docs/blog_004_pod_selected_rom.md) |
| 測っていない方向の変位も直る | 横方向 Ux も **126 倍**改善 | [blog_004 §7-5](../docs/blog_004_pod_selected_rom.md) |
| 変位計だけでも同化できる | 温度センサなしで **0.21 K** | [blog_004 §7-4c](../docs/blog_004_pod_selected_rom.md) |

### 6. センサの置き場所

- 変位センサは、熱感度 $W$ の大きい点（よく動く上面）に置く。
- 温度センサは、 $W$ の大きい点に置けばよいわけではない。**A 側と O 側に分けて置く。**
- 置き場所は、 $W$ と ROM から**測る前に計算で選べる**。予測した順位と、実際に同化した結果の順位はほぼ一致した（順位相関 0.98）。

詳しい説明：[blog_005 §4-6](../docs/blog_005_optimal_sensor_placement.md)

### 7. 限界（正直に言うこと）

- 真値はすべて計算で作った模擬データ。実機でも、実ソルバ（OpenFOAM＋FrontISTR）を真値にした試験でもない。
- 放熱係数 $h$ は、600 秒の計算では当たらない。
- 熱源の位置が変わると、選んだ置き場所も変わる。
- 加熱のしかた（いつ発熱するか）がモデルの仮定と違うと、同化は合わない（間欠加熱で確認）。

## 熱感度 $W$ の使い方

熱感度 $W$ は「温度が 1 K 変わると、どこが何 µm 動くか」を表す表で、FrontISTR で計算する。

| 使い方 | $W$ の使い方 |
|---|---|
| 変位センサの置き場所 | $W$ が大きい点に置く |
| 温度センサの置き場所 | $W$ を重みにして、温度のばらつきと組み合わせて計算で選ぶ |
| 同化の中 | 温度から変位を計算する変換として使う |

## 追加検証の結果（2026-10-03）

詳しくは [docs/21_advantage_verification.md](../docs/21_advantage_verification.md)。真値は OpenFOAM＋FrontISTR の計算結果。

| 確かめたこと | 結果 |
|---|---|
| 学習していない発熱量（25 W） | 同化は合う。温度場 0.14〜0.18 K、反り 0.15〜0.28 µm、発熱量も 24.9〜25.1 W と推定 |
| 従来の回帰補正との比較（25 W、温度 P2＋P4） | 同化（温度2点＋変位2点）0.10 µm、回帰式 0.29 µm。**同化が約3倍正確** |
| 学習していない加熱のしかた（間欠加熱） | **同化は合わない**（反り 0.9 µm）。回帰式（0.3 µm）より悪い。ROM が「0〜300 秒に一定の発熱」と仮定しているため |
| 変位計が発熱量の推定を主に担うか | **違った**。発熱量を真値に近づけたのは主に温度センサ |

## 主張できること／できないこと

| 主張できる | 主張しない |
|---|---|
| オープンソースだけで解析から同化まで一通りつないだ | 実機で精度が出ること |
| 測っていない場所の熱変形を推定できた（模擬データで） | センサの置き方の理論が新しいこと（先行研究がある） |
| 加熱のしかたが分かっていれば、学習していない発熱量でも従来の回帰補正より約3倍正確（実ソルバ真値） | どんな運転条件でも回帰補正より良いこと（間欠加熱では悪かった） |
| センサの置き場所を測る前に計算で選べた（この条件で） | どんな機械にも通用すること |

## 一つだけ決めること（未決定）

5章の主な数値（0.16 K）は、温度センサを**片側（P2＋P0）**に置いた計算の結果。

- **そのまま発表する**：「片側に置いた結果。両側に置けばさらに良くなる見込み」と説明する。
- **計算し直す**：両側（P2＋P4）で計算し、数値を差し替える。

どちらでも発表は成り立つ。
