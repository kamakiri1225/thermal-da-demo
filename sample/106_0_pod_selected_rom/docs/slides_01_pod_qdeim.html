1. POD ― スナップショット行列 §1.1

各時刻の全セル温度を縦ベクトルにし、時間方向に並べる（$N$=セル数, $m$=時刻数）:

$$X=\big[\,u(t_1)-\bar u,\ \dots,\ u(t_m)-\bar u\,\big]\in\mathbb{R}^{N\times m},\qquad \bar u=\frac1m\sum_k u(t_k)$$

  • $u(t_k)$ … その時刻の温度場まるごと（1列＝全セル分, 長さ $N$）
  • $\bar u$ … 平均場。全体で1つの数ではなく、セルごとの時間平均を並べた縦ベクトル
  • $u(t_k)-\bar u$ … 同じセルどうしの引き算（各セルから、そのセルの時間平均を引く）

「平均場を場所ごとに引く」を具体例で §1.1b

各列は「その時刻に各場所が自分の平均からどれだけ上下したか」。POD はこの変動表から 共通の型を取り出す。コードでは X - mean[:,None]（mean=X.mean(axis=1)＝行ごと＝場所ごとの時間平均）。

最適な型を求める変分問題 §1.2

場を1つの型 $\varphi$（$\|\varphi\|=1$）で最もよく表す＝$\varphi$ 方向成分の二乗和を最大化:

$$\max_{\|\varphi\|=1}\ \sum_{k=1}^{m}\big|\varphi^\top (u(t_k)-\bar u)\big|^2 =\max_{\|\varphi\|=1}\ \varphi^\top \big(XX^\top\big)\varphi$$

ラグランジュ未定乗数で微分してゼロ → 固有値問題になる:

$$ (XX^\top)\,\varphi=\lambda\,\varphi $$

  • 固有ベクトル $\varphi_k$ ＝ PODモード（型）
  • 固有値 $\lambda_k=\sigma_k^2$ ＝ その型のエネルギー（大きいほど支配的）
  • $C=XX^\top$ ＝ 空間相関行列（$N\times N$）

SVD との同値（実際の計算法） §1.3

$X$ を特異値分解 $X=U\Sigma V^\top$ すると

$$XX^\top=U\Sigma V^\top V\Sigma U^\top=U\,\Sigma^2\,U^\top$$

よって $U$ の各列がそのまま $C=XX^\top$ の固有ベクトル＝PODモード、$\sigma_k^2$ が固有値。
巨大な $C$（$20696^2$）を作らず、SVD 一発で POD が得られる。

なぜ「最良」で、なぜ「速い」か §1.4–1.5

Eckart–Young の定理（最良性）

上位 $r$ モード打ち切り $X_r=\sum_{k=1}^r\sigma_k u_k v_k^\top$ は、 ランク $r$ の全行列の中でフロベニウス誤差 $\|X-X_r\|_F$ を最小にする。 ＝「POD は最もエネルギー効率の良いモード分解」。

スナップショット法（高速化）

空間 $N \gg$ 時間 $m$（20696 ≫ 121）なので、小さい $m\times m$ の $X^\top X$ を解けばよい:

$$X^\top X\,v_k=\sigma_k^2 v_k,\qquad \varphi_k=\frac{1}{\sigma_k}X v_k$$

economy SVD（full_matrices=False）が実質これを行う。

2. POD の実装 §2


# ① スナップショット行列 X (N=20696セル × m=121時刻)
ts, C, X = load_snapshots()          # OpenFOAMの各時刻 solid/T を読む

# ② 平均を引く（変動成分だけ見る）
mean = X.mean(axis=1)
Xc   = X - mean[:, None]

# ③ SVD（＝PODモード抽出）
U, S, Vt = np.linalg.svd(Xc, full_matrices=False)   # U:(N,m) S:(m,) Vt:(m,m)

# ④ 各モードのエネルギー比と累積
energy = S**2 / (S**2).sum()
cum    = np.cumsum(energy)           # 何モードで何%説明できるか

本ケースの結果：1モードで 91.8%、2モードで 99.9%（＝場は実質2〜3自由度）。

3. Q-DEIM ― 狙い §3.1

$r$ 個の点 $P$ の温度だけから、PODモードで全場を復元したい（gappy 再構成 / DEIM 補間）:

$$\hat u=\bar u+U_r\,a,\qquad a=\big(U_r[P,:]\big)^{+}\big(u[P]-\bar u[P]\big)$$

$U_r[P,:]$ ＝「モード行列の、選んだ点の行だけ」を抜いた $r\times r$ 行列。

復元が安定なのは $U_r[P,:]$ が良条件（可逆・条件数が小さい）なとき。
だから「$U_r[P,:]$ の条件数を小さくする点集合 $P$」を選ぶ ＝ Q-DEIM。

Q-DEIM ― 列枢軸QR §3.2

モード行列の転置 $U_r^\top$ に列枢軸付きQR分解をかけ、最初の $r$ 個の枢軸列（＝行）を補間点にする:


from scipy.linalg import qr
# 先頭 r モード U[:, :r] の転置に列枢軸QR
_, _, piv = qr(U[:, :r].T, pivoting=True)   # piv: 重要な行(=点)の順
points = list(piv[:r])                       # 最初の r 個が代表点(セル番号)
coords = C[points]                           # その点の座標

枢軸QRは「互いに最も独立な（張る空間が大きい）行を順に選ぶ」ので、 モードを最もよく分離できる点＝場を最もよく覆う点が出る。 これが「勘」ではなくデータから系統的に選ぶの中身。

4. ROM ― 一般化集中定数モデル §4.1

任意配置の $n$ 点をノードとし、全点対をコンダクタンスで結ぶ:

$$C_i\frac{dT_i}{dt}=\sum_{j\ne i}K_{ij}(T_j-T_i)+q_i(t)-h\,(T_i-T_\text{air})$$

  • $K_{ij}$：ノード間コンダクタンス [W/K]（対称・全点対、$n{=}5$ なら 10本）
  • $q_i$：ヒータ発熱（ヒータ最近傍ノード P2 に投入）
  • $h$：放熱係数 [W/K]

行列形 $\dot{\mathbf T}=M\mathbf T+\mathbf b$ になり、RK4 で一括前進積分できる。

ROM ― 校正（$C,K,h$ を実データに合わせる） §4.2


def resid(vec):                       # vec = [C(5), K上三角(10), h(1)] = 16未知
    C = vec[:5]; K = tri_to_matrix(vec[5:15], 5); h = vec[15]
    Ymodel = integrate_rom(C, K, h)   # ROMを前進積分して5点温度履歴を作る
    return (Ymodel - Yobs).ravel()    # OpenFOAMとの差

sol = least_squares(resid, x0, bounds=(lb, ub))

選んだ5点の OpenFOAM温度履歴を目標に、$C[5],K[10],h$ を最小二乗で同定。
