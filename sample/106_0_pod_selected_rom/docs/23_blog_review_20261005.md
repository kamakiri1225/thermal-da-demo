## 感度からどこまで証明したか

[blog_005 §1-2](blog_005_optimal_sensor_placement.md)を参照。

- Qだけが未知、他条件既知、局所線形・ガウス・同じ事前分布なら、Q感度のノイズ規格化二乗和が最大の点が事後分散を最小にする。
- Q/hが同時に未知なら、感度の大きさだけでなく、影響を区別する方向の情報が必要。比例した感度の反例を示した。
- 未観測変位差なら、その変位差と候補観測の共分散から事後分散を評価する。W最大点が常に最適ではない。
- これらは設定した線形化モデルの最適性で、有限メンバーEnKFの最終誤差を無条件に証明するものではない。実験結果による確認を併用する。
