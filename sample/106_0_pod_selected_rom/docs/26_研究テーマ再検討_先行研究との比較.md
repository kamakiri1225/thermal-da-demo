## 1. 依頼と前提

### 1-1. 何を調べたか

ユーザーは、2026-11-12 のオープンCAEシンポジウム（B35「データ同化による温度・変位推定」）で、次の研究を発表する予定である。

- **題材**：片側だけを加熱する中空円筒。工作機械を想定した**数値実験**で、実機では確かめていない。
- **正解（真値）**：OpenFOAM の流体‐固体連成伝熱（CHT）で温度場を計算し、その温度場を FrontISTR の熱弾性解析に入れて変位を出したもの。
- **軽いモデル（ROM）**：POD と Q-DEIM で「代表 5 点」を選び、その 5 点を結んだ熱回路を作る。熱回路の係数（熱容量 C、熱コンダクタンス K、放熱 h）は OpenFOAM の結果に最小二乗で合わせる。600 秒分を 31 ms で計算できる。
- **データ同化**：ROM の上で EnKF（60 メンバー）を回す。状態は「5 点の温度＋発熱倍率 q＋放熱 h」。観測は温度 2 点と変位 2 点。
- **主な結果**（真値＝OpenFOAM＋FrontISTR、15 W・25 W・間欠加熱の 3 条件）
  - 一度も測らない 2 点 A と O の「反り」（上下変位の差 A−O）の誤差は 0.076 µm。A・O を直接測った場合は 0.137 µm、温度 2 点だけの場合は 0.775 µm。
  - 測っていない場所を含む全セルの温度 RMSE は 0.12〜0.14 K（温度 2 点だけなら 0.53〜0.88 K）。
- **変位計の置き場所**：反りの事後標準偏差が最小になる場所を、1 本ずつ貪欲に追加して選ぶ（「目的指向」の選び方）。代表 5 点の温度共分散を小さくする A 最適（0.089 µm）や D 最適（0.108 µm）より良かった（差は 8〜15%）。
- **分かっている弱点**：放熱 h は 600 秒では同定できない。熱源の位置が変わると ROM を作り直す必要がある。ROM の熱コンダクタンスは一意に決まらない。実機での検証がない。学習に使った計算は 1 本だけ。

> **数値の注意**：A 最適・D 最適との比較の値は資料によって少し違う。依頼文では「0.089 / 0.108 µm、差 8〜15%」、[blog_008 §7-6](blog_008_novelty_displacement_assimilation.md#7-6-同じ試験にかけた結果) の表では 15 W のとき「目的指向 0.075、A 最適 0.090、D 最適 0.108 µm、差 15〜20%」となっている。どの条件・seed で平均したかの違いと考えられるが、この文書では確認していない。発表前にどちらか一方にそろえる必要がある。

ユーザーは、Siemens の Simcenter 3D Smart Virtual Sensing（縮約 FEM＋カルマンフィルタ＋実測で、応力・ひずみ・変位を実時間で推定する製品）と、工作機械の熱変位についての近い先行研究 2 本（[論文 A](https://doi.org/10.1016/j.mfglet.2024.09.025)・B）を見つけた。さらに Siemens 関係者の論文 2 本を追加で提供した。この文書では次の 5 点を調べた。

1. 先行研究の整理（論文 A・B を最優先、Siemens も同じ観点で）
2. まだ解かれていない課題と、関連文献の有無
3. 研究テーマの案（4 つ）
4. 最小限の検証計画
5. 批判的な評価と結論（特に、11/12 の発表の主張が論文 A・B とどこで重なり、どこで違うか。Siemens が参入した場合に何が残るか）

## 2. 先行研究の整理

### 2-1. 論文 A：温度センサ＋普通のカルマンフィルタで熱状態を推定する（2024）

**何をしたか。** ETH Zurich（とスピンオフ企業 inspire AG）は、工作機械全体の有限要素モデルを縮約し、そこに通常の（線形の）カルマンフィルタを組み合わせて、少数の温度センサから全体の温度場を推定した。推定した温度場を熱弾性モデルに入れて、工具と工作物の相対変位（熱変位）を計算する。**学習データ（実測で合わせた係数）を一切使わない**ことを利点としている。

**本文で確かめたこと**

| 項目 | 内容（節番号） |
|---|---|
| モデル | ANSYS で作った FE メッシュを、ソフト MORe で状態空間モデルに変換（§2.1）。熱は $`E\dot x=Ax+Bu`$、変位は $`y_{\rm mech}=C_iK^{-1}K_{\rm th}x`$（式 1、2） |
| 縮約 | **Krylov Modal Subspace（KMS）**。5 軸機は 353,169 節点を 214 モードに、試験台は 208,941 節点を 56 モードに（表 1） |
| 熱入力 | **$`u=0`$ とする**。「熱入力の知識は仮定しない」「実生産で熱入力を測るのは非常に難しい」と明記（§2.1）。熱入力の分はプロセスノイズで吸収する考え方 |
| 物性・境界条件 | 物性値と表面の熱伝達率は**一定と仮定**（§2.1）。気流による熱伝達率の変化などは、プロセスノイズに含まれるとしている（§3.5） |
| フィルタ | 離散時間の線形カルマンフィルタ（式 3〜9）。可観測性と安定化可能性を確かめ、リッカチ方程式の定常解に収束することを述べる（§3.4） |
| ノイズの決め方 | プロセスノイズ $`Q`$ は ROM のシミュレーション結果とその低域通過から推定。観測ノイズ $`R`$ はセンサの計測不確かさから（§3.5） |
| **観測（更新に使う量）** | **温度のみ**。図 1 の構成図で、フィルタに入るのは「Temperature sensor measurements」だけ。選ばなかった温度センサは検証用に残す（§3.3） |
| **変位の扱い** | 推定した温度から計算する**出力**。試験台では Heidenhain の変位計 5 本（ISO 230-3 の配置）、5 軸機ではタッチプローブの R-Test で測り、**検証にだけ使う**（§4.1、§4.2） |
| センサの選び方 | 観測行列 $`C`$ の行を z スコアで正規化し、k-means でクラスタ分けして各クラスタの代表を選ぶ（§2.3）。目的（熱変位）は使っていない |
| CFD | **使っていない**（記述なし） |
| 実験 | アルミ製 C フレーム試験台（ヒータマット 65 W×4、各 6 時間加熱＋10 時間冷却、約 80 時間）と、Mori Seiki NMV5000 DCG（約 150 時間、軸移動・主軸回転のランダムな負荷） |
| 結果 | 未観測の温度センサの RMSE は試験台 2.7 ℃（24 本）、5 軸機 1.3 ℃（12 本）。試験台の熱変位 RMSE は 67.4 → 33.3 µm（52.7% 減）。方向別では Z が 62.1% 減だが、Y down は −14.6%（悪化）（表 2） |
| 著者が挙げた課題 | 5 軸機ではボールねじなど動く部品に温度センサを付けられず、**完全には可観測でない**（§2.3、§5.2）。右側ヒータの取り付けの隙間（接触の悪さ）がモデルにないことが誤差の原因（§5.1）。今後は「熱伝達率を可変パラメータにする」「最適なセンサ配置」「制御装置のデータを仮想センサに使う」「境界条件の効率的なパラメータ化」（§5.2、§6） |

**読めなかったこと・注意。** 計算時間の数値は本文にない（「実時間で計算できる」とだけある）。

### 2-2. 論文 B：境界条件の違う 500 個のモデルに、それぞれカルマンフィルタをかけて重み付けする（2026）

**何をしたか。** [論文 A](https://doi.org/10.1016/j.mfglet.2024.09.025) の弱点（熱伝達率などの境界条件を一定と仮定した 1 個のモデル）を補うため、境界条件を変えた ROM を 500 個用意し、**ROM ごとに別々の（普通の）カルマンフィルタ**を走らせる。各 ROM の「予測と観測の合い具合」（尤度）から重みを決め、重み付きで出力を合成する。題名と抄録では「enhanced ensemble Kalman filter」と呼んでいるが、**中身は通常の EnKF（1 つのモデルの状態を乱数メンバーで表す方法）ではなく、複数モデルのフィルタを並べて重み付けする方法**である（下の表の §4.4〜4.5 の記述からの、この文書の解釈）。

**本文（Springer のオープンアクセス版）で確かめたこと**

| 項目 | 内容（節番号） |
|---|---|
| モデル | ANSYS のメッシュを MORe で状態空間化（§3.1）。熱弾性の連成は論文 A と同じ $`C_{\rm mech}K^{-1}K_{\rm th}`$ |
| 縮約 | KMS。圧縮率は約 1849 倍、時間刻み Δt=10 s、行列指数関数で厳密に離散化（§3.1、§3.3） |
| アンサンブルの作り方 | **ラテン超方格サンプリングで 500 個の ROM**（§3.2）。変えたのは、外面と作業空間の熱伝達率、アルミ管内面の熱伝達率、金属どうしの接合部の**接触熱コンダクタンス**。ベースプレートは無限大の熱溜めにつなぐ |
| 熱入力 | **既知として与える**。ヒータの公称の熱流を入力 $`u`$ に入れる（「実験の熱入力に設定」）。熱入力を測らずにプロセスノイズで吸収する方法は「別案」として触れるだけ |
| フィルタ | ROM ごとに独立の線形カルマンフィルタ（§4.1〜4.3、式 10、11）。$`Q`$・$`R`$ は対角で全モデル共通 |
| 重み | ガウス尤度 $`L(f\mid z)\propto p(z\mid f)p(f)`$、事前は一様 $`1/F`$、毎ステップ正規化（§4.4、式 12〜14）。ROM ごとに縮約基底が違うので、状態ではなく**観測の空間で合成**（§4.5、式 15〜20）。上位 N 個の選び方を 3 通り比較 |
| **観測（更新に使う量）** | **温度のみ**。式 (9) $`z_{\rm obs}[k]=C_{{\rm obs},f}x_f[k]+w_f[k]`$ の $`z`$ は「観測したセンサの温度」と明記。変位計 5 本（X up/down、Y up/down、Z）は**検証にだけ使い、フィルタの式には入らない** |
| **未知パラメータの扱い** | 熱伝達率・接触熱コンダクタンスは、**オフラインで作った 500 通りの中から重みで選ぶだけ**で、オンラインで値を連続的に直すことはしない。著者自身が「カルマンフィルタに応じてサンプリング空間を実時間で動かす」ことを今後の課題に挙げている |
| CFD の利用 | **パラメータの上下限を決めるためだけ**。「実験データと大規模な CFD 計算をもとに上下限を決めた」「密閉した箱の中は自然対流だけと仮定」（§3.2）。CFD と熱伝導の連成や、OpenFOAM の記述はない |
| センサの選び方 | 離散リアプノフ方程式の可観測性グラミアンの**最小固有値の、全モデルでの平均を最大化**。遺伝的アルゴリズムが貪欲法や PSO より良く、温度センサを 40 本中 10 本選ぶ（§3.4）。**目的（熱変位）は使っていない** |
| 実験 | 論文 A と同系統の C フレーム試験台（温度センサ 40 本、変位計 5 本）。70 時間の測定（ヒータを順に入れ、最後に同時に入れる） |
| 結果 | 最良モデルで温度 RMSE 1.5 ℃（論文中で「従来 2.7 ℃」と比較）。上位 N≒15 個で温度 RMSE が最小。変位 RMSE は「多くの場合 70% 以上減」。熱変位の低減率は抄録では「一貫して 70% 超」、結論では「約 61〜82%」 |
| 計算時間 | 500 個のフィルタで 70 時間分を約 1.6 時間（Intel Core i7-13700K）。抄録は「実時間の 45 倍超」、本文は「約 47 倍」 |
| 著者が挙げた課題 | X 方向の変位を合わせきれない。試験台の緩い接触がモデルでは一体の鋼になっている。ヒータ付近の熱流を過大評価している疑い。今後は「モデル選択と境界条件サンプリングのフィードバック」「**機械的な挙動を考えたセンサ選択**」「**熱入力とプロセスノイズの実時間の適応推定**」「機種・現場への拡張」 |

**読めなかったこと・注意**

- 表 2（パラメータの上下限）と表 3（上位モデルの値）は取得できなかった。熱伝達率・接触熱コンダクタンスの具体的な値は分からない。
- 「上位 N 個を、全期間の平均重みで選ぶ」方式は、未来のデータまで使って選んでいるように読める。厳密なオンライン推定かどうかは本文の再確認が必要である（この文書の解釈）。
- 低減率の表記（70% 超と 61〜82%）、速度倍率（45 倍と 47 倍、1.6 時間からの計算では約 44 倍）が本文中で一致していない。引用するときは数値の出典の節を明記する。
- 要約機能を通した読み取りなので、引用する前に原文 PDF を手元で確認すること。

### 2-3. Siemens Simcenter 3D Smart Virtual Sensing と、その元になった論文

**製品の考え方。** Siemens の Smart Virtual Sensing は、構造の有限要素モデルを縮約し、それを「拡張カルマンフィルタ（Augmented Kalman Filter, AKF）」で包んで、少数のひずみゲージなどの実測から、測れない場所のひずみ・応力・変位と、**未知の入力荷重**を同時に推定する。荷重は「ランダムウォーク」（前の時刻の値＋小さな乱数）として状態ベクトルに加える。縮約モデルと推定器をまとめて FMU 形式の「実行可能なデジタルツイン（xDT）」として書き出し、試験ソフト（Testlab）で実時間に動かせる。

ここでいう AKF は「状態ベクトルを未知量で拡張したカルマンフィルタ」のことで、EnKF のようなアンサンブルは使わない。本研究の EnKF も「状態＝温度＋q＋h」と拡張しているので、**状態を未知量で拡張する発想そのものは Siemens と同じ**である。

**ユーザー提供の 2 本と、熱を扱う Siemens 関係の論文 1 本を本文で読んだ。**

**ここから言えること（この文書の判断）**

- Siemens は、**構造**では「縮約 FEM＋AKF＋未知荷重の推定＋センサの種類まで含めた配置設計＋実時間の xDT」を製品にしている。ひずみ・変位を観測に使うのは、構造の仮想センシングでは標準である。
- **熱**では、2025 年の時点で「Flotherm の熱 ROM＋AKF で熱伝達率と発熱を推定＋配置設計」を研究段階で発表している。つまり「CFD 系の熱解析ソフトから作った熱 ROM」「熱伝達率・発熱のオンライン推定」「パラメータの事後共分散による配置」は、Siemens 側に既にある。
- **熱と構造をつなぐ（温度から熱変形を出し、変位の観測で温度・発熱を直す）**例は、今回読んだ Siemens の資料には見つからなかった。ただし 2022 年の時点で「マルチフィジックスへの拡張」を明言しており、材料（熱 ROM と構造 ROM と AKF と配置設計）はそろっている。

## 4. 研究テーマの案

以下の 4 案は、どれも「今ある OpenFOAM＋FrontISTR＋ROM＋EnKF の仕組み」を使える。新規性の見込みは、§2・§3 で見つかった文献を踏まえた**率直な見込み**であり、保証ではない。

### 案 1：温度と変位を混ぜた観測で、測れない相対変位を当てる ― 混合センサの配置設計と逐次同化（今の研究の延長）

**内容。** 温度計と変位計（向きを含む）を同じ候補の集合に入れ、「測らない相対変位（工具‐工作物を想定した A−O）」の事後分散を目的に、固定のセンサ予算（例：合計 4 本）の中で**何を何本どこに置くか**を選ぶ。選んだ配置を逐次同化（EnKF）で確かめる。

| 観点 | 内容 |
|---|---|
| 先行研究との具体的な差 | Herzog 系列（§2-4）は目的（TCP 変位）を指定するが、**候補は温度センサだけ**で、推定は移動ホライズンの最小二乗。Siemens は種類も選ぶが、**構造の荷重推定**で、目的は荷重。[論文 A](https://doi.org/10.1016/j.mfglet.2024.09.025)・B は温度だけで、目的を使わない。本案は「温度計か変位計か」を同じ尺度で比べ、熱の逐次同化で確かめる |
| 新規性の見込み | **狭いが、残っている可能性がある**。ただし SFB/TR 96 第 III 期が同じ方向（温度に変位・ひずみを加える）を目標に掲げており、成果が出れば重なる。「目的指向で選ぶこと」自体は新しくない |
| 技術的難易度 | 低〜中。既存の `(B⁻¹+F)⁻¹` の貪欲選択に温度計の候補を加えるだけで計算できる |
| 必要な数値手法 | 線形ガウスの事後共分散（予算つきの組合せ選択）、EnKF、持ち越し（holdout）評価 |
| OpenFOAM＋FrontISTR での実現 | 今の 3 条件の真値をそのまま使う。温度候補は OpenFOAM の全セル、変位候補は FrontISTR の上面節点（向き 3 つ） |
| 学会発表に必要な比較実験 | 同じ予算で「温度 4 本」「温度 3＋変位 1」「温度 2＋変位 2」「温度 1＋変位 3」を比較。配置法は目的指向／A 最適／D 最適／Herzog 型（温度だけで目的指向）／[論文 B](https://doi.org/10.1007/978-3-032-01194-7_25) 型（グラミアン）／無作為。評価は測らない反りと全セル温度 |

### 案 2：境界条件の不確かさを「連続的に推定する」か「モデルの集合から選ぶ」か ― 論文 B との直接比較

**内容。** 熱伝達率や接触熱抵抗が分からないとき、[論文 B](https://doi.org/10.1007/978-3-032-01194-7_25) は 500 個の ROM から重みで選び、本研究は EnKF の状態に入れて連続的に直す。同じ真値・同じセンサで両者を比べ、**どちらがどんな条件で良いか**（真値がサンプルの範囲の外にある場合、時間とともに変わる場合）を示す。

| 観点 | 内容 |
|---|---|
| 先行研究との具体的な差 | 論文 B は自分の方法だけを実験で示し、連続推定と比べていない。論文 B 自身が「サンプリング空間を実時間で動かす」ことを今後の課題としている |
| 新規性の見込み | **比較研究としての価値はある**が、手法の新しさはない（多重モデル推定もパラメータ拡張も既知）。論文 B のチームが自分で次に進める可能性が高い |
| 技術的難易度 | 中。ROM を境界条件ごとに作り直す必要がある（今の ROM は 1 本の学習計算から作っているので、境界条件を変えた OpenFOAM 計算が要る） |
| 必要な数値手法 | ラテン超方格サンプリング、ROM ごとの線形 KF と尤度重み、拡張状態の EnKF（または EKF） |
| OpenFOAM＋FrontISTR での実現 | 外気側の流れ・温度、接触面の熱抵抗（OpenFOAM の `thermalBaffle` 等、または固体間の界面条件）を変えた CHT を数本〜十数本計算し、パラメトリック ROM を作る |
| 学会発表に必要な比較実験 | §5 の 3 方式比較。特に、真値の熱伝達率をサンプル範囲の外に置いた場合と、運転中に変えた場合 |

### 案 3：熱入力が変わる運転への追従 ― 発熱量の時間変化と、制御装置の情報の使い方

**内容。** 工作機械では主軸回転数・送りが変わり、発熱が時間とともに変わる。[論文 A](https://doi.org/10.1016/j.mfglet.2024.09.025) は熱入力を 0 と置き、[論文 B](https://doi.org/10.1007/978-3-032-01194-7_25) は既知とした。本研究の既存の検証（[21 §④](21_advantage_verification.md)）では、ON/OFF の時刻を与えると誤差 0.08 µm、与えないと 0.18 µm だった。これを「NC 装置から分かる情報（回転数・電力）をどこまで使うか」の比較に広げる。

| 観点 | 内容 |
|---|---|
| 先行研究との具体的な差 | 論文 A・B とも、熱入力の実時間推定を今後の課題としている。[Lang ら (2023)](https://scholar.google.com/scholar?q=Lang%202023) は電力を回帰の入力に使ったが、物理モデルの同化ではない |
| 新規性の見込み | **工作機械の熱変位での実証としては可能性がある**。手法（入力のランダムウォーク推定）は Siemens・構造分野で標準なので、手法の新しさは主張できない |
| 技術的難易度 | 中。発熱の時間変化の表し方（ランダムウォークの大きさ）の選び方が結果を左右する。今の検証では 3 条件を見て σ=0.4 を選んでおり、別条件での確認が要る |
| 必要な数値手法 | 入力推定つきカルマンフィルタ（AKF/EnKF）、電力からの発熱モデル、ノイズの適応推定 |
| OpenFOAM＋FrontISTR での実現 | ヒータ出力の時間変化（台形・段階・ランダム）を OpenFOAM の境界条件の時間表で与えた真値を数本 |
| 学会発表に必要な比較実験 | 「熱入力 0（論文 A 型）」「既知の入力（論文 B 型）」「時刻のみ既知」「全く未知」の 4 通りで、測らない反りと発熱の推定誤差を比べる |

### 案 4：いつまで・どこで測れば放熱 h が決まるか ― 観測期間を含めた同定可能性の設計

**内容。** 600 秒では h が同定できず、長時間の ROM 試験では平均値が改善した（[19 §4-2](19_research_advantage_and_validation.md)）。これを「センサの場所」だけでなく「測る期間・加熱のさせ方（励起）」も設計変数に入れた実験計画として整理する。工作機械なら、暖機運転や停止中の冷却をどう使えば熱伝達率が決まるか、という実務的な問いになる。

| 観点 | 内容 |
|---|---|
| 先行研究との具体的な差 | Herzog 系列・Depaola は場所の設計で、主に定常か固定の時間窓。[論文 B](https://doi.org/10.1007/978-3-032-01194-7_25) は h を推定しない。過渡の熱伝達率同定で「名目値で最適化した配置は弱い」という指摘（MCM2026）はある |
| 新規性の見込み | **工作機械の熱変位に結び付けた形では見込みがある**が、一般の最適実験計画としては既知。理論の深さで勝負するなら数学系の研究者と組む必要がある |
| 技術的難易度 | 中〜高。h と q の相関（同時に決まらない方向）の扱い、モデル誤差がある中でのフィッシャー情報の意味づけ |
| 必要な数値手法 | 時間に累積したフィッシャー情報、プロファイル尤度、事後分布の被覆率の確認 |
| OpenFOAM＋FrontISTR での実現 | 長時間（数千秒）の CHT 計算を 1〜2 本追加し、ROM の外挿ではなく実ソルバで h の同定を確かめる（今は ROM の外挿だけ） |
| 学会発表に必要な比較実験 | 観測期間 600／1800／5000 秒、加熱の再投入あり・なしで、h・q の誤差と信用区間の被覆率を比較 |

## 6. 批判的評価と結論

### 6-1. 11/12 の発表の主張と、論文 A・B の重なり・違い

**主張 1「変位を観測に入れる」**

| | [論文 A](https://doi.org/10.1016/j.mfglet.2024.09.025) | [論文 B](https://doi.org/10.1007/978-3-032-01194-7_25) | 判断 |
|---|---|---|---|
| 変位を測っているか | 測っている（変位計 5 本、R-Test） | 測っている（変位計 5 本） | **測ること自体は同じ** |

| 推定する未知量 | 温度状態のみ（熱入力 0、h 一定） | 温度状態のみ（h・接触は 500 通りから選ぶ、熱入力は既知） | 本研究は q・h を状態に入れて直す。**違い** |

ただし、論文 A・B 以外では重なりがある。

- SFB/TR 96 の第 III 期は「温度測定に変位・ひずみを加える」ことを**目標として明記**している（成果論文は見つからなかった）。
- Siemens の構造の仮想センシングでは、ひずみ・位置を観測に入れるのは標準であり、Siemens は「マルチフィジックスへの拡張」を明言している。
- Ansari ら（2025、2026）は変位（と温度）から温度場を求めている（随伴最適化で、逐次同化ではない）。

したがって、[blog_008 §8-1](blog_008_novelty_displacement_assimilation.md#8-1-既存の4つの流派) の「変位を『観測』として状態推定に戻す流派がありません」という書き方は**強すぎる**。言えるのは「**今回調べた工作機械の熱変位の逐次推定（論文 A・B）では、変位は検証にだけ使われ、更新には使われていない**」までである。

**主張 2「目的指向の配置」**

| | 論文 A | 論文 B | Herzog 系列（§2-4） | 判断 |
|---|---|---|---|---|
| 目的（熱変位）を配置の基準に使うか | 使わない（k-means） | 使わない（グラミアン） | **使う**（TCP 変位の共分散） | 論文 A・B とは違うが、**工作機械の熱弾性では 2014 年から先行例がある** |
| 候補のセンサ | 温度 | 温度 | 温度 | 本研究は**変位計（向き込み）**。ここは違う |
| 確かめ方 | ― | ― | 移動ホライズン推定の模擬データ | 本研究は**逐次 EnKF を CHT 真値で回して順位を確認** |

したがって、「反りの事後分散を最小にする配置」を本研究の発明のように見せると、Herzog らの論文を知る聴衆・査読者から指摘される可能性が高い。**[Herzog, Riedel & Uciński (2018)](https://doi.org/10.1007/s11081-018-9391-8) と [Naumann, Riedel & Herzog (2025)](https://doi.org/10.1007/978-3-658-45180-6_12) を引用し、「同じ考え方を変位計の配置に適用し、逐次同化で確かめた」と位置づける**のが安全である。また、A 最適との差は 8〜15%（資料によっては 15〜20%）で、[blog_008 §7-7](blog_008_novelty_displacement_assimilation.md#7-7-分かったこと) 自身が「効き目は限定的」と書いている。発表の目玉にするには弱い。むしろ「よく動く点に置くと無作為より悪い」「A・O を直接測るより別の 2 点が良い」のほうが、実務者に伝わる知見である。

### 6-2. Siemens が参入した場合に、何が残るか

**まず、Siemens が既に持っているもの**（原文で確認）

1. 縮約 FEM＋AKF＋未知入力の推定＋実時間の xDT（構造、製品）
2. センサの**種類と場所**を選ぶ OSP ツール（構造、製品）
3. CFD 系の熱解析ソフト（Flotherm）から作る熱 ROM と、それに AKF をかけて**熱伝達率と発熱を推定**する手法、未知量の事後共分散による配置（熱、研究段階、2025）
4. 「マルチフィジックスへの拡張」の明言（2022）

熱 ROM（3）と構造 ROM（1）を $`K^{-1}K_{\rm th}`$ でつなげば、「温度＋ひずみ・変位を観測にした熱変形の仮想センシング」は、Siemens にとって**技術的には近い距離**にある。製品になれば、「ROM＋カルマンフィルタ＋配置設計を使える」という**道具としての優位性は残らない**。ここは率直に認めるべきである。

**それでも残りうるもの**（具体的に）

| 残りうるもの | 理由 | 条件 |
|---|---|---|
| **工作機械の熱変位に固有の知見** | 製品は道具で、「工作機械のどこに何を置けば工具‐工作物の相対変位が当たるか」「どの量は短時間では決まらないか」は教えない。本研究には、変位計を入れると測らない点の温度まで直る、h は 600 秒では決まらない、変位計は Q を直接は動かさない（[21 §③](21_advantage_verification.md)）、近接 2 点は無作為より悪い、ヒータ反対側を含む配置が良い、など失敗例込みの定量的知見がある | 円筒だけでなく、少なくとも 1 つの実機（または実機に近い試験台）で同じ傾向を示すこと |
| **論文 A・B 型、Siemens 型との公平な比較結果** | ベンダーや他研究室は自分の方法の結果しか出さない。同じ真値・同じセンサ予算での比較（§5）は第三者だから出せる | §5 を実施すること |
| **中身が見える再現可能な実装（OSS）** | 本実装ではフィルタ・観測写像・係数同定のソースを確認・変更し、追試できる。商用も行列出力・APIを持つ場合があるため、一律にブラックボックスとは呼ばない | 公開実装だけで数理手法の新規性は示せない。公開範囲と追試可能な条件を具体的に述べる |
| **CHT に基づく境界条件の物理的根拠** | 論文 B は CFD を上下限にだけ使い、Siemens の BCI-ROM は熱伝達率をパラメータとして外から与える。本研究は CHT の結果で ROM を校正している | 弱い。Flotherm も CFD なので、Siemens が同じことをするのは容易。強みにするなら「CHT で得た熱伝達率の時間・場所の変化が、同化でどう効くか」まで示す必要がある |
| **工作機械メーカーの社内にある実機・運転データへのアクセス** | ユーザー自身の最大の資産。Siemens も大学も、量産機の運転データと変位の実測を自由には持てない | 会社の許可と、実測の計画（`IoT/thermal_expansion_experiment/` は設計のみで未実施） |

**結論として**、Siemens が参入すると「仕組みを作った」こと自体の価値は大きく下がる。残るのは「**工作機械の熱変位で、何をどこで測ればよいかについての検証された知見**」と「**実機データ**」である。研究の重心をそちらに移すべきである。逆に言えば、Siemens の xDT が出てきたら、それを比較対象（または道具）として使えばよい。

### 6-3. 今の研究を続けるべきか、方向を変えるべきか

**11/12 の発表は、このまま行う価値がある。** ただし主張の言い方を次のように変える。

| 今の言い方（資料） | 変えた言い方（案） |
|---|---|
| 変位を観測として状態推定に戻す流派がない | 工作機械の熱変位の逐次推定の先行研究（[Lang ら 2024](https://doi.org/10.1016/j.mfglet.2024.09.025)、2026）は温度だけを観測に使い、変位は検証用だった。本研究は温度と変位を同じ EnKF の観測に入れ、測らない相対変位の改善を CHT＋熱弾性の真値で定量化した |
| 測れない場所を当てる設計論（目玉） | Herzog らの目的指向の配置（温度センサ）を、変位計の位置と向きの選択に適用し、逐次同化で順位がほぼ保たれることを確かめた（順位相関 0.9） |
| （言及なし） | Siemens Smart Virtual Sensing は構造で同じ枠組み（縮約 FEM＋拡張カルマンフィルタ＋配置設計）を製品化しており、熱でも研究段階にある。本研究はその熱変形版を公開ソルバで追試できる形にしたものと位置づけられる |
| 限界：実機なし | 限界：実機なし、1 形状、1 本の学習計算、[論文 A](https://doi.org/10.1016/j.mfglet.2024.09.025)・B の方式とは同条件で比べていない |

**社会人博士のテーマとしては、今の形のままでは弱い。** 理由は 3 つある。

1. **競合が近い**。[論文 B](https://doi.org/10.1007/978-3-032-01194-7_25) のチーム（ETH／inspire）は熱入力の推定と機械挙動を考えた配置を次の課題に挙げ、SFB/TR 96 は変位の追加を目標にし、Siemens は熱 AKF と OSP を持っている。手法の組合せで勝つ余地は小さく、しかも狭まっている。
2. **実測がない**。比べる相手（論文 A・B、Siemens の熱以外）はすべて実測で示している。数値実験だけでは、精密工学・生産工学の学会や論文誌では評価されにくい。
3. **差が小さい**。目的指向と A 最適の差は 8〜20%。博士論文の中心にするには、もっとはっきりした効果か、深い理論が要る。

**方向として推奨するのは**、案 3（熱入力の変化への追従）を中心に、案 1 と §5 の比較を「方法の章」として組み込み、**実機（社内の機械または試験台）での検証**を必須にすることである。案 3 は、論文 A・B の両方が今後の課題として残した点で、工作機械メーカーの立場（NC の情報・電力が手に入る）が直接効き、実機で運転条件を変えるのも比較的容易である。案 4（同定可能性）は、理論を深めたい場合の第二の柱になる。

### 6-4. 独自性がどこにあるか（現時点の評価）

- **独自性があるとまでは言えないが、まだ埋まっていないと思われる部分**：工作機械を想定した熱変形問題で、温度と変位を同じ逐次フィルタの観測に入れ、熱入力・放熱を同時に直し、測らない相対変位で評価し、その観測配置を変位計の向きまで含めて選ぶ、という組合せ。今回の検索では同じ組合せは見つからなかった。
- **独自性がないもの**：ROM＋カルマンフィルタ（論文 A、Siemens）、状態を未知量で拡張すること（Siemens の AKF、Depaola）、熱伝達率・発熱のオンライン推定（Depaola、Zhang、Oka）、目的を指定した配置（Herzog 系列）、変位から温度を求めること（Ansari）、$`W=K^{-1}H`$（Mayr 2015、論文 B）。
- **新規性を確かめるために必要なこと**：§7 の文献（特に SFB/TR 96 第 III 期の成果、論文 B の後続、Siemens の熱‐構造の仮想センシング）を本文で確認すること。

### 6b-1. 何を調べたか

**なぜ調べるか。** §2〜§6 で見たとおり、「縮約モデル＋カルマンフィルタ＋未知の発熱・熱伝達率の推定＋配置設計」という**方法の組み合わせ**は、Siemens・KU Leuven（[Depaola 2025](https://doi.org/10.1109/THERMINIC65879.2025.11216915)）、[論文 A](https://doi.org/10.1016/j.mfglet.2024.09.025)・B、Herzog/Naumann 系列とほとんど重なった。ユーザーは、組み合わせではなく**理論**で新しさを出したいと考えている。そこで、理論の章になりうる次の 4 候補について、既存の理論と文献がどこまであるかを調べた。

| 候補 | 問い（一文で） | §6 までとの関係 |
|---|---|---|
| 1. 発熱と冷却を見分ける条件 | 温度（と変位）の観測から、発熱 $`Q`$ と放熱 $`h`$ を別々に決められるのは、どんな時間の長さ・センサ位置・加熱の入り切りのときか | §4 案 4 と、[19 §4-2](19_research_advantage_and_validation.md) の「600 秒では $`h`$ が決まらない」を理論にしたもの |
| 2. 変位の観測が温度場について持つ情報 | 変位 $`u=WT`$（温度場の重み付き和）を測ることは、温度を点で測ることと比べて、温度場の何を教えるのか | §6-1 主張 1「変位を観測に入れる」を理論にしたもの |

#### 1 点モデルで見た「なぜ 600 秒では $`h`$ が決まらないか」（私の手計算、未検証）

理論の章の出発点になる形を、いちばん簡単な 1 点の熱回路で書いておく。熱容量 $`C`$ の物体に一定の発熱 $`Q`$ を入れ、周りへ $`h(T-T_\infty)`$ だけ逃げるとすると、温度の上がり $`\Delta T(t)`$ は

```math
\Delta T(t)=\frac{Q}{h}\left(1-e^{-t/\tau}\right),\qquad \tau=\frac{C}{h}.
```

$`x=t/\tau`$（時間を時定数で割った無次元の時間）とおき、$`Q`$ と $`h`$ をそれぞれ 1% 変えたときの温度の変わり方（尺度をそろえた感度）を計算すると

```math
Q\frac{\partial \Delta T}{\partial Q}=\Delta T_\infty\left(1-e^{-x}\right),\qquad
h\frac{\partial \Delta T}{\partial h}=-\Delta T_\infty\left[(1-e^{-x})-x e^{-x}\right],\qquad \Delta T_\infty=\frac{Q}{h}.
```

ここから 3 つのことが読める。

1. **加熱の初め（$`x\ll1`$）**：$`Q`$ の感度は $`\Delta T_\infty x`$、$`h`$ の感度は約 $`-\Delta T_\infty x^2/2`$ で、比はおよそ $`x/2`$。106 の時定数 約 2,100 s で 600 s までなら $`x\approx0.29`$、比は約 0.14。つまり **$`h`$ が温度に与える影響は $`Q`$ の 1/7 ほどしかない**。
2. **十分に時間が経ったとき（$`x\to\infty`$）**：2 つの感度は $`+\Delta T_\infty`$ と $`-\Delta T_\infty`$ で**ちょうど逆向き**になる。定常では温度は $`Q/h`$ の比だけで決まり、**$`Q`$ と $`h`$ を別々には決められない**（構造的に同定できないのは比の方向）。
3. **見分ける情報は途中の過渡にある**：2 つを分ける成分は $`x e^{-x}`$ の項で、これは $`x=1`$（$`t=\tau`$）で最大になる。加熱を止めて冷やす区間（$`Q=0`$ で $`e^{-t/\tau}`$ だけが見える）や、加熱の入り切りの繰り返しは、この成分を何度も作り直す。

これは [19 §4-2](19_research_advantage_and_validation.md) の結果（$`h`$ の 3 seed 平均の誤差が 600 秒で 56.7%、5,000 秒で 1.30%）と**向きは合う**。ただし 19 自身が「0.3〜1.1τ が普遍的に最適」と断定しないと書いているとおり、上の式は 1 点・一様な $`h`$・$`C`$ 既知の場合で、5 点の ROM（時定数は $`C^{-1}(L-hI)`$ の固有値で複数ある）では確かめていない。**この節の式は理論の章の「問い」を示すためのもので、結果ではない。**

#### この研究の条件で残る所

- **一般論は厚い**：感度の線形従属で同定可能性を見る（Beck & Arnold）、Fisher 情報やプロファイル尤度で実用的な同定可能性を見る、Fisher 情報で分布系のセンサ配置を選ぶ（Uciński）、未知入力の推定条件（Maes）はどれも確立している。
- **この条件で見つからなかったもの**：
  - **発熱 $`Q`$（体積や面の熱源）と放熱 $`h`$（同じ物体の冷却）を同時に推定するときの同定可能性を、観測期間 $`t/\tau`$・加熱の入り切り・センサ位置の 3 つで整理した結果**。電池の研究は似ているが、発熱は電気から既知として扱う。
  - **変位の観測を加えたときに、$`Q`$ と $`h`$ の分けやすさがどう変わるか**（候補 2 と重なる）。
  - **流れで $`h`$ が変わる（時間で $`h(t)`$ が動く）ときの同定可能性**。$`h`$ が一定なら長く測れば決まるが、ポンプの入り切りで $`h`$ が変わるなら、「長く測る」と「$`h`$ が変わる」が両立しない。
- **重なる可能性が高いもの**：Herzog, Riedel, Uciński (2018) は「状態とパラメータを同時に推定する配置」を熱弾性で扱っている（抄録の範囲）。観測期間を設計変数にしているかは未確認。

#### 手薄さの判定

**一般論はあるが、この条件では手薄。** 根拠：IHCP・同定可能性・OED の一般論は教科書と総説になっている。一方、「$`Q`$ と $`h`$ の同時推定」「工作機械の熱変位」「観測期間と励起」「変位観測」を組み合わせて、同定できる条件を示した文献は、下の検索語では見つからなかった（見つからないことは、ないことの証明ではない）。

検索語：`simultaneous estimation heat source and heat transfer coefficient inverse heat conduction identifiability`、`practical identifiability heat transfer coefficient profile likelihood transient experiment design Fisher information`、`"heat transfer coefficient" "heat source" correlated sensitivity coefficients cannot be estimated simultaneously transient inverse lumped`、`simultaneous estimation time-dependent heat flux and heat transfer coefficient inverse problem Robin coefficient Lesnic`。

#### この研究の条件で残る所

既存の研究を並べると、「変位から温度を求める」（Ansari、Marin）も、「温度場の積分を観測とする熱方程式の逆問題」（Lesnic ら）も、どちらもある。しかし、次の**2 つを結びつけた理論**は見つからなかった。

- 本研究の変位は $`u_i=\sum_j W_{ij}T_j`$（$`W`$ の $`i`$ 行目が、変位計 $`i`$ の「温度場の重み」）。つまり**変位計は、温度場の特定のモーメント（重み付きの平均）を測る積分観測**である。円筒の反り A−O なら、加熱側と反対側の温度差（1 次のモーメント）に、伸びなら平均温度（0 次のモーメント）に近い量を測っていると考えられる（梁の古典からの類推で、106 の $`W`$ で確かめてはいない）。
- 熱方程式は、時間が経つと温度場の細かい形を平らにし、**低次のモーメントほど長く残る**。したがって「変位計は、熱方程式が長く残す成分を直接測る」「点の温度計は、局所の値を測るが、遠くの温度は熱方程式を通してしか教えない」という対比が立つ。これが、本研究で**変位 2 点を足すと、測っていない場所の温度まで直った（全セル RMSE 0.54 → 0.13 K）**ことの説明候補になる。ただし、これは仮説で、未確認。
- 平均温度は、一様な $`h`$ の 1 点モデルでは、熱の収支 $`C\,d\bar T/dt=Q-h(\bar T-T_\infty)`$ をそのまま満たす。もし変位計が平均温度に近い量を測るなら、**変位計は $`Q`$ と $`h`$ の収支を直接見ている**ことになり、候補 1 とつながる。一方で [21 §③](21_advantage_verification.md) の「変位計は $`Q`$ を直接は動かさない」という結果もあり、この関係は単純ではない。
- Ansari らは静的で熱伝導の式を使わない。本研究は熱伝導の時間発展（ROM）を前提とし、その上で変位を観測にする。**過渡の熱伝導＋積分観測としての変位**、という問題設定の違いは残っている。

#### 手薄さの判定

**この条件では手薄（見つからない部分がある）。** 根拠：変位から温度を求める計算法（Ansari）、熱弾性の逆問題の一意性（Marin、Kozlov）、積分観測の係数逆問題（Lesnic）は**それぞれある**。しかし「温度計と変位計が、熱方程式の上で、温度場のどの成分をどれだけ教えるか」を比べた理論（固有モードごとの情報量、変位の観測の零空間、時間の長さとの関係）は、下の検索語では見つからなかった。SFB/TR 96 が目標に掲げているので、**近い将来に埋まる可能性はある**。

#### 勧める組み合わせと、その理由

**勧めるのは、候補 1 と候補 2 を一つの理論の章にまとめることである。** 題にすれば「過渡の熱伝導で、温度の点観測と熱変位の積分観測は、発熱・冷却・温度場について何を教えるか」。

理由は 4 つある。

1. **手薄さが比較的大きい**。候補 3・4 は一般論が厚く、理論の新しさを主張するには数学の側で新しい誤差評価を作る必要がある。候補 1・2 は、一般論（Fisher 情報、積分観測）はあるが、「$`Q`$ と $`h`$ の同時推定」と「変位＝温度場のモーメント」を結びつけた文献は見つからなかった。
2. **これまでの数値結果に、理論の説明を与える形になる**。「600 秒では $`h`$ が決まらない」（候補 1）と「変位 2 点を足すと測っていない場所の温度まで直る」（候補 2）は、どちらもすでに数字がある。理論の章は、この 2 つが**なぜ起きるか**を式で示し、予測（例：観測期間 $`\tau`$ 前後で $`h`$ の情報が最大、低次モードほど変位計が有利）を立てて、新しい計算で確かめる形にできる。
3. **方向 A の理論の土台になる**。候補 1 は「運転・冷却が変わるとき、発熱と冷却を分けて追えるか」という方向 A の中心の問いそのもの。候補 2 は、そのとき変位の観測がどれだけ助けになるか（Q4）を与える。方向 B（CHT の ROM）は候補 3・4 が受け持ち、方法と検証の章になる（下記）。
4. **計算の追加が比較的少ない**。$`W`$、POD モード、ROM はすでにある。必要な新しい CHT は長時間 1 本と、加熱の入り切りを変えた数本程度。

**候補 3・4 の位置づけ。** 理論の章の中心にするより、**方法と検証の章**（ROM の作り方と、流れが変わったときの使える範囲・誤差の扱い）として持つのがよいと考える。特に候補 4 の Q1（ROM の誤差を入れないと $`Q`$・$`h`$ がどれだけ偏るか）は、候補 1 の結果を実際の CHT 真値で確かめるときに**避けて通れない**ので、候補 1 の検証の一部として入れる。

**率直な注意。**

- 候補 1 の理論の多くは、1 点モデルなら教科書の範囲（Beck & Arnold の感度の議論）に収まる。新しさは「工作機械の熱変位」「変位観測」「観測期間と励起の設計」「$`h`$ が流れで変わる」を組み合わせた所にあり、**理論そのものの新しさは大きくない可能性がある**。数学系の共同研究者（逆問題・同定可能性）がいると深さが出る。
- 候補 2 は SFB/TR 96 が目標に掲げ、Ansari らも温度＋変位に進んでいる。**数年以内に近い成果が出る可能性がある**。早めに学会で出すのがよい。
- §6-3 で推奨した「案 3（熱入力の変化への追従）を中心に、実機で検証」とは矛盾しない。候補 1 の Q2・Q3（加熱の入り切り、$`h`$ の時間変化）は案 3 の理論の裏付けになる。ただし、§6-3 の「案 4 は理論を深めたい場合の第二の柱」という位置づけから、この章は**候補 1（＝案 4 を広げたもの）と候補 2 を理論の柱に上げる**提案になっている。どちらを主にするかは、実機の計画（案 3）が進められるかで決めるのがよい。

### 8-3. ① 発熱と冷却を見分けるには、何を証明する必要があるか

まず、106の放熱パラメータは表面熱伝達率ではない。ここでは $`g=h_{\mathrm{ROM}}`$ [W/K] と書き、物理的な表面熱伝達率 $`h_s`$ [W/(m² K)] と区別する。

1点の熱回路で、既知の熱容量 $`C`$、温度上昇 $`\theta=T-T_\infty`$ を使うと、

```math
C\dot\theta(t)=Q(t)-g(t)\theta(t)
```

である。Qとgがともに未知の任意時間関数なら、任意に選んだgに対して $`Q=C\dot\theta+g\theta`$ と置ける。**温度が完全に分かっても、1本の式だけから両関数を一意に決められるとは限らない。**

一方、Q・gが定数でCが既知なら、

```math
\underbrace{\begin{bmatrix}C\dot\theta(t_1)\\ \vdots\\ C\dot\theta(t_M)\end{bmatrix}}_{M\times1}
=
\underbrace{\begin{bmatrix}1&-\theta(t_1)\\ \vdots&\vdots\\1&-\theta(t_M)\end{bmatrix}}_{M\times2}
\underbrace{\begin{bmatrix}Q\\g\end{bmatrix}}_{2\times1}
```

となる。温度が時間とともに変化すれば2列が独立になる場合がある。定常温度だけでは $`Q=g\theta`$ という関係しか得られない。これは理想的な例であり、実測温度の数値微分は雑音を増幅するため、そのまま実装法にするという意味ではない。

空間分布を持つモデルでは、複数時刻の観測予報を縦に並べた $`\mathbf y(\mathbf p)`$ と、$`\mathbf p=[Q,g]^{\mathsf T}`$ の感度を考える。

```math
J_p=\begin{bmatrix}\partial\mathbf y/\partial Q&\partial\mathbf y/\partial g\end{bmatrix}
```

観測雑音とパラメータの尺度をそろえた感度の列が独立かを調べる。独立でもほぼ比例していれば雑音に弱い。**局所線形化での識別性、非線形問題の大域的一意性、有限メンバーでの推定精度は別々に評価する。** Fisher情報の最小固有値を計算しただけで、すべてを証明したとはしない。

ここまでの考え方は既存の識別性・実験計画の理論である。研究としては、熱容量・初期温度・機械的荷重・モデル誤差も未知にしたとき、どの運転情報と観測が必要になるかを、先行研究と比較して絞る必要がある。

### 8-4. ② 変位は温度の従属量でも、新しい観測情報になりうる

温度分布をPOD係数 $`\mathbf a`$（r×1）で表し、平均からの観測のずれを考えると、

```math
\delta\mathbf y_T=H_T\mathbf a+\boldsymbol\eta_T,\qquad
\delta\mathbf y_u=H_u\mathbf a+\boldsymbol\eta_u
```

である。$`H_T`$（温度観測数×r）は温度復元と温度センサ位置から決まる。$`H_u`$（変位観測数×r）はPOD温度復元・IDW・FrontISTR応答・変位センサの位置と方向から決まる。両者とも同じ温度状態を観測するが、**その温度状態の異なる組み合わせを測る**。

温度だけでは見えない成分 $`\mathbf v`$ があり、

```math
H_T\mathbf v=\mathbf0,\qquad H_u\mathbf v\ne\mathbf0
```

なら、その成分は変位観測に現れる。例えば少数の温度計が捉えにくい温度差を、構造全体の膨張・傾きの結果として変位計が捉える場合がある。

ただし、これは瞬間の線形観測の説明である。時間発展 $`\mathbf a_{k+1}=A\mathbf a_k`$ を使う場合は、$`H_T,H_TA,\ldots`$を縦に並べた可観測性行列と、変位を加えた行列を比べる。温度観測だけでも時間情報によって状態が見える場合があり、変位追加で必ずランクが増えるわけではない。

**変位が温度から計算されることと、少数の温度センサの測定値から変位観測が既に分かることは同じではない。** 一方、全温度状態を無誤差で観測済みなら、既知の線形熱弾性モデルから得る変位は新しい状態自由度を増やさない。

このランク・可観測性の考え方も一般理論である。Ansariらの先行研究に対する違いを明らかにするには、熱の時間発展、Q/gの未知性、変位に混じる機械的荷重、ROM誤差を含む条件で、情報が増える条件・増えない条件を具体化する必要がある。

### 8-5. ③・④ ROMの誤差をどう分けて扱うか

#### 既存手法を基準法として使う

観測値とROM出力の関係を、

```math
\mathbf y^{\mathrm{obs}}=\mathbf y_r(\mathbf p)+\boldsymbol\delta(\mathbf p)+\boldsymbol\eta
```

と書く。$`\mathbf y_r`$はROMの観測予報、$`\boldsymbol\delta`$は高忠実度モデルとROMの差、$`\boldsymbol\eta`$はセンサ雑音である。すべて観測数と同じ長さの列ベクトルとする。

[Silvaら（2023）](https://scholar.google.com/scholar?q=Silva%202023)の§3.2の近似では、ROM誤差の平均 $`\bar{\boldsymbol\delta}`$ と共分散 $`\Gamma_\delta`$ を事前に推定し、雑音共分散Rに対して、

```math
\mathbf y^{\mathrm{obs}}\approx\mathbf y_r(\mathbf p)+\bar{\boldsymbol\delta}
+\boldsymbol\xi,\qquad
\operatorname{Cov}(\boldsymbol\xi)=R+\Gamma_\delta
```

として扱う。独立な誤差として周辺化する近似の下での式であり、今回初めて提案する方法ではない。**共分散を増やすだけでなく、平均のずれも扱う**のが重要である。[Paganiら（2017）](https://scholar.google.com/scholar?q=Pagani%202017)は逐次EnKFに縮約誤差モデルを組み込んでいるため、逐次処理にするだけでも差別化できない。

#### Rを増やせばすべて直るわけではない

| 誤差の種類 | 現れる場所・確認すること |
|---|---|
| PODモードの打ち切り・空間復元の誤差 | ROM状態が正しくても観測写像・未観測点の出力に差が残る。捨てたモードを固定基底の状態更新だけで自由に復元することはできない |
| 熱回路係数・時間積分の誤差 | 予報モデルの誤差として蓄積・減衰・相関を持つ。状態雑音の共分散も検討対象になる |
| 系統的な放熱・熱入力の見込み違い | ゼロ平均雑音とみなすと、Q/gを誤って動かして観測へ合わせるおそれがある |
| 時間相関・状態との相関があるROM誤差 | 独立な白色雑音の単純な加算では表せない場合がある。誤差状態の拡張や条件付き誤差モデルなどを既存手法と比較する |

特に、ROM誤差を評価する条件とROMを作る条件が同じだけでは、未学習条件の誤差を過小評価しうる。[Silvaら（2023）](https://scholar.google.com/scholar?q=Silva%202023)も、基底構築と誤差統計の推定に同じデータを使う影響と、分割する方法を論じている。106・108で試す際も、構築用・誤差モデル用・最終評価用の運転を区別する。

### 8-6. 絞り込み候補：パラメータの変化とROM誤差を、どの観測なら区別できるか

> **研究質問の候補**：温度・変位・既知の運転情報を併用したとき、発熱と冷却条件の変化を、ROM自身の誤差から区別できる条件は何か。区別できない場合、未観測の熱変位にどれだけ誤差が残るか。

ただし、**モデル誤差と物理パラメータの混同という問題自体は既知**であり、[Brynjarsdóttir・O’Hagan（2014）](https://doi.org/10.1088/0266-5611/30/11/114007)が直接扱っている。この問いに言い換えただけで新規性が出たとはしない。

計画を具体化するための、既存の線形代数に基づく整理を示す。複数時刻の観測差を並べ、雑音で白色化し、パラメータの尺度もそろえた後で、

```math
\underbrace{\Delta\widetilde{\mathbf y}}_{m\times1}
\approx
\underbrace{\widetilde J_p}_{m\times2}
\underbrace{\Delta\widetilde{\mathbf p}}_{2\times1}
+
\underbrace{\widetilde G}_{m\times s}
\underbrace{\boldsymbol\beta}_{s\times1}
+\widetilde{\boldsymbol\eta}
```

と表す。$`\Delta\widetilde{\mathbf p}`$は規格化したQ/gの変化、$`\widetilde G\boldsymbol\beta`$は仮定したROM誤差の形とその係数、mは全時刻・全観測成分の合計、sは誤差の形の数である。初期温度や非熱的荷重なども未知なら、その影響も未知量として追加する必要がある。

ROM誤差の形と同じ観測変化を起こすパラメータ変化は、データだけから区別しにくい。$`\widetilde G`$の列空間へ射影する行列を $`\Pi_G=\widetilde G\widetilde G^+`$（$`+`$は擬似逆行列）とすると、

```math
\underbrace{J_{\mathrm{sep}}}_{m\times2}
=(I_m-\Pi_G)\widetilde J_p
```

は、ROM誤差と同じ形の成分を除いて残るQ/g感度である。この**局所線形・誤差係数を無拘束で未知とする設定**では、$`\operatorname{rank}(J_{\mathrm{sep}})=2`$がQ/gの変化を誤差項から分離する条件になる。最小特異値が小さければ雑音に弱い。温度のみの場合と温度＋変位の場合で、この行列がどう変わるかを比較できる。

この式は新しい定理ではなく、研究計画のための既存理論の整理である。ROM誤差を任意の観測差に合わせられるほど自由にすると、パラメータとの区別は失われる。正則化や事前情報で推定値が得られても、それは観測データだけで識別できたこととは区別する。また、局所線形のランク条件だけで、非線形問題全体の一意性やEnKFの収束を保証しない。

**研究として必要な上積み**は、例えば、熱方程式・熱弾性応答から誤差の形を制約したときの識別条件、観測と運転の時間窓に依存する誤差評価、未観測相対変位に対する保証を導き、既存の誤差考慮EnKFと比べることである。これらの新規性と実現可能性は未確認で、次の文献精査で絞る。

**「熱にだけ起きる」とは書かない。** 識別困難・モデル誤差・長時間予測の誤差は他分野にもある。熱で注目するのは、拡散による情報の平滑化、放熱感度が温度上昇や時間窓に依存すること、流量変更による移流の変化、熱変位が温度分布を空間的に重み付けすることなどである。

**「Siemensは熱伝導だけ」とも書かない。** [FLOEFD 2506のBCI-ROMの説明](https://blogs.sw.siemens.com/simcenter/simcenter-floefd-2506-whats-new/)は3D熱伝導モデルからの構築を扱う。一方、[Siemensの2025-10-24の公式記事](https://blogs.sw.siemens.com/art-of-the-possible/computer-aided-engineering-in-the-industrial-metaverse-part-4/)は、流体・熱を含む多物理場のparametric POD-ROMを紹介している。BCI-ROMの条件をSiemens全体に一般化しない。メーカーの機能紹介だけでは、誤差保証や今回の観測構成の理論まで備えているとは判断しない。

### 8-8. 次に進める順序と、成果の判定

1. **本文を優先して読む**：[Huttunen・Kaipio（2007）](https://doi.org/10.1088/0266-5611/23/5/019)、[Paganiら（2017）](https://scholar.google.com/scholar?q=Pagani%202017)の出版版、[Brynjarsdóttir・O’Hagan（2014）](https://doi.org/10.1088/0266-5611/30/11/114007)、時間依存Robin係数・熱流束の同時再構成論文。今回未取得の本文を入手し、仮定・保証・破綻条件を比較表にする。
2. **問題を固定する**：Q/gを定数か時間関数か、C・初期温度・機械的荷重のどれを既知とするか、観測可能な温度・変位・NC情報、ROM誤差の許容形を決める。h_ROMと物理HTCのどちらを推定するかも固定する。
3. **既存理論で説明できる範囲を先に確認する**：可観測性・規格化感度の特異値・モデル誤差と感度の重なりで106の結果が説明できるなら、それを既存理論の適用として記録する。
4. **比較試験を設計する**：温度のみ／温度＋変位、正しいモデル／係数誤差／モード不足、加熱のみ／加熱＋冷却、既知入力／未知入力を分ける。誤差無視、既存の平均・共分散補正、必要なら基底更新を同じ条件で比べる。構築に使わない運転で評価する。
5. **新しい主張を限定する**：既存の補正法で十分なら、その結果を受け入れる。十分でない条件で、識別条件や未観測変位の誤差評価を追加できるかを検討する。理論を導いただけで終わらず、対応する数値例・反例、可能なら試験台で検証する。

現段階の判断は、**①＋②を中心に③・④の既存手法を基準として比較する方向は検討できるが、博士研究としての独自性を確認済みとは言えない**、である。未知の組み合わせを探すだけでなく、先行研究の仮定を一つ明示的に変えたとき、何を証明・保証・反証できるかを次の判断材料にする。
