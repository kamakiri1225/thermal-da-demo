# 発表ストーリー（オープンCAE学会向け）― 全体の流れ

オープンソースCAE（**OpenFOAM＋FrontISTR＋Python**）とデータ同化だけで、
少数の温度・変位観測から **温度分布・発熱量・熱変形** を逆推定する——という一連の流れ。
全コード・全ドキュメント・全図が公開され、**誰でも再現できる**ことが最大の貢献。

> この発表ストーリーは 104（実ソルバDA）・105（観測設計）・106（POD選定ROM）を横断してまとめたもの。
> アルゴリズム詳細は本フォルダ106の `00_data_assimilation_algorithm.md`（EnKF/OI）・`01_pod_qdeim_algorithm.md`（POD/Q-DEIM）・`02_full_story.md`（絵と数式の全ストーリー）を参照。

> それを**観測設計（感度解析）**と、**2通りの軽量化（ROM / OI）**でどう扱うかを示す。」

## 1. 背景と貢献（オープンソース）〔厚め〕

- 工作機械の加工誤差の大きな割合は **熱変形**。少数センサから全体の温度・変形・熱源を
  推定できれば、リアルタイム補正やデジタルツインに使える。
- 本研究は **OpenFOAM（CHT）＋FrontISTR（熱膨張）＋Python（データ同化）だけ** で、
  実験を模した**双子実験（OSSE）**の逆推定を実装。**商用ソルバ不要で一連の逆問題が組める**。
- **全コード・図・解説を公開＝再現可能**。ここがオープンCAEへの貢献。
- 題材：中空円筒の片側加熱（ヒータ）による共役熱伝達＋熱膨張。0〜600秒（加熱0〜300／冷却300〜600）。

## 2. まず高忠実モデルでデータ同化が"動く"（104 EnKF）〔厚め〕

- `chtMultiRegionFoam`（温度場）＋ `fistr1`（熱変形）を**そのまま前進モデル**にして EnKF。
- 温度2点（hot/cold）＋上面の鉛直変位2点を観測に、**固体20,696セルの温度＋発熱量Q**を更新。
- 結果：でたらめ初期→真値へ収束。

  | 指標 | 結果 |
  |---|---|
  | 全セル温度RMSE | **7.61 K → 0.011 K** |
  | 発熱量 Q | **→ 14.93 W**（真値15 W、誤差約0.5%） |
  | 構成／コスト | 5メンバー・60秒ごと10更新／**直列で約13時間（重い）** |

- **メッセージ**：オープンソース連成でも実ソルバDAは成立する。**が、実機規模では計算コストが非現実的**。
- 図：`../../104_0_openfoam_frontistr_da_enkf/docs/img/openfoam_fem_enkf_rmse.png`, `..._Q.png`

## 3. 熱変位の同化は、実は難しい（本研究の核心）〔厚め〕

ここが「ただ動いた」で終わらせない中身。

- **熱変位は初期温度・発熱量Q・熱伝達率h・輻射など、条件を"すべて"合わせないと合わない。**
  温度の傾向が合っていても、変位まで合う保証はない。
- 変位は温度場から $u = W\,T$（$W=K^{-1}H$、FrontISTRの熱感度行列）で決まる。
  この **W が大きく、わずかな温度誤差（0.3 K級）をµmオーダーの変位誤差へ増幅**する。
  → 「温度をそこそこ合わせる」だけでは変位はズレる、という証拠を提示（`img/disp_amplification.png`）。
- さらに **発熱量Qと放熱hは似た温度変化を作る（等結果性・equifinality）** ため、分離＝同定が難しい。
- **メッセージ**：熱変位DAの成否は「①観測をどこに置くか」「②何を推定し何を固定するか」で決まる。→ 4・5・6へ。

## 4. 観測点は"感度"で設計する（105）〔軽め・本命の知見〕

- 観測点を適当に選ぶと、**過渡（加熱序盤）で推定が外れる**（低感度点はノイズを増幅し逆振れ）。
- **変位観測点は熱感度 $W=K^{-1}H$ の行感度**で選ぶ（高感度点ほど温度→変位の写りが強い）。
- **温度センサは別の感度 $dT/dQ$（未知量Qへの感度）**で選ぶ。感度の種類を混同しない。
- → **FrontISTRの感度解析で、装置を作る前にセンサ配置を設計できる**
  （`../../105_0_sensor_placement_sensitivity/docs/03_sensor_design_guide.md`）。

## 5. 軽量化ルートA：ROMで秒にする（106＝本フォルダ）〔軽め〕

- OpenFOAMのスナップショットに **POD**：温度場は **2〜3モードで約99%** 説明＝少数点で表せる。
- **Q-DEIM（POD由来の最適補間点選定）** で代表点を**データから系統的に**選ぶ（勘で置かない）。
- 選点＋熱回路網の集中定数ROMを実データに校正（残差0.012K）→ **0〜600秒が数秒**で回る。
- **効用**：同化・観測構成の比較を**何度も試せる**（高忠実版では試行回数が取れない）。
- 図：`img/qdeim_points.png`, POD累積エネルギー, ROM同化の温度/変位追従

## 6. 軽量化ルートB：OIで"アンサンブル無し"にする〔軽め〕

- **OI（最適内挿）**：アンサンブルを使わず**背景トラジェクトリ1本**＋**固定した背景共分散B**で更新。
  実ソルバ（OpenFOAM＋FrontISTR）はそのまま。**forecastコストはEnKFの約1/N**。
  （計算場所：`../../104_0_openfoam_frontistr_da_enkf/run/run_openfoam_fem_oi.py`、ケース `openfoam/run_fem_oi*`）
- 結果（実ソルバ・背景1本）：

  | 指標 | OI | 参考：EnKF |
  |---|---|---|
  | 全セル温度RMSE | 5.0 K → **0.11 K** | → 0.011 K |
  | 変位（観測点・未観測点） | **真値に追従** | 追従 |
  | 発熱量 Q | **→ 約9 W止まり**（真値15Wに届かず） | → 14.9 W |
  | コスト | **約1.2〜1.6 h** | 約13 h |

- **σの決め打ちが難しい**ことを実証：背景の $\sigma_Q$ を **0.5→50 W と100倍振っても** Q推定は**8.8〜9.0 Wでほぼ不変**（ゲイン飽和）。同化なしはQ=22W・RMSE6.2Kで発散。
- **考察（重要）**：OIは**温度場・変位は真値へ寄せられる**が、**固定BのもとでパラメータQは弱可同定**。
  一方EnKFの**流れ依存の標本共分散はQをよく当てる**。
  → 「軽さ（OI）」と「パラメータ同定精度（EnKF）」の明確なトレードオフとして提示できる。
  さらに「Qが9Wでも温度・変位は合う」＝3章の等結果性の実例にもなっている。
- 図：`img/oi_Q_estimate.png`（σ_Q=0.5/2/6/50＋同化なしのQ(t)）、`img/oi_fullsolver_temp.png`（観測点＋未観測点の温度・変位、no-DA重畳）、`img/oi_obs_points.png`（観測点の位置）

## 7. 温度分布・熱変形を全場で再現する〔厚め〕

- 代表点の温度から、**温度分布は復元**（IDW／gappy-POD）。
- **変位は距離補間ではなく**、FrontISTRの**単位温度応答を事前計算したM演算子**で復元。
- **同化なし vs 同化あり**を並べ、観測点だけでなく**未観測点でも真値へ寄る**ことを提示。
- → 少数点の推定から、全体の温度分布と熱変形をアニメーション／時刻歴で見せられる。
- 図：ParaViewの温度・変位分布、`img/oi_fullsolver_temp.png` の未観測点パネル

## 8. まとめと限界〔厚め〕

- **まとめ**：オープンソースだけで「高忠実DA（EnKF）→ 熱変位DAの難しさの明示 → 観測設計（感度）→
  2通りの軽量化（ROM／OI）→ 分布・変位の再現」が一通り動き、**全て公開・再現可能**。
- **手段の使い分け**：
  - パラメータ（Q・h）まで当てたい → **EnKF**（重いがQを同定）
  - とにかく軽く場を寄せたい → **OI**（1/N。ただしQは弱可同定、σ調整はケースバイケース）
  - 観測構成を何度も比較したい → **ROM**（秒で回る）
- **限界**：①高忠実版の計算コスト ②**Q と h の識別可能性**（似た温度変化＝等結果性で分離困難、OIでは顕著）
  ③実機主軸での検証は未実施（双子実験の段階）。
- **今後**：多熱源（前後軸受）へQをベクトル化、実機での識別可能性の実証、OIの $B$ の適応化。

## 想定質疑（背景として用意）

- **Q1: なぜEnKFではなくOIも見せる？** → コスト1/Nの軽量化。ただし固定Bでパラメータ同定は弱くなる、というトレードオフを実データで示すため。
- **Q2: OIのσはどう決めた？** → 背景の相対不確かさ（$\sigma_Q/Q\approx40\%$）から決め打ち。**が、100倍振っても結果が変わらない**＝決め打ちの妥当性は本質的に検証しづらい、と正直に述べる。
- **Q3: Qが9Wでも温度・変位が合うのは矛盾では？** → 等結果性。DAは温度場を直接補正するため、Qが外れても場・変位は合いうる。パラメータ同定と場の再現は別問題、という核心メッセージ。
- **Q4: 実機ではどう測る？** → 温度＝熱電対／熱流束センサ、変位＝レーザ変位計。観測ノイズは温度0.3K・変位0.1µm相当を仮定。
