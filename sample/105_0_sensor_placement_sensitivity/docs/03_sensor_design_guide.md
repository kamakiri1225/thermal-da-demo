# 実務ガイド：W=K⁻¹H を使った「実験前のセンサ配置設計」

105の検証で得られた、**装置を作る前にセンサ計画を最適化する**ための手順と設計則。
今後の資料作り・実験計画にそのまま使えるようにまとめる。

---

## 1. 核心のメッセージ（1枚スライド用）

> **感度行列 W=K⁻¹H を実験前に1回計算しておけば、
> 「どこに変位計を貼れば、1本の測定で温度場をよく縛れるか」が
> 装置を作る前に分かる。**
>
> - 計算コストは FrontISTR（DUMPWパッチ版）1回＝**数十秒〜数分**。実験のやり直しはゼロ
> - 効果は実証済み：観測点の選び方だけで同化精度が**1.7倍**（5自由度ROM）〜
>   **12倍**（570節点実FEM, KinvH検証）変わる
> - 選び方を誤ると「意味がない」だけでなく**害になる**：低感度点の信号は
>   ノイズに埋もれ、EnKFが偶然の相関でノイズを増幅して**逆方向に補正**する
>   （加熱序盤にQoIが−1µmまで逆振れした実例あり）

## 2. なぜ実験前に分かるのか

W=K⁻¹H は「節点温度→変位」のヤコビアン（線形弾性なら厳密）。
**構造（形状・材料・拘束）だけで決まり、ヒータ位置や運転条件に依存しない。**
だから CADとメッシュがあれば、装置の製作前・実験前に計算できる。

| Wの読み方 | 意味 | 使い道 |
|---|---|---|
| **行** Σ\|W[i,:]\| | 点iの変位は温度場にどれだけ敏感か | **変位計をどこに貼るか**（効果大） |
| **列** W[:,j] / W_diff | 節点jの温度は観測(QoI)をどれだけ動かすか | 温度管理すべき場所の特定（治具・床への熱逃げ） |

## 3. 設計手順（本フォルダで再現可能）

```
① メッシュ準備（四面体341。六面体しかなければ6分割テトラ化: run/dumpw_cylinder.py）
② DUMPWパッチ版fistr1で1回実行
   !SOLVER,METHOD=DIRECT,...,DUMPTYPE=MM,DUMPW=YES + sensitivity_points.dat
   → W_diff(QoI感度場) と K,H のダンプが出る          …15秒
③ K,Hから W全体を構築（run/build_W_from_dumps.py）      …約2分
④ 行感度マップから変位計の位置を決める（run/kinvh_sensitivity.py）
⑤ そのままデータ同化(EnKF)に投入して精度を事前リハーサル（run/以下のDA一式）
```

## 4. 選点の設計則（実証済みの教訓）

1. **W行感度の高い場所に変位計を貼る**（今回：底面固定の対極＝上端。
   拘束から遠い側ほど大きい）
2. **固定境界近傍の見かけ感度は除外する**。拘束節点まわりはアーティファクトで
   感度が桁違いに出る（今回も6×10⁷µm/Kが出現。中央値の100倍超は捨てる）
3. **2本目は「方向の違う」点を選ぶ**：1本目とWの行ベクトルの方向が近い点は
   情報が重複する。|cosθ|<0.9 を目安に選ぶと堅牢
4. **温度センサは熱感度ではなく「推定したい未知量への感度」(dT/dQ)で選ぶ**。
   変位計を併用するなら、熱感度の高い場所の温度情報は変位計が既に持っている（冗長）。
   熱源近傍に置き、感度最小の場所（今回はcold）だけは必ず避ける
5. **W列(W_diff)マップは「温度を管理すべき場所」を教える**。今回は底面固定部近傍が
   最も敏感 → 床への熱逃げ・治具温度の管理が変位精度を左右する

## 5. 効果の実証データ（引用用）

| 検証 | 条件 | 結果 |
|---|---|---|
| 本ケース(105) ROM | 変位2点を高感度/低感度で選び分け | RMSE **0.0237K vs 0.0400K**（1.7倍） |
| KinvH 実FEM(570節点) | 同上 | QoI誤差 **89%→8%**（12倍） |
| 傾向 | 自由度が大きいほど | **差は拡大**（実機スケールでは死活問題） |
| 温度センサ側(証拠B) | W_diff最大/最小に置き分け | 0.0225K vs 0.0251K（差小=変位と冗長） |

## 6. 工作機械への応用イメージ

- 主軸先端変位などの**QoIを sensitivity_points.dat に指定**すれば、
  W_diff がそのまま「主軸熱変位の温度感度マップ」になる
- QoIに対する**W行感度の高い位置へ変位センサを少数配置**すれば、
  過渡熱変位のリアルタイム推定（データ同化）が成立しうる
- 逆に低感度位置へのセンサ増設は費用対効果が低い、と**定量的に**言える

## 7. 検証の信頼性（出所）

- W は DUMPWパッチ版FrontISTR（随伴法と2.4e-8一致検証済み, 20260810_KinvH）の
  K・Hダンプから構築し、DUMPW直接出力 W_diff と**最大相対差1.9e-7で一致**
- 独立な摂動法（120パッチ+1K×FrontISTR実行）とも**最大差5.8%**で整合
  （六面体vs四面体の離散化差）
