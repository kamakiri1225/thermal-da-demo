# 結果ガイド

## 比較の大原則

すべての結果グラフで **No-DA（センサなし）と KF（DA あり）は同一条件からスタートしている**。
同じ初期温度・同じ熱入力モデルを使い、唯一の違いはセンサ観測を使うかどうかだけである。
この原則を守ることで「センサが何をもたらすか」だけを純粋に評価できる。

## ケース 1：基本デモ（`main.py`）

### 実験条件

| 条件 | 真値 (Truth) | No-DA | KF（DA あり） |
|---|---|---|---|
| 初期温度 | 全節点 **20°C** | 全節点 **22°C**（2°C 過大） | 全節点 **22°C** ← No-DA と同じ |
| 熱入力モデル | 6,500 W/m | 6,500 W/m（同じ、モデル誤差なし） | 6,500 W/m（同じ） |
| センサ観測 | — | **✗ 使わない** | **✓ Node 0, Node 9（σ=0.20°C）** |

「システム起動時に初期温度を正確に知ることができない」状況を模擬している。
No-DA は 2°C の初期誤差が熱的時定数（≈ 73 分）のために残り続ける。
KF は数ステップで正しい値に引き戻す。

### KF パラメータ（最適値）

| パラメータ | 記号 | 値 | 根拠 |
|---|---|---|---|
| プロセスノイズ | σ_Q | 0.03°C | システムの揺らぎに対応 |
| 観測ノイズ | σ_R | 0.20°C | センサ精度に合わせた値 |
| Q 拡大係数 | Q_SCALE | **1.0** | モデル誤差なし → 拡大不要 |
| 初期共分散 | P0 対角 | **4.0°C²** | 初期誤差 2°C → σ² = 4.0（最適） |
| P0 空間相関長 | L_P0 | **4 節点** | 初期誤差が均一なので長めに設定 |

## ケース 2：DA 効果デモ（`main_da_demo.py`）

### 実験条件

| 条件 | 真値 (Truth) | No-DA | KF（DA あり） |
|---|---|---|---|
| 初期温度 | **暖機後の状態**（Node 0 ≈ 46°C） | 全節点 **20°C**（初期誤差 26°C） | 全節点 **20°C** ← No-DA と同じ |
| 熱入力モデル | 8,450 W/m（Q×1.3） | **6,500 W/m**（30% 過小評価） | 6,500 W/m ← No-DA と同じ |
| センサ観測 | — | **✗ 使わない** | **✓ Node 0, Node 9（σ=0.20°C）** |

真値だけを 50 分間先行して走らせ、暖機済み状態を作る。
No-DA / KF はその暖機履歴を知らないコールドスタート（電源投入時に過去状態が分からない状況）。
さらにモデルの発熱量が 30% 少ないため、No-DA は誤差が時間とともに累積する。

### KF パラメータ（最適値）

| パラメータ | 値 | 根拠 |
|---|---|---|
| Q_SCALE | **5.0** | 30% モデル誤差に対してゲインを上げる |
| P0 空間相関長 | **4 節点** | 初期補正を隣接節点へ波及させる |
| σ_R | 0.20°C | センサ精度に対応 |

## ケース 3：変位センサ追加（`main_disp_obs.py`）

### 実験条件

3 ケースすべてが **同じ初期条件・同じ熱モデル** からスタートし、**観測の種類だけが異なる**。

| ケース | 観測 | センサ構成 |
|---|---|---|
| **Case A** | 温度 2 点のみ | Node 0, Node 9 の温度 |
| **Case B** | 温度 2 点 + 変位 | Node 0, Node 9 の温度 ＋ 棒全体の熱変位 |
| **Case C** | 変位のみ | 棒全体の熱変位のみ（温度センサなし） |

**変位** = 全節点の温度上昇の積算値。中央節点の情報も「合計」として間接的に含む。
これにより変位観測は中央節点の推定を補助できる。

### 出力ファイル

- `results_disp_obs.png`：6 パネル比較（2 節点の温度、変位、精度バー）
- `results_disp_obs_all_nodes.png`：全 10 節点の Case A / B / C vs 真値（5×2 グリッド）

### 定常域 RMSE（後半 30 分）

| ケース | 未観測平均 RMSE [°C] | 最大 RMSE [°C] | 変位 RMSE [µm] |
|---|---:|---:|---:|
| Case A：温度 2 点のみ | 0.341 | 0.519 | 3.212 |
| Case B：温度 2 点 + 変位 | 0.113 | 0.169 | 0.234 |
| Case C：変位のみ | 0.191 | 0.312 | 0.250 |

変位観測を加えた Case B が全ての指標で最高精度。
Case C（変位のみ）は温度センサなしでも Case A より中央節点の精度が良い場合があり、
実機では工具長計測（変位計）だけでも熱補償できる可能性を示唆している。
