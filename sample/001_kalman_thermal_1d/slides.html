01 — 先行研究 ／ 基礎概念

データ同化（DA）とは何か？

目標：観測できない量（未観測節点の温度）を、 物理モデルの予測とセンサ観測を組み合わせることで推定する。

物理モデル（シミュレーション）
$\hat{\boldsymbol{\theta}}_k^- = \mathbf{A}_d\hat{\boldsymbol{\theta}}_{k-1}^+$
熱伝導方程式を解いて全節点の温度を予測
⚠ モデル誤差あり（パラメータの不確かさ）
センサ観測
$\mathbf{y}_k = \mathbf{H}\boldsymbol{\theta}_k + \mathbf{v}_k$
Node 0 と Node 9 の温度を測定
⚠ 一部節点のみ / センサノイズあり
⟹
データ同化
$$\hat{\boldsymbol{\theta}}_k^+ = \hat{\boldsymbol{\theta}}_k^- + \mathbf{K}_k\underbrace{(\mathbf{y}_k - \mathbf{H}\hat{\boldsymbol{\theta}}_k^-)}_{\text{イノベーション}}$$
$\mathbf{K}_k$（カルマンゲイン）が
モデルと観測の信頼度に応じて重みを決定
⟹
最適推定値
$\hat{\boldsymbol{\theta}}_k^+ \in \mathbb{R}^{10}$
全10節点の温度（未観測含む）
✅ モデル単独より精度が高い
カルマンゲイン $\mathbf{K}$ の直感：  モデルが不正確（誤差共分散 $\mathbf{P}$ が大きい）→ $\mathbf{K}$ が大きく → 観測を重視  /  センサがノイジー（$\mathbf{R}$ が大きい）→ $\mathbf{K}$ が小さく → モデルを重視

01 — 先行研究 ／ 基礎概念

データ同化の数学的基礎：ベイズの定理

データ同化は ベイズ推定 の枠組みで統一的に理解できる。 「モデル予測（事前情報）」と「観測（尤度）」を組み合わせて 「更新後の推定（事後分布）」を求める操作がその本質。

\[ p(\mathbf{x} \mid \mathbf{y}) \;=\; \frac{p(\mathbf{y} \mid \mathbf{x})\; p(\mathbf{x})}{p(\mathbf{y})} \;\propto\; \underbrace{p(\mathbf{y} \mid \mathbf{x})}_{\text{尤度（観測）}} \cdot \underbrace{p(\mathbf{x})}_{\text{事前分布（モデル）}} \]
事前分布 \(p(\mathbf{x})\)
モデルによる予測分布
平均 \(\hat{\mathbf{x}}^-\)、共分散 \(\mathbf{P}^-\)
→ 観測前の不確かさ（広い）
尤度 \(p(\mathbf{y}\mid\mathbf{x})\)
センサが状態 \(\mathbf{x}\) のとき
観測 \(\mathbf{y}\) が得られる確率
→ 観測ノイズ \(\mathbf{R}\) で決まる
事後分布 \(p(\mathbf{x}\mid\mathbf{y})\)
観測を反映した更新分布
平均 \(\hat{\mathbf{x}}^+\)、共分散 \(\mathbf{P}^+\)
→ 不確かさが縮小（狭い）
カルマンフィルタ ＝ 線形ガウス系でのベイズ推定の厳密解
事前分布 \(\mathcal{N}(\hat{\mathbf{x}}^-, \mathbf{P}^-)\) × 尤度 \(\mathcal{N}(\mathbf{H}\mathbf{x}, \mathbf{R})\) の積を解析的に計算すると、そのままカルマンゲイン式が導かれる： \[ \hat{\mathbf{x}}^+ = \hat{\mathbf{x}}^- + \underbrace{\mathbf{K}}_{\text{ゲイン}}(\mathbf{y} - \mathbf{H}\hat{\mathbf{x}}^-) \qquad \mathbf{P}^+ = (\mathbf{I} - \mathbf{K}\mathbf{H})\mathbf{P}^- \] 非線形・非ガウスの場合は EnKF・粒子フィルタ等の近似手法が必要

01 — 先行研究 ／ 基礎概念

データ同化の動作イメージ：逐次的な推定更新

観測が届くたびに「予測（P⁻ 大）」→「観測」→「更新（P⁺ 小）」を繰り返す。推定誤差が収縮していく。

ポイント：観測が来るたびに P⁻（広い）→ P⁺（狭い）へ収縮。 次の予測で再び P⁻ に拡大。この繰り返しで推定値が真値に収束していく。 カルマンゲイン $\mathbf{K} = \mathbf{P}^-\mathbf{H}^\top(\mathbf{H}\mathbf{P}^-\mathbf{H}^\top + \mathbf{R})^{-1}$ が P⁻ と R の比から 自動的に重みを決定する。

01 — 先行研究 ／ 手法分類

DA手法の2大アプローチ：変分法 vs 逐次法

変分法（Variational）

考え方：観測全体に対してコスト関数を最小化する。
「過去〜現在の全観測を一括して最適化」
3D-Var
コスト関数：$J = \frac{1}{2}(\mathbf{x}-\mathbf{x}^b)^T\mathbf{B}^{-1}(\mathbf{x}-\mathbf{x}^b) + \frac{1}{2}(\mathbf{y}-\mathbf{H}\mathbf{x})^T\mathbf{R}^{-1}(\mathbf{y}-\mathbf{H}\mathbf{x})$
固定の背景誤差共分散 B。気象予報で広く利用
4D-Var
時間方向にも積分してコスト最小化
随伴モデルが必要。実装が難しいが最高精度
デメリット：随伴コード作成コストが高い。
時間逆積分が困難なモデルには不向き

逐次法（Sequential）

考え方：観測が来るたびに推定値を逐次更新する。
「予測 → 観測が来たら更新 → また予測 → …」

03 — 理論：物理モデルの導出

出発点：1次元熱伝導方程式

物理問題の設定

長さ $L = 1$ m の熱棒。左端から熱入力、両端から対流冷却：

支配方程式（熱伝導 PDE）

$$\rho c_p \frac{\partial \theta}{\partial t} = k \frac{\partial^2 \theta}{\partial x^2}$$

$\rho c_p$：体積熱容量 [J/(m³·K)]、$k$：熱伝導率 [W/(m·K)]
$\alpha = k/(\rho c_p)$：熱拡散率 [m²/s]

$$\frac{\partial \theta}{\partial t} = \alpha \frac{\partial^2 \theta}{\partial x^2}$$

有限差分法（FDM）による空間離散化

棒を $n=10$ 節点に分割（$\Delta x = L/(n-1) = 0.1$ m）。2階微分を中心差分で近似：

$$\left.\frac{\partial^2\theta}{\partial x^2}\right|_i \approx \frac{\theta_{i-1} - 2\theta_i + \theta_{i+1}}{\Delta x^2}$$

各節点 $i$ の時間微分：

$$\dot{\theta}_i = \underbrace{\frac{\alpha}{\Delta x^2}}_{r}\left(\theta_{i-1} - 2\theta_i + \theta_{i+1}\right)$$

境界節点（Node 0）では対流冷却の境界条件を加算：

$$\dot{\theta}_0 = r(\theta_1 - 2\theta_0) - h(\theta_0 - T_\text{amb}) + \underbrace{Q_\text{in}}_{\text{熱入力}}$$
まとめると連続時間 ODE： $$\dot{\boldsymbol{\theta}} = \mathbf{A}_c\boldsymbol{\theta} + \mathbf{B}_c u$$ $\boldsymbol{\theta} \in \mathbb{R}^{10}$（全節点温度）、$\mathbf{A}_c$：三重対角行列

03 — 理論：状態空間モデル

連続時間 ODE から離散時間状態方程式へ

前進オイラー法で時間離散化

連続時間 ODE $\dot{\boldsymbol{\theta}} = \mathbf{A}_c\boldsymbol{\theta} + \mathbf{B}_c u$ を $\Delta t = 10$ s で差分化：

$$\frac{\boldsymbol{\theta}_{k+1} - \boldsymbol{\theta}_k}{\Delta t} \approx \mathbf{A}_c\boldsymbol{\theta}_k + \mathbf{B}_c u_k$$

整理すると：

$$\mathbf{A}_d = \mathbf{I} + \mathbf{A}_c\,\Delta t,\quad \mathbf{B}_d = \mathbf{B}_c\,\Delta t$$

$\mathbf{A}_c$ の実装（thermal_model.py）：

r = alpha / dx**2   # r = 1.2e-5 / 0.01 = 0.0012
h = h_conv / (rho_cp * dx)

# 内部節点 i
A_c[i, i-1] = +r
A_c[i, i  ] = -2*r
A_c[i, i+1] = +r

# 端部節点（対流冷却あり）
A_c[0, 0] = -r - h
A_c[0, 1] = +r

離散時間状態方程式

状態方程式（システムモデル）
$$\boldsymbol{\theta}_{k+1} = \mathbf{A}_d\,\boldsymbol{\theta}_k + \mathbf{B}_d\,u_k + \mathbf{w}_k$$
$\mathbf{w}_k \sim \mathcal{N}(0, \mathbf{Q})$：プロセスノイズ（モデル誤差）
安定条件の確認：
$r\,\Delta t = 0.0012 \times 10 = 0.012 \ll 0.5$ ✅

Step 3：観測式

観測方程式（センサモデル）
$$\mathbf{y}_k = \mathbf{H}\,\boldsymbol{\theta}_k + \mathbf{v}_k$$
$\mathbf{H} \in \mathbb{R}^{2 \times 10}$：Node 0, Node 9 のみ取り出す行列
$\mathbf{v}_k \sim \mathcal{N}(0, \mathbf{R})$：観測ノイズ

03 — 理論：カルマンフィルタ

線形カルマンフィルタのアルゴリズム

記号の定義
$\hat{\boldsymbol{\theta}}_k^- \in \mathbb{R}^{10}$予測ステップ後の推定温度ベクトル（観測反映前）
$\hat{\boldsymbol{\theta}}_k^+ \in \mathbb{R}^{10}$更新ステップ後の推定温度ベクトル（観測反映済み）
$\mathbf{P}_k^- \in \mathbb{R}^{10\times10}$予測誤差共分散行列：推定誤差の大きさと相関を表す
$\mathbf{P}_k^+ \in \mathbb{R}^{10\times10}$更新後誤差共分散行列：観測後に不確かさが減少
$\mathbf{Q} \in \mathbb{R}^{10\times10}$プロセスノイズ共分散：モデル誤差の大きさ
$\mathbf{R} \in \mathbb{R}^{2\times2}$観測ノイズ共分散：センサ精度の逆数に相当
$\mathbf{K}_k \in \mathbb{R}^{10\times2}$カルマンゲイン：2点センサ → 10節点全体への「重み行列」

予測ステップ（Predict）

状態の時間発展
$$\hat{\boldsymbol{\theta}}_k^- = \mathbf{A}_d\,\hat{\boldsymbol{\theta}}_{k-1}^+ + \mathbf{B}_d\,u_{k-1}$$
誤差共分散の時間発展
$$\mathbf{P}_k^- = \mathbf{A}_d\,\mathbf{P}_{k-1}^+\,\mathbf{A}_d^\top + \mathbf{Q}$$ 
def predict(self, u):
    self.x = self.A @ self.x + self.B @ u
    self.P = self.A @ self.P @ self.A.T + self.Q

更新ステップ（Update）

カルマンゲイン
$$\mathbf{K}_k = \mathbf{P}_k^-\,\mathbf{H}^\top\!\left(\mathbf{H}\,\mathbf{P}_k^-\,\mathbf{H}^\top + \mathbf{R}\right)^{-1}$$
状態の更新（イノベーション反映）
$$\hat{\boldsymbol{\theta}}_k^+ = \hat{\boldsymbol{\theta}}_k^- + \mathbf{K}_k\!\left(\mathbf{y}_k - \mathbf{H}\,\hat{\boldsymbol{\theta}}_k^-\right)$$
誤差共分散の更新
$$\mathbf{P}_k^+ = \left(\mathbf{I} - \mathbf{K}_k\,\mathbf{H}\right)\mathbf{P}_k^-$$
カルマンゲインの直感： $\mathbf{K} \approx \dfrac{\text{モデルの不確かさ } \mathbf{P}}{\text{モデル不確かさ} + \text{センサノイズ } \mathbf{R}}$  →  $\mathbf{R}$ が大きい（ノイズ多）→ K 小 → モデル重視  /  $\mathbf{P}$ が大きい（モデル不確か）→ K 大 → センサ重視

03 — 理論

カルマンゲインの導出（最小分散推定）

カルマンゲイン $\mathbf{K}$ は「推定誤差の分散を最小にする最適な重み行列」として導出される。 「センサ観測をどれだけ信じるか」という重みを、モデル誤差とセンサ誤差の比から自動計算する。

Step 0 — 何を最小化するか？

更新式を線形に仮定する： $$\hat{\mathbf{x}}^+ = \hat{\mathbf{x}}^- + \mathbf{K}(\mathbf{y} - \mathbf{H}\hat{\mathbf{x}}^-)$$ $\mathbf{K}$ をどう選べば推定誤差が最小になるか？
目標：事後誤差共分散 $\text{tr}(\mathbf{P}^+)$ を最小化。

Step 1 — $\mathbf{P}^+$ を $\mathbf{K}$ で表す

事後誤差 $\mathbf{e}^+ = \mathbf{x} - \hat{\mathbf{x}}^+$ を計算すると： $$\mathbf{e}^+ = (\mathbf{I} - \mathbf{K}\mathbf{H})\mathbf{e}^- - \mathbf{K}\mathbf{v}$$ （$\mathbf{e}^-$：事前誤差、$\mathbf{v}$：観測ノイズ）
事後共分散： $$\mathbf{P}^+ = (\mathbf{I}-\mathbf{K}\mathbf{H})\mathbf{P}^-(\mathbf{I}-\mathbf{K}\mathbf{H})^\top + \mathbf{K}\mathbf{R}\mathbf{K}^\top$$

Step 2 — $\mathbf{K}$ で微分してゼロと置く

$\text{tr}(\mathbf{P}^+)$ を $\mathbf{K}$ で微分してゼロと置く： $$\frac{\partial\,\text{tr}(\mathbf{P}^+)}{\partial \mathbf{K}} = -2\mathbf{P}^-\mathbf{H}^\top + 2\mathbf{K}(\mathbf{H}\mathbf{P}^-\mathbf{H}^\top + \mathbf{R}) = \mathbf{0}$$

Step 3 — 最適ゲイン $$\boxed{\mathbf{K} = \mathbf{P}^-\mathbf{H}^\top \!\left(\mathbf{H}\mathbf{P}^-\mathbf{H}^\top + \mathbf{R}\right)^{-1}}$$ この $\mathbf{K}$ を代入すると $\mathbf{P}^+ = (\mathbf{I} - \mathbf{K}\mathbf{H})\mathbf{P}^-$ に整理できる。
物理的解釈：
分子 $\mathbf{P}^-\mathbf{H}^\top$：モデルの不確かさをセンサ空間に射影した量
分母 $\mathbf{H}\mathbf{P}^-\mathbf{H}^\top + \mathbf{R}$：センサ空間での合計不確かさ
→ $\mathbf{K}$ = モデル不確かさ ÷ 合計不確かさ = センサへの信頼度割合
