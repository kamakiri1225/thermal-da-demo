# EnKF と PF の比較

同一の真値・同一の観測(seed 一致)で EnKF と PF を走らせ、でたらめな初期状態からの
収束を比較する。

## 1. 高速プロトタイプ(ROM)での比較

`run/compare_enkf_pf.py` が両フィルタを同条件で回し、全ノード温度 RMSE の時刻歴を重ねる:

![EnKF vs PF RMSE](img/enkf_vs_pf_rmse.png)

観察(ROM、5ノード・2点観測):

- **EnKF(N=60)**: でたらめ初期(RMSE ~10 K)から急速に収束し、観測ノイズ(0.3 K)を
  下回る水準まで到達。未観測ノードも共分散を通じてよく補正される。
- **PF(N=400)**: 収束はするが EnKF より遅く・浅い。少数の観測に対し高次元の状態を
  重み付けするため、リサンプリング後の**粒子貧困化**で分散を過小評価し、
  未観測ノードにバイアスが残りやすい。粒子数を増やすと改善する。

要約値は `results/compare_summary.yaml`。

## 2. 一般的な特徴の整理

| 観点 | EnKF | PF |
|------|------|-----|
| 分布の仮定 | ガウス近似 | 任意(非ガウス・多峰OK) |
| 高次元(場)への強さ | 強い(低ランク更新) | 弱い(次元の呪い) |
| 必要サンプル数 | 数十〜 | 高次元では非常に多く必要 |
| 主な弱点 | 非ガウスを表現できない・共分散過小評価(要インフレーション/局所化) | 粒子貧困化・退化(要リサンプリング/正則化) |
| CFD/CHT との相性 | 良い(標準的に使われる) | 低次元・強非線形向き |

## 3. OpenFOAM 連成版での比較

`103_0` の `run/run_openfoam_enkf.py` と本フォルダの `run/run_openfoam_pf.py` は
同一の真値・観測を用いるため、生成される

- `103_0_openfoam_da_enkf/results/openfoam_enkf_summary.yaml`
- `103_1_openfoam_da_pf/results/openfoam_pf_summary.yaml`

の `rmse_field_final_K` と `Q_final_W` を比べれば、field-space での両手法の
収束・パラメータ推定精度を直接比較できる。

> **本ケースの最小実行(N=5)について**: 約2万次元の温度場に対し5メンバー/粒子は
> 非常に少ないため、両手法とも「全体オフセット＋Q」の補正が主になる。手法差を
> はっきり見たい場合は、まず軽い ROM 版(上の比較図)で確認し、OpenFOAM 版は
> メンバー数を増やして回すとよい。
