## 結果の扱い

実ソルバ版の結果は保存CSV・YAML・ログに基づきます。重いOpenFOAM／FrontISTR同化計算は資料作成時に再実行していません。ROMは現設定で再計算し、初期RMSE 9.738172 K、同化後最終0.0388469 K、同化なし最終2.614447 Kを確認しました。

既存の説明・図で誤解されやすい点を、発表資料では明確にしています。

- ROMで同化するのは温度2成分のみ。変位は予測・表示用です。
- 温度のみ／温度＋変位の統制比較は未実施であり、変位追加の優位性を実証したとは記載していません。
- 3D比較図の左は0秒の初期平均です。同化なしで20秒まで進めた結果ではありません。
- 温度場RMSEはセル等重み。CSVの `rmse_obs_K` は同じ値の複写なので独立指標として掲載していません。
- Qの帯はメンバーの表示用標準偏差です。推定平均の信頼区間ではありません。
- 変位予報図はログから再描画し、実計算されていない0秒のゼロ値を除いています。
- 固定補間・一定物性の線形静解析を「ソルバを経由するから非線形」とは説明していません。

## 編集と再生成

`slides.json` と `slides.css` を編集して、以下を実行します。生成されたMarkdown／HTMLだけを編集しても、再生成すると元に戻ります。

```bash
python3 presentation/build_presentation.py
```

上記は104ケース直下から実行します。Pythonライブラリは NumPy、Matplotlib、WeasyPrint、変換コマンドは Pandoc を使用します。日本語フォントは Noto Sans CJK JP を指定しています。数式はSVGとして生成し、PDF／HTMLで共通表示します。

`assets/` は発表用に描き直した図・数式です。既存のdocsや解析ケースは変更しません。
