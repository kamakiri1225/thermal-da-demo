# よくある疑問 ― サイクル・時間刻み・アンサンブルの計算回数

`rom_fem_temperature.png`(ROM版, 60メンバー, 0→600s, 観測20秒ごと)を見ながら
出てくる素朴な疑問に答える FAQ。共分散の数式そのものは
[`06_ensemble_calculation.md`](06_ensemble_calculation.md)、
理論全体は [`02_beginner_guide.md`](02_beginner_guide.md) を参照。

## Q1. 観測点(赤い点)はなぜバラバラに散らばっているの?

**わざと測定ノイズを加えているから**(バグではない)。双子実験では観測を
「真値＋ノイズ」で作る:

$$y_n = T^\mathrm{true}(t_n) + \varepsilon_n, \qquad \varepsilon_n \sim N(0,\ \sigma^2), \quad \sigma = 0.30\ \text{℃}$$

- 赤点 = 黒破線(真値)に標準偏差 0.30℃ の正規乱数を足したもの → 上下に散らばる
- 設定 `config/da_config.yaml` の `noise_C: 0.30`、生成 `dacore/observations.py`
- 今回は600秒でも温度上昇が約5℃と小さいので、0.3℃のノイズが相対的に目立つ

**むしろ良いこと**: 赤点がばらついても青線(データ同化)は黒破線に滑らかに乗る。
EnKF が複数時刻・複数メンバーの情報を統計的に平均し、**ノイズを均して**
真の滑らかな履歴を復元している。赤点まで完全に追うのは過剰適合で逆に悪い。

## Q2. 分散は毎秒計算しているの?

**いいえ。平均・分散・EnKF更新は観測が来る20秒ごとだけ。** 2つの時間刻みを分けて考える:

| | 刻み | 何をするか | 600秒で何回 |
|---|------|-----------|------------|
| **前進計算(予報)** | 1秒ごと | 60メンバーを ROM で積分するだけ(統計は取らない) | 各メンバー600ステップ |
| **平均・分散・EnKF更新(解析)** | **20秒ごと** | 60メンバーから平均・共分散を出し観測で補正 | **30回だけ** |

- `model_dt_s: 1.0` … メンバーを1秒刻みで前へ進める(ただの積分)
- `obs_interval_s: 20.0` … 20秒ごとに観測が来たときに**だけ**平均・分散を計算して更新

$$\underbrace{1\text{s}\to 2\text{s}\to\dots\to 20\text{s}}_{\text{60メンバーをただ前進(分散計算なし)}}
\;\xrightarrow{\ 20\text{s: 観測}\ }\;
\underbrace{\text{平均・分散を計算して補正}}_{\text{1回}}\;\to\;\cdots$$

分散・共分散を計算するのは「観測とどう混ぜるか(カルマンゲイン)」を決める瞬間だけ。
予報の間は各メンバーを独立に走らせるだけでよい。

## Q3. 「30サイクル」とはどういう意味? 数秒おき?

**サイクル = データ同化を1回まわすこと**(時間の単位ではなく回数)。
1サイクル = 「予報 → 観測 → 補正」の1セット。

$$\underbrace{60\text{メンバーを20秒ぶん前進}}_{\text{予報}}\;\to\;
\underbrace{20秒時点の観測}_{\text{観測}}\;\to\;
\underbrace{平均・分散で補正}_{\text{解析}}$$

今回は観測が20秒ごとなので、**1サイクル = 20秒ぶんの処理**。

$$600\ \text{s} \div 20\ \text{s} = 30\ \text{回} \;\Rightarrow\; \textbf{30サイクル}$$

```
t= 20s → 1サイクル目(1回目の補正)
t= 40s → 2サイクル目
   ⋮
t=600s → 30サイクル目
```

「数秒おき」に見えたのは**前進計算(1秒刻み)**の方。
**サイクル(平均・分散を出して補正する回)は20秒おきに30回**。
観測を密にしたいなら `obs_interval_s` を小さくする(例: 5.0 → 120サイクル)。

## Q4. 平均・分散を出すのに、結局アンサンブルを何回計算しているの?

その図(ROM版)の設定での回数:

| 項目 | 回数 |
|------|------|
| アンサンブル数 | 60 メンバー |
| 平均・共分散の計算 | **31回**(初期 t=0 ＋ 30サイクル)、1回あたり60サンプル |
| メンバーの前進計算 | 60メンバー × 30サイクル = **1800区間** |
| 真値ラン | 1本(0→600s 通し) |

平均・分散の式(各時刻ごとに60メンバーから1回):

$$\bar{T}(t) = \frac{1}{60}\sum_{i=1}^{60} T^{(i)}(t), \qquad
P(t) = \frac{1}{60-1}\sum_{i=1}^{60}\big(T^{(i)}(t)-\bar{T}(t)\big)^2$$

**分母の注意**: EnKF の共分散(ゲイン計算)は不偏の **N−1=59** で割る。
表示用の ±1σ 帯は N=60 で割ることもある(詳細は `06_ensemble_calculation.md`)。

> OpenFOAM 実機版は1メンバーが重いので **5メンバー × 2サイクル**。
> ROM版は軽いので 60メンバー × 30サイクルと多く回せる(=分布がなめらか)。
> メンバーが多いほど平均・共分散は正確になるが、その分計算回数が増える。

## Q5. でたらめ初期からでも、なぜ「すぐ」直るの?

- 出発点は各ノード 10〜50℃ バラバラ(真値20℃から RMSE 9.74 K)
- 観測は20秒ごと。**最初の1〜2サイクル(20〜40秒)で真値にほぼ吸い付く**
- 最終的に RMSE 0.039 K(観測ノイズ0.3Kより小さい)

速い理由:
1. **観測が頻繁**(20秒ごと)に入り、そのたびに引き戻される
2. **アンサンブルの相関**で、hot/cold の2点を直すと未観測の mid/top/core も同時に直る
3. 初期のばらつきが大きい=カルマンゲインが大きい=観測を強く信じて**大きく修正**できる

**直ったまま保てる**のは、温度だけでなく**発熱量 Q も同時推定**しているから。
Q が間違ったままだと次の瞬間からまたズレる(=灰色の「同化なし」線が発散する理由)。
Q を正しく直すので、その後の物理発展も真値と同じ道をたどり続ける。
