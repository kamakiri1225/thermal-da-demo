# FrontISTR変位による補正を実データで手計算する

「変位観測がどうやって温度場を直すのか」を、**実際に走った600s計算サイクル1の
ログ値だけ**を使って手計算で再現する。使う数字はすべて
`openfoam/run_enkf_600.log` の実測値。姉妹編: `10_q_estimation_explained.md`（記号の定義）。

---

## ① 各メンバーの変位を「実際にFrontISTRで」計算（予報観測）

t=60s、5メンバーの温度場をそれぞれFrontISTRに通した結果（実ログ）:

| member | T@hot [℃] | FrontISTRの上面変位 uz [µm] |
|--------|-----------|------------------------------|
| 0 | 47.8（熱すぎ） | **+32.96**（伸びすぎ） |
| 1 | 27.1 | +7.82 |
| 2 | 11.9（冷たすぎ） | **−10.05**（縮んでいる） |
| 3 | 20.3 | −0.77 |
| 4 | 38.1 | +21.38 |

**熱いメンバーほど伸びる** ― この5点の並びそのものが「温度と変位の相関」のデータ。
FrontISTRの役割はここまで（変位の予報値を作る係）。補正の計算はここからEnKF。

## ② 相関からゲインを作る

5メンバーのばらつき（平均からのズレの積の平均）で標本共分散を計算:

$$\mathrm{cov}(T_\mathrm{hot},u_z)=\frac{1}{N-1}\sum_i \delta T_i\,\delta u_i = 243.9\ \mathrm{K\cdot µm}$$

$$\mathrm{var}(u_z)=\frac{1}{N-1}\sum_i \delta u_i^2 = 294.8\ \mathrm{µm}^2$$

カルマンゲイン（このセルに対する変位1成分ぶん）:

$$K=\frac{\mathrm{cov}(T,u_z)}{\mathrm{var}(u_z)+R}=\frac{243.9}{294.8+0.01}=0.827\ \mathrm{K/µm}$$

意味: 「**変位が1µmズレていたら温度を0.83K直せ**」という換算係数。
誰も教えていないのに、①の5点の並びから自動的に出てくる。

## ③ 観測とのズレ × ゲイン ＝ 補正

観測（真値の変位＋ノイズ）は $u_z^{obs}=1.79$ µm。各メンバーの更新
$T_a=T_f+K\,(u_z^{obs}-u_z^{f})$:

| member | ズレ (観測−予報) [µm] | 補正量 [K] | 補正後 [℃] |
|--------|----------------------|-----------|------------|
| 0 | −31.2 | **−25.8** | 22.0 |
| 1 | −6.0 | −5.0 | 22.1 |
| 2 | +11.8 | **+9.8** | 21.7 |
| 3 | +2.6 | +2.1 | 22.4 |
| 4 | −19.6 | −16.2 | 21.9 |

「**伸びすぎ→冷やす、縮みすぎ→温める**」を係数どおり機械的に適用しただけで、
47.8℃も11.9℃も**全員22℃前後（真値）に収束**。実際の本番ログでもサイクル2開始時の
メンバーは23℃台であり、この手計算とよく一致する。

## ④ 本番との違い（ここだけ拡張されている）

- 実際は T@hot 1セルではなく**全20,696セルそれぞれ**に同じ計算をする
  （セルごとに $\mathrm{cov}(T_\text{cell},u_z)$ を持つ）→ **場全体が一斉に補正**される
- 観測は変位2点＋温度2点の4成分で、$K=C_{zy}(C_{yy}+R)^{-1}$ の4×4逆行列版になる
- 発熱量 Q も状態に入っているので、$\mathrm{cov}(Q,u_z)$ を通じて Q も同時に直る

## 数字の再現コード

```python
import numpy as np
T  = np.array([47.83, 27.05, 11.95, 20.30, 38.09])   # ℃ 実ログ
uz = np.array([32.96,  7.82,-10.05, -0.77, 21.38])   # µm 実ログ
y  = 1.79                                            # µm 観測
dT, du = T-T.mean(), uz-uz.mean()
K = (dT@du/4) / (du@du/4 + 0.1**2)                   # 0.827 K/µm
print(T + K*(y-uz))    # → 全員 22℃前後
```
