## 購入時の注意

1. **MAX31855 と MAX6675 を間違えない**。MAX6675は旧型（分解能0.25°C、負温度不可）。
2. **BME280 と BMP280 を間違えない**。BMP280は湿度が測れない。商品名に「BME280」とあっても届くのはBMP280という粗悪品があるため、レビューを確認。
3. ESP32-DevKitC は**技適マーク付き**（国内正規流通品）を選ぶ。
4. microSDモジュールは5V専用（レベルシフタ+3.3Vレギュレータ構成で5V入力前提）の物があるので、**3.3Vで動作する物**を選ぶ。
5. 熱電対のコネクタ形状（ミニプレート/むき出し線）と MAX31855 モジュールの端子台が合うか確認。むき出し線ならネジ端子台付きモジュールが楽。
