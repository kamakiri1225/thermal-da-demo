# 配線表（ESP32 + MAX31855 + BME280 + microSD）

更新日: 2026-07-17

対象スケッチ: `arduino/sketches/esp32_thermal_logger/esp32_thermal_logger.ino`

---

## 全体の考え方

- **SPI機器が2種類**（MAX31855 と microSD）あるが、**SCK / MISO / MOSI は共通のバスに相乗り**してよい。
  区別は **CS（チップセレクト）ピンだけ別々**にすることで行う。
- **BME280 は I2C 接続**（SPI とは別の2本線。SDA/SCL）。
- **ESP32 は 3.3V ロジック**。各モジュールは 3.3V 対応品を選ぶこと（多くのモジュールは3.3V/5V両対応だが、必ず仕様を確認）。
- 電源はすべて ESP32 の **3V3 ピンから供給**する（今回の構成の消費電流なら足りる）。

## ピン割り当て一覧（ESP32-DevKitC）

| 役割 | ESP32ピン | 接続先 |
|---|---|---|
| SPIクロック | GPIO18 (SCK) | MAX31855 全個 + microSD の SCK/CLK |
| SPIデータ入力 | GPIO19 (MISO) | MAX31855 全個の SO/DO + microSD の MISO/DO |
| SPIデータ出力 | GPIO23 (MOSI) | microSD の MOSI/DI のみ（**MAX31855には不要**） |
| CS: 表面温度1 | GPIO25 | MAX31855 #1 の CS |
| CS: 表面温度2（増設時） | GPIO26 | MAX31855 #2 の CS |
| CS: 表面温度3（増設時） | GPIO27 | MAX31855 #3 の CS |
| CS: 表面温度4（増設時） | GPIO33 | MAX31855 #4 の CS |
| CS: microSD | GPIO5 | microSDモジュールの CS |
| I2Cデータ | GPIO21 (SDA) | BME280 の SDA |
| I2Cクロック | GPIO22 (SCL) | BME280 の SCL |
| 電源 | 3V3 | 全モジュールの VCC/VIN |
| グラウンド | GND | 全モジュールの GND |

## モジュール別配線表

### MAX31855（K型熱電対アンプ）× 1〜4個

| MAX31855ピン | ESP32ピン | 備考 |
|---|---|---|
| VIN (VCC) | 3V3 | 3.3Vで駆動 |
| GND | GND | |
| CLK (SCK) | GPIO18 | 全個共通 |
| DO (SO/MISO) | GPIO19 | 全個共通 |
| CS | GPIO25 / 26 / 27 / 33 | **個体ごとに別ピン** |
| T+ / T− | K型熱電対 | 極性あり。逆だと温度変化が逆向きに出る |

- MAX31855 は読み出し専用のセンサなので **MOSI(DI)端子はそもそも存在しない**。
- 熱電対の極性チェック: 先端を指でつまんで温度が「上がれば」正しい。下がるなら T+/T− を入れ替える。

### BME280（温湿度・気圧、I2C接続）

| BME280ピン | ESP32ピン | 備考 |
|---|---|---|
| VIN (VCC) | 3V3 | 3.3V駆動 |
| GND | GND | |
| SDA | GPIO21 | |
| SCL | GPIO22 | |
| SDO | （開放 or GND） | GND=アドレス0x76、3V3=0x77。スケッチは両方試すのでどちらでも動く |
| CSB | 3V3 または未接続 | I2Cモードにするため（モジュールによっては端子なし） |

### microSDカードモジュール（SPI接続）

| SDモジュールピン | ESP32ピン | 備考 |
|---|---|---|
| VCC | 3V3 | **3.3V対応モジュールを使うこと**（5V専用品に注意） |
| GND | GND | |
| CLK (SCK) | GPIO18 | 共通バス |
| MISO (DO) | GPIO19 | 共通バス |
| MOSI (DI) | GPIO23 | |
| CS | GPIO5 | |

- microSDカードは **FAT32でフォーマット**（32GB以下推奨）。
- 5V用のレベル変換IC付きモジュールは、3.3V供給だと動かないことがある。「3.3V対応」明記の物を選ぶ。

## 配線イメージ（テキスト図）

```
                        ┌──────────────┐
   K型熱電対 ──T+/T−──▶│  MAX31855 #1 │
                        │  CS=GPIO25   │──┐
                        └──────────────┘  │
                        ┌──────────────┐  │   SPIバス共通
   （増設時）K型熱電対─▶│  MAX31855 #2 │──┤   SCK  = GPIO18
                        │  CS=GPIO26   │  │   MISO = GPIO19
                        └──────────────┘  │   MOSI = GPIO23（SDのみ）
                        ┌──────────────┐  │
                        │  microSD     │──┘
                        │  CS=GPIO5    │
                        └──────────────┘
                        ┌──────────────┐      I2C
                        │  BME280      │───  SDA = GPIO21
                        │  addr 0x76   │───  SCL = GPIO22
                        └──────────────┘
   すべてのモジュール: VCC → 3V3, GND → GND
```

## 実体配線時の注意

1. **ブレッドボードの電源レール**に 3V3 と GND を先に引き、各モジュールはレールから取る。
2. SPIの共通線（SCK/MISO）は**数珠つなぎ**でよい。配線は短めに。
3. **BME280 は ESP32 基板から 10cm 以上離す**。ESP32やUSB給電部の発熱を拾うと雰囲気温度が 1〜3°C 高く出る。ジャンパ線で浮かせるか、別の小基板に載せる。
4. 熱電対の**補償導線を途中で他の金属線に継がない**（異種金属接点が新たな熱電対になり誤差が出る）。
5. 表面温度の測り方（README の測定注意も参照）:
   - 熱電対先端を対象面に**密着**させ、カプトンテープで固定
   - 必要なら小さなアルミテープで押さえる（大きく貼ると表面の放射・対流条件を変えてしまう）
   - 線は先端から数cmの部分も面に沿わせて固定（線からの熱逃げ＝フィン効果を減らす）
