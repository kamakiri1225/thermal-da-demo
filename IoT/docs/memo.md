# K型熱電対 温度測定 メモ

## 目的

K型熱電対を使って固体表面温度を測定する。
将来的にはOpenFOAMの計算結果とデータ同化を行う。

---

## 現在持っているもの

| 品目 | 状態 |
|---|---|
| Arduino UNO | 所持済み |
| K型熱電対 | 所持済み |
| PC | 所持済み |

## 購入予定・必要なもの

| 品目 | 用途 |
|---|---|
| MAX31856搭載 熱電対アンプモジュール | 熱電対のSPI読み取り |
| ジャンパーワイヤ | 配線 |
| USBケーブル | Arduino-PC接続 |
| 粘土 | 熱電対の固定 |
| ゴムテープ | 熱電対の固定（低温用） |
| カプトンテープ または アルミテープ | 熱電対の固定（高温対応） |
| 熱伝導グリス（あれば） | 熱電対と固体の密着性向上 |

  ↓

## Arduino UNO と MAX31856 の配線

| MAX31856側 | Arduino UNO側 |
|---|---|
| VIN / VCC | 5V |
| GND | GND |
| SCK / CLK | D13 |
| SDO / DO / MISO | D12 |
| SDI / DI / MOSI | D11 |
| CS / CSB | D10 |

**注意**: MAX31856モジュールは5V Arduino対応またはレベル変換回路搭載のものを使うこと。
スイッチサイエンスやAdafruit系が候補。

---

## K型熱電対の極性

| 線の色 | 極性 |
|---|---|
| 黄色 | + |
| 赤色 | - |

**確認方法**: 熱電対の先端を指でつまんで温度が上がればOK。下がるなら +/- が逆。

## 固体温度測定の固定方法

### 基本構成（推奨）

```
粘土
──────
カプトンテープ or アルミテープ
──────
熱伝導グリス（あれば）
──────
熱電対の先端  ← ここが固体に直接触れる
──────
固体表面
```

**重要**: ゴムテープや粘土を熱電対と固体の間に挟まないこと。
熱を伝えにくく測定値がズレる原因になる。

### 温度帯別の固定材料

| 温度帯 | 推奨材料 |
|---|---|
| 〜50℃ | ゴムテープ（試験的に可） |
| 80〜100℃以上 | カプトンテープ、アルミテープ、耐熱固定具 |

---

## トラブルシューティング

| 症状 | 確認すること |
|---|---|
| MAX31856が見つからない | CS, SCK, MISO, MOSI, GNDの配線 |
| 温度が表示されない | 熱電対の接続、断線 |
| nan が出る | 熱電対未接続、断線、極性ミス |
| 指で温めると温度が下がる | 熱電対の +/- が逆 |
| 温度が大きくズレる | K型設定（MAX31856_TCTYPE_K）になっているか |
| 値がふらつく | 熱電対先端の接触不良、配線のゆるみ、ノイズ |
| 固体温度が低めに出る | 熱電対が固体に密着していない、空気に冷やされている |
