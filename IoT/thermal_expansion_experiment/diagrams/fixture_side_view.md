# 治具 側面図・断面図（概念図）

## 側面図

```
        軸方向ストッパ
             ↓
        ┃●===========================================□
        △                                        △    ●
      支持点1                                  支持点2  ↑
     (左, 固定寄り)                          (右, 自由端寄り)  インジケータ
                                                          (デジマチック)

        └──────────────┬──────────────────────────────┘
                    断熱材(基台〜ヒーター間)
        ┌──────────────────────────────────────────────┐
        │                     基台                        │
        └──────────────────────────────────────────────┘
```

- インジケータ本体・電子回路（ESP32, MAX31856）は加熱部から離して設置する（`docs/03_mechanical_fixture.md`3.8-3.9節）。
- インジケータ測定軸と丸棒軸を一致させる（上下・左右とも傾かないよう調整、コサイン誤差対策）。

## 支持点の断面図（V支持、ベアリング方式）

```
        丸棒中心線
           |
           ○   ← 丸棒(φ20)
          / \
         o   o  ← ベアリング2個(V字配置、径方向支持・軸方向は低摩擦)
        /     \
    ―――――――――  ← 支持ブラケット/基台
```

## 支持点の断面図（Vブロック方式、代替案）

```
        丸棒中心線
           |
           ○   ← 丸棒(φ20)
          / \
         /   \
        ‾‾‾‾‾‾‾  ← 金属製Vブロック（滑らかな接触面）
    ―――――――――  ← 基台
```

## 左端ストッパ 断面イメージ

```
   丸棒端面
      |
      █ ←→ ┃ ストッパ(点/小面積接触、強くクランプしない)
      |
   （軸方向の移動のみを止める。横方向・上下方向は過度に拘束しない）
```
