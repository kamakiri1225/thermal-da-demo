## 2.6 購入時の注意（まとめ）

1. MAX31856とMAX31855・MAX6675を混同しない（本用途はMAX31856が必須：CJ補償・詳細フォルトが必要なため）。
2. インジケータ型番・ケーブル型番の適合は、購入前に必ずメーカー最新資料で確認する（**要メーカー仕様確認**）。
3. ESP32は技適マーク付き正規流通品を選ぶ。
4. ヒーターは寸法・電圧・最高使用温度を丸棒径・目標温度に合わせて選定する（**要確認**、`04_electrical_wiring.md`・`10_safety.md`参照）。
5. AC100V部品（SSR、ヒューズ、ケース等）は電気工作の基本知識がある人が選定・配線を確認すること。
