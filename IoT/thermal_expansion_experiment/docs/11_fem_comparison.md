# 11. FEM/理論値との比較の考え方

更新日: 2026-07-27

## 11.1 基本式

一様な温度変化を仮定する場合:

```
ΔL = α L ΔT
```

軸方向に温度が一様でない場合:

```
ΔL(t) = ∫[0,L] α(T(x,t)) [T(x,t) − T0(x)] dx
```

初期段階では、線膨張係数αを一定値として扱ってよい（`config/material_properties_sus304.json`参照）。ただし物性値は温度依存するため、一定値を使う場合はその仮定を明示すること。

## 11.2 平均温度の求め方（3点からの近似）

**単純平均（最初の候補）:**

```
T_avg = (T1 + T2 + T3) / 3
```

ただし、3点の単純平均は、実際の軸方向平均温度（∫T(x)dx/L）と一致しない可能性がある。特に加熱端付近で温度勾配が急な場合、単純平均は実際の平均より低め/高めに偏りうる。

**改善案（`python/analyze_experiment.py`に実装）:**

1. **区間ごとの線形補間 + 台形積分**: T1, T2, T3の測定位置(x1, x2, x3、`config/experiment_config.example.json`の`sensor_positions_mm_from_heated_end`)を使い、区間[0,x1], [x1,x2], [x2,x3], [x3,L]を線形補間して台形則で積分する。両端（x=0, x=L）の温度は最近傍の測定値で外挿する簡易近似とする（要検証）。
2. **温度センサ位置に基づく重み付き平均**: 各測定点が代表する区間の長さを重みとして平均する（線形補間による積分と近い結果になるが、より簡易な近似）。
3. **FEM温度分布を使った積分**: FEM側で得られる温度分布形状（正規化した分布パターン）を使い、3点の実測値をFEM分布にフィットさせてから積分する、より高度なアプローチ（将来課題）。

**近似熱膨張の計算（3点配置、実装方針）:**

`python/analyze_experiment.py`では、上記1の「線形補間+台形積分」をデフォルトの近似法として実装し、単純平均との差分も比較表示する。

```
ΔL_approx(t) = α × ∫[0,L] [T_interp(x,t) − T0_interp(x)] dx
```

（T_interp: 3点の線形補間による温度分布、T0_interp: 実験開始前の初期分布）

## 11.3 実験結果とFEMの比較項目

- 温度履歴（T1, T2, T3の時系列プロット、実験 vs FEM境界条件で計算した同位置の予測温度）
- 丸棒軸方向の温度分布（ある時刻での3点近似分布 vs FEMの連続分布）
- 自由端変位の時系列（実験 vs FEM熱構造解析、または簡易式 `ΔL=αLΔT`）
- 理論熱膨張量（単純式・積分式の両方）
- FEM解析結果との差・誤差率
- 再現性（繰返し試験3回の最大変位・時定数のばらつき）
- 加熱過程と冷却過程のヒステリシス（同じ平均温度に対する変位が昇温時と冷却時で異なるか。支持部摩擦・熱応答遅れ・治具の熱慣性が主な要因候補）
- 欠損データ数・センサ異常回数（MAX31856フォルト、spc_valid=0の回数）
- ドリフト補正前後の比較（ゼロ点・基台熱膨張補正の有無での変位カーブの違い）

## 11.4 FEM側の境界条件（未確定、方針のみ）

- 熱解析: ヒーター接触面の熱流束または表面温度境界、他表面は自然対流+放射（熱伝達係数は文献値または実験のドリフト試験から逆算することを推奨）。
- 構造解析: 支持点は径方向拘束のみ（軸方向自由）、左端は軸方向の変位基準点として1点のみ拘束するモデル化が、本治具の実際の拘束条件（3.1〜3.4節）に最も近い。
- 具体的な熱伝達係数・接触熱抵抗等のパラメータは**要確認**であり、無加熱ドリフト試験や予備加熱試験の結果からキャリブレーションすることを推奨する。

## 11.5 誤差率・再現性の定義（解析スクリプトでの実装方針）

- 誤差率: `(実験値 − FEM/理論値) / FEM/理論値 × 100 [%]`（ピーク変位、または任意時刻での比較）
- 再現性: 繰返し試験N回のピーク変位の標準偏差、または最大−最小の範囲
- ヒステリシス指標: 同一平均温度における昇温時変位と冷却時変位の差の最大値
