# 03. 治具設計

更新日: 2026-07-27

## 3.1 基本方針

以前検討した「完全片持ち（左端のみ強固定）」構造、および「縦吊り」構造は、以下の理由で**採用しない**。

**完全片持ちを採用しない理由:**
- 自重たわみが無視できない（3.5節で概算）
- 固定部の局所変形
- 棒の反り
- 自由端の上下移動、インジケータとの接触位置変化
- 固定部が熱膨張そのものを拘束してしまう
- 固定部からの熱逃げ
- 曲げ変形が軸方向測定値に混入する

**縦吊りを採用しない理由:**
水平自重たわみが減る・支持部摩擦がなくなるという利点はあるが、装置が背高になり転倒しやすい、上端固定部に荷重集中、ヒーターのずれ落ちや丸棒落下の危険、インジケータ配置と熱電対配線が扱いにくい、初心者向けの安全性が低い、という欠点が大きいため見送る。

**採用する基本方針:**

- 丸棒は**水平配置**
- 丸棒は**2点支持**
- 支持部は**軸方向に低摩擦**（丸棒が軸方向へ滑らかに伸びられるようにする）
- 軸方向の基準は**片側端面のみ**（左端ストッパ）
- 反対側（右端）は**自由端**とし、インジケータで変位を測定する
- 丸棒の外周は**強くクランプしない**

## 3.2 概念図（側面図・簡易）

```
        軸方向ストッパ
             ↓
        ┃●===========================================□
        △                                        △    ●
      支持点1                                  支持点2  ↑
     (左, 固定寄り)                          (右, 自由端寄り)  インジケータ
                                                          (デジマチック)

  ● : 丸棒端面が当たる基準点／インジケータ測定子
  △ : 低摩擦支持（ベアリングV支持 or Vブロック）
  = : SUS304丸棒 (φ20×300)
```

- 左端: 丸棒の端面がストッパに軽く当たる（=軸方向の原点）。強いクランプはしない。
- 右端: 自由端。ここにインジケータの測定子を当てる。
- 支持点1・2: 丸棒径方向（自重）を支える。軸方向には拘束しない（低摩擦）。
- ヒーターは支持点1寄り（左＝加熱側）に設置し、T1をその近傍、T3を自由端(右)近傍、T2を中央に配置する。

## 3.3 支持方法の候補

### 第一候補: 小型ベアリングによるV支持（推奨・仮案）

```
      丸棒(断面)
         ○
        / \
       o   o
     ベアリング(2個/箇所)
```

- 2個のベアリングを「V字」に配置し、丸棒を径方向に支える。
- ベアリングは自転できるため、丸棒が軸方向へ軽く移動する際の摩擦を大きく下げられる（回転方向の転がり抵抗のみで、軸方向はベアリング外輪と丸棒表面の接触＝多少の転がり摩擦は残る点に留意）。
- 左右方向（丸棒が転がって逃げる方向）への移動もV字形状で抑制できる。
- ベアリング寸法・耐熱条件は**要選定**（仮案: 内径5〜8mm程度の深溝玉軸受、ヒーター直近を避け熱害を回避）。

### 第二候補: 金属製Vブロック

- なめらかな接触面のVブロックで丸棒を受ける。
- 必要に応じてごく少量の高温対応潤滑剤を検討（種類・耐熱温度は要確認）。
- 軸方向摩擦は使用前に3.6節の予備試験で必ず評価する。

### 第三候補: 小径丸棒による簡易ローラー

- 小径の金属丸棒を横向きに置き、簡易的な転がり支持とする。
- 最も安価だが、位置決めと再現性は前2候補に劣る。

### 採用しない支持方法

- 木材へ直接丸棒を載せる構造: 摩擦、焦げ、熱変形、再現性の観点から本実験には不向き。木材は基台・支柱としては使用可能だが、加熱部からは離す。

## 3.4 軸方向拘束（左端ストッパ）

- 丸棒の端面をストッパへ当てるだけとし、外周を万力やクランプで強く締め付けない。
- ストッパが満たすべき条件:
  - 軸方向の移動だけを止める（横方向・上下方向は過度に拘束しない）
  - 接触面はできるだけ点または小面積
  - 熱膨張そのものを拘束しない
  - 加熱によるストッパ自体の熱変形を抑える（ストッパは加熱源から離す、または低膨張・断熱を検討）
  - 丸棒が離れない程度の軽い予圧を検討する（インジケータの測定力によって丸棒全体が左へ押されるため、ストッパがその反力を受ける）
- インジケータの押付力によって支持部（3.3節のベアリング/Vブロック）が軸方向にずれてしまわないか、組立後に必ず確認する。

## 3.5 自重たわみの概算

丸棒（SUS304、直径D=20mm、長さL=300mm）の自重による曲げたわみを、単純化した梁理論で概算する。

**使用する物性値**（`config/material_properties_sus304.json` より）:
- 密度 ρ = 7900 kg/m³
- ヤング率 E = 193 GPa
- 重力加速度 g = 9.81 m/s²

**断面諸量:**
- 断面積 A = π/4 × D² = π/4 × (0.02)² ≈ 3.1416×10⁻⁴ m²
- 単位長さ当たり自重 w = ρ×A×g ≈ 7900 × 3.1416×10⁻⁴ × 9.81 ≈ 24.35 N/m
- 断面二次モーメント I = π×D⁴/64 = π×(0.02)⁴/64 ≈ 7.854×10⁻⁹ m⁴

**(a) 完全片持ち（参考・不採用構造の比較用）:**

先端たわみ δ = w L⁴ / (8EI)

L⁴ = 0.3⁴ = 8.1×10⁻³ m⁴
δ ≈ 24.35 × 8.1×10⁻³ / (8 × 193×10⁹ × 7.854×10⁻⁹)
 ≈ 0.1972 / 12,125 ≈ **1.63×10⁻⁵ m ≈ 0.016 mm**

→ ユーザー既知の見積り「完全片持ちで約0.016mm」と整合。この値は想定熱膨張量0.4mm程度に対して約4%に相当し、無視できない大きさである。

**(b) 単純支持（2点支持、両端に支点と仮定した理想化）:**

等分布荷重の単純支持梁、中央たわみ δ = 5wL⁴ / (384EI)

δ ≈ 5 × 24.35 × 8.1×10⁻³ / (384 × 193×10⁹ × 7.854×10⁻⁹)
 ≈ 0.986 / 581,990 ≈ **1.7×10⁻⁶ m ≈ 0.0017 mm**

→ 完全片持ちの約1/10以下に低減される。2点支持を採用する設計上の根拠となる数値。

**注意点（要確認・簡易近似であることの明記）:**
- 支持点を丸棒の両端ぴったりに置けない場合（支持点を少し内側にする場合）、両端のオーバーハング部分の自重による回転・たわみが加わり、上記(b)より悪化する。支持スパンはできるだけ丸棒全長に近づけることを推奨。
- このたわみ自体は「鉛直方向」の変形であり、軸方向変位（インジケータの読み）に直接加算されるわけではない。ただし、以下を介して間接的に測定誤差へ混入しうる（`09_error_budget.md`参照）:
  - インジケータ軸と丸棒軸のずれ（コサイン誤差の増大）
  - 自由端の接触位置の変化
  - 丸棒の反りとの複合効果

## 3.6 摩擦・スティックスリップ確認（組立後の必須予備試験）

支持部の摩擦が大きいと、熱膨張が滑らかに測定されず、変位が階段状（スティックスリップ）になる可能性がある。**加熱試験前に必ず以下を確認する。**

**手順（無加熱状態）:**
1. 丸棒を手で軸方向に0.1〜0.2mm程度、そっと動かす。
2. 手を離したとき、毎回同じ位置へ戻るか確認する。
3. 押す方向と戻す方向で、インジケータの読みに差がないか確認する（ヒステリシス）。
4. 動かす際に「カクッ」と滑る感触がないか確認する。
5. インジケータの値を見ながら、ゆっくり荷重を変化させたとき、値が連続的に変化するか、階段状に飛ぶかを確認する。
6. 上記を3回以上繰り返し、再現性を確認する。

**判定の目安:**
- 戻り位置のばらつきがインジケータ分解能(0.001mm)の数倍以内であれば良好と判断する（具体的な許容値は目的精度に応じて`09_error_budget.md`で検討）。
- 明らかな階段状変化・大きなヒステリシスが見られる場合は、支持部の摩擦が大きすぎるため、支持方式の変更（ベアリングの追加潤滑、Vブロックの表面仕上げ見直し等）を検討する。

加熱試験中の変位履歴が階段状になる場合も、まずスティックスリップを疑うこと。

## 3.7 インジケータの配置

- インジケータの測定軸と丸棒の軸を一致させる（横から見ても上から見ても傾かないように調整）。コサイン誤差を抑えるため（`09_error_budget.md`参照）。
- 測定子が丸棒端面から外れないよう、端面の大きさと測定子径の関係を確認する。
- 加熱時の棒の反りにより接触位置がずれる可能性があるため、初回加熱試験で位置ずれの有無を目視確認する。
- インジケータ本体は高温部から離して設置する（本体樹脂部・電子部の耐熱性、および本体自体の温度上昇による誤差を避けるため）。
- 測定子の押込み量（初期セット位置）に、期待変位量(約0.4mm)+マージンを確保する。

**接触板（丸棒端面が粗い・斜め・不安定な場合）:**
- 候補: 薄いステンレス板、薄いアルミ板、小型の平座金、端面加工した治具部品
- 接着剤だけでの固定は高温時にずれる可能性があるため、可能な限り機械的固定（小ねじ、C型クリップ等）を検討する（**要確認・要実機確認**）。

## 3.8 基準フレームの熱変形（治具側の熱膨張混入）

インジケータで測定される「見かけの変位」は、概念的には以下のように分解できる。

```
測定変位 = 丸棒の熱膨張
         − 基準側治具の熱変位
         + インジケータ固定部の変位
         + 支持部の変位
         + その他誤差
```

対策:
- ヒーターから支持台・インジケータ固定台をできるだけ離す
- ヒーターと基台の間に断熱材を入れる（3.9節）
- 電子回路（ESP32, MAX31856）を加熱部から離す
- 基台自体の温度を把握する（余裕があれば予備の熱電対で基台温度も測定できるよう、`04_electrical_wiring.md`ではMAX31856を1枚拡張できる設計にしている）
- 無加熱状態で30〜60分のドリフト試験を行い、治具由来のドリフトの大きさを事前に把握する（`07_experiment_procedure.md`）

**定量的な注意点（例）:** 仮に基台がアルミ製（線膨張係数≈23×10⁻⁶/K）で、加熱の影響で基台の一部が3℃上昇し、その影響が及ぶ長さが400mm程度だとすると、
`ΔL_frame ≈ 23e-6 × 0.4 × 3 ≈ 27.6μm ≈ 0.028mm`
となり、想定変位0.4mmに対して約7%にも達しうる。基台材質の選定（低膨張材、または断熱により基台温度上昇そのものを抑える）が重要である。基台の温度を実測し補正することも検討する。

## 3.9 断熱材の配置

- ヒーターと基台の間に断熱材（セラミックウール等、高温対応品）を挟む。
- 支持部・インジケータ固定部は断熱材の外側（低温側）に配置する。

## 3.11 熱電対の固定（本ドキュメントからの参照、詳細は`04_electrical_wiring.md`・`08_calibration.md`）

- 熱電対先端は、ヒーターに直接触れず、丸棒表面温度を測る構成とする。
- 固定方法の候補: 薄い耐熱テープ（カプトン等）、ステンレスバンド、細い金属線、熱電対用溶接、熱伝導セメント。
- ポリイミド(カプトン)テープ単体は高温時に剥がれる可能性があるため、想定温度域が高い場合（目安100℃超）は、ステンレスバンドや熱伝導セメントとの併用、または溶接による恒久固定を検討する（**要確認**、目標最高温度が未確定のため最終選定は保留）。
