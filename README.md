# thermal-da-demo

カルマンフィルタを用いた熱データ同化（Data Assimilation）のデモプロジェクトです。  
「温度センサ数点の計測値だけで、測れていない場所の温度を正確に推定できるか」を検証します。

---

## やりたいこと（全体ゴール）

工作機械の熱変位補償を最終目標に、**データ同化（DA）× CAE シミュレーション** の組み合わせを段階的に構築します。

```
センサ計測値（少数点）
     ↓
カルマンフィルタ（データ同化）
     ↓
全節点の温度場を高精度に推定
     ↓
熱変位を予測 → 工作機械の加工誤差を補正
```

実機での計測はコストが高く、全節点の温度を直接測ることは困難です。  
DAを使えば、少数のセンサ情報と物理モデルを組み合わせることで、**測れていない場所の状態を確率的に推定**できます。

## sample/001_kalman_thermal_1d の詳細

### モデル概要

- **対象**: 長さ 1 m の 1 次元熱伝導棒（10 節点に離散化）
- **熱入力**: 節点 0（左端）に集中投入、10 分 ON → 5 分 OFF サイクル
- **センサ**: 節点 0・節点 9（両端）の温度、または熱変位（積分量）
- **時間刻み**: 10 秒

### 3 つの実験ケース

| | Case 1 (`main.py`) | Case 2 (`main_da_demo.py`) | Case 3 (`main_disp_obs.py`) |
|---|---|---|---|
| **目的** | 線形KFの基本動作確認 | 大きな初期誤差＋モデル誤差でのDA効果 | センサ種類（変位センサ）の効果検証 |
| **真値初期温度** | 20°C | 46°C（暖機済み） | 20°C |
| **推定側初期温度** | 22°C（+2°C 誤差） | 20°C（最大26°C 誤差） | 20°C |
| **熱入力誤差** | なし | 30% 過大（8,450 W/m） | なし |
| **センサ構成** | 温度 2 点（N0 + N9） | 温度 2 点（N0 + N9） | A: 温度2点 / B: 温度2点+変位 / C: 変位のみ |
| **RMSE 改善率** | 88〜95% | 大幅改善 | Case B が最高精度 |

### 実行方法

```bash
cd sample/001_kalman_thermal_1d

# Case 1: 基本デモ
python main.py

# Case 2: DA効果デモ（コールドスタート＋モデル誤差）
python main_da_demo.py

# Case 3: 変位センサ追加
python main_disp_obs.py
```

## 技術的背景

### データ同化とは

観測データ **y** と数値モデルの予測 **x̂⁻** を、それぞれの不確かさ（誤差共分散）に応じて最適に融合し、  
真の状態 **x** の最良推定値 **x̂⁺** を得る手法です。

```
予測ステップ:  x̂⁻ = A_d x̂  +  B_d u
              P⁻  = A_d P A_d^T + Q

更新ステップ:  K   = P⁻ H^T (H P⁻ H^T + R)^{-1}
              x̂⁺ = x̂⁻ + K (y - H x̂⁻)
              P⁺  = (I - KH) P⁻
```

- **Q**: プロセスノイズ共分散（モデルの不確かさ）
- **R**: 観測ノイズ共分散（センサの不確かさ）
- **K**: カルマンゲイン（両者のバランスを自動調整）

### なぜ変位センサが有効か

温度センサは「点」の情報しか与えませんが、  
熱変位 δ = α·Σ(θᵢ - T_ref)·dx は**全節点の積分量**です。  
1 つの変位センサが全節点の温度情報を間接的に提供するため、  
少ないセンサ数でも中央節点の推定精度が大幅に向上します。
