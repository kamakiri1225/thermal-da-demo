# 切削時の時間応答データ同化による構造モデルの接触部境界条件推定

## 1. 研究テーマの一文要約

工作機械の切削中に計測される振動・変位・加速度などの時間応答を使い、構造解析モデル内の「接触部境界条件」をデータ同化で推定する。

ここで推定したいのは、単なる変位や応力ではない。
リニアガイド、ボルト締結部、主軸支持部、テーブル・コラム結合部などに含まれる、モデル化しにくい接触面の剛性・減衰・摩擦的な境界条件である。

---

## 2. なぜこのテーマが重要か

工作機械の構造解析では、部品そのものの形状や材料物性は比較的モデル化しやすい。
一方で、実機と解析モデルのズレの多くは、部品同士の接触部・締結部・摺動部に起因する。

例えば次のような場所である。

- ボルト締結された構造接合面
- リニアガイドとベッドの取り付け面
- テーブル・サドル・コラムの接触面
- 主軸ユニットの支持部
- 摺動面・案内面
- 治具やワークの固定部

これらは、CAD形状だけでは正しく表現できない。
接触面の面圧、締結力、微小すべり、摩擦、油膜、組付け誤差によって、実効的な剛性や減衰が変わるためである。

その結果、構造解析では次のようなズレが生じる。

| 現象 | 解析と実機でズレやすい理由 |
|---|---|
| 固有振動数 | 接触面の実効剛性が未知 |
| FRF | 接触部の減衰が未知 |
| 切削中の振動応答 | 切削力と接触境界の両方が不確か |
| びびり発生条件 | モード、減衰、動剛性のズレが安定限界に直結 |
| 加工面品位 | 実機振動の予測誤差が加工痕へ波及 |

つまり、工作機械の構造解析を設計判断に使うには、接触部境界条件を実機に合わせて更新する必要がある。

---

## 3. 何を「逆問題」として解くのか

通常の順問題は、境界条件を与えて応答を計算する。

```text
構造モデル + 接触部境界条件 + 切削力
        ↓
変位・速度・加速度の時間応答
```

今回解きたいのは、この逆である。

```text
実機で測った時間応答
        ↓
どの接触部境界条件なら、その応答を再現できるかを推定
```

言い換えると、次の問題を解く。

> 実機の切削中応答に合うように、構造モデル内の接触部剛性・減衰を推定する。

ここで重要なのは、推定対象を「全節点の変位」にしないことである。
全節点変位を直接合わせると、観測点が少ないため不安定になりやすい。
そこで、推定対象を接触部の物理パラメータに絞る。

---

## 4. 推定対象

接触面を、ばね・ダンパで近似して考える。

| 記号 | 意味 | 例 |
|---|---|---|
| `k_n` | 法線方向接触剛性 | 面同士が押し合う方向の硬さ |
| `k_t` | 接線方向接触剛性 | 微小すべり方向の硬さ |
| `c_n` | 法線方向減衰 | 押し込み方向のエネルギ散逸 |
| `c_t` | 接線方向減衰 | すべり方向のエネルギ散逸 |
| `mu` | 摩擦係数 | 接線力と法線力の関係 |
| `F_preload` | 締結・予圧 | ボルト締結力、ガイド予圧など |

最初からすべてを推定すると難しい。
第一段階では、次のように簡略化するのが現実的である。

```text
推定対象 = 接触面ごとの等価剛性 k と等価減衰 c
```

---

## 5. 数式で見る問題設定

構造モデルの運動方程式を次のように書く。

```math
\mathbf{M}\ddot{\mathbf{u}}(t)
+ \mathbf{C}(\boldsymbol{\theta})\dot{\mathbf{u}}(t)
+ \mathbf{K}(\boldsymbol{\theta})\mathbf{u}(t)
= \mathbf{f}_{cut}(t)
```

ここで、

- `u(t)`: 節点変位
- `M`: 質量行列
- `C(theta)`: 減衰行列
- `K(theta)`: 剛性行列
- `f_cut(t)`: 切削力
- `theta`: 推定したい接触部境界条件

推定したいパラメータを次のようにまとめる。

```math
\boldsymbol{\theta}
=
\begin{bmatrix}
k_1 & k_2 & \cdots & c_1 & c_2 & \cdots
\end{bmatrix}^{\mathsf{T}}
```

センサで観測できるのは、全節点ではなく一部の応答だけである。

```math
\mathbf{y}(t)
=
\mathbf{H}\mathbf{u}(t)
+ \boldsymbol{\varepsilon}(t)
```

ここで、

- `y(t)`: 加速度・変位・主軸先端応答などの観測値
- `H`: 観測行列
- `epsilon(t)`: 観測ノイズ

逆問題としては、次を満たす `theta` を探す。

```math
\mathbf{y}_{meas}(t)
\simeq
\mathbf{H}\mathbf{u}(t; \boldsymbol{\theta})
```

## 6. なぜデータ同化を使うのか

単純な最適化でも、接触剛性を合わせ込むことはできる。
しかし切削中の構造応答は時間的に変化する。

例えば、

- 工具位置が変わる
- ワーク剛性が加工により変わる
- 温度上昇で接触状態が変わる
- 切削条件が変わる
- びびりに近づくと応答が急変する

そのため、1回だけ同定して終わるのではなく、時間応答を見ながら逐次的に更新する考え方が必要になる。

データ同化では、解析モデルの予測と実測データを繰り返し融合する。

```text
解析モデルによる予測
        ↓
実測応答との差を見る
        ↓
接触部パラメータを更新
        ↓
更新モデルで次の時刻を予測
```

この流れにより、実機の状態に追従する構造デジタルツインを作れる可能性がある。

---

## 7. 推奨する手法

### 第一段階: オフライン同定

最初は、切削実験または加振実験の時間応答を用いて、接触部剛性・減衰をまとめて推定する。

候補手法:

- 最小二乗法
- MAP推定
- Ensemble Kalman Filter
- Ensemble Smoother
- ベイズ最適化

目的は、実機に近い基準モデルを作ることである。

### 第二段階: 逐次推定

次に、時間応答を使って接触部パラメータを逐次更新する。

候補手法:

- Ensemble Kalman Filter
- Unscented Kalman Filter
- Particle Filter
- Moving Horizon Estimation

第一候補は Ensemble Kalman Filter でよい。
理由は、構造解析モデルが非線形化しても扱いやすく、状態変数とパラメータを同時推定できるためである。

---

## 8. 実験・検証の進め方

いきなり実機切削で始めると難しい。
段階的に検証するのがよい。

### Step 1: 数値実験

まず、正解パラメータを持つ簡単な構造モデルを作る。
そこから疑似観測データを作り、データ同化で正解パラメータを戻せるか確認する。

```text
正解モデル
  ↓ 疑似センサ応答
初期値をずらしたモデル
  ↓ データ同化
接触剛性・減衰を推定できるか
```

### Step 2: 加振実験

次に、切削力ではなくインパルスハンマや加振器で構造を励振する。
切削力が未知でないため、接触境界条件の推定に集中できる。

### Step 3: 非切削運転

主軸回転や送り運動だけの応答を見る。
この段階で、回転数依存の振動や機械状態の変化を扱う。

### Step 4: 切削実験

最後に、実際の切削中応答を用いる。
ここでは切削力も不確かになるため、接触境界条件と切削力を同時に扱う必要がある。

---

## 9. 評価指標

| 評価項目 | 見るもの |
|---|---|
| 時間応答RMSE | 予測変位・加速度が実測に合うか |
| FRF一致度 | 周波数応答が実機に近づくか |
| 固有振動数誤差 | 同化前後で固有値が改善するか |
| 減衰比誤差 | ピーク幅・減衰特性が合うか |
| びびり安定限界 | 安定限界予測が改善するか |
| 推定パラメータの安定性 | 不自然に暴れないか |

---

## 10. 研究としての新規性

このテーマの新規性は、単に「構造解析を実測で合わせ込む」ことではない。

新規性は次の点にある。

1. 切削中の時間応答を用いて、接触部境界条件を推定する
2. 状態変数ではなく、解析モデルの境界条件をデータ同化で更新する
3. 接触部パラメータの更新により、動剛性・びびり予測の精度改善を狙う
4. 工作機械の構造デジタルツインを、実機応答に追従するモデルへ近づける

---

## 11. 想定される難しさ

| 難しさ | 内容 | 対策 |
|---|---|---|
| 切削力が未知 | 応答のズレが接触条件由来か切削力由来か分けにくい | まず加振実験で検証する |
| パラメータが多い | 接触面ごとに剛性・減衰を持たせると同定不能になりやすい | 推定対象を少数の代表パラメータに絞る |
| 観測点が少ない | 全モードを観測できない | センサ配置と可観測性を検討する |
| ノイズが大きい | 切削中の加速度信号はノイズが多い | 周波数帯を限定し、フィルタ処理する |
| 計算コスト | FEMを毎時刻回すと重い | モード縮約、サロゲートモデルを使う |

---

## 12. 最初に作るべき最小モデル

最初は、実機全体ではなく、2自由度または3自由度のばね・質量・ダンパ系でよい。

```text
工具・主軸側質量  m1
        │ k_contact, c_contact
テーブル・構造側質量 m2
        │ k_base, c_base
固定端
```

このモデルで、

1. 正解の `k_contact`, `c_contact` を決める
2. 疑似的な切削力を入れる
3. 加速度応答を作る
4. 初期値をずらしたモデルからデータ同化で推定する

という検証を行う。

ここで成功すれば、次にFEMの縮約モデルへ進む。

---

## 13. 最終的な到達点

最終的には、次のような構造モデル更新システムを目指す。

```text
実機の切削中応答
    ↓
データ同化
    ↓
接触部境界条件を更新した構造モデル
    ↓
FRF・動剛性・びびり安定限界を再計算
    ↓
設計変更、保全、加工条件最適化へ反映
```

これは、工作機械の構造解析を「作って終わりのモデル」から「実機応答で更新され続けるモデル」へ変える研究である。
