# 研究方針まとめ: 熱変位予測のためのデータ同化

> 最終更新: 2026-06  
> 対象: 計算力学講演会・計算工学講演会レベルの研究発表を想定した方針メモ

---

## 1. 研究の核となる問い

> **「温度場を精度よく推定すれば、熱変位も精度よく予測できるのか？」**

これが本研究の差別化点。既存研究の多くは「温度センサ → FEM → 熱変位推定」の流れであり、温度場の精度と熱変位精度の関係を直接問うたものは少ない。

**面白い仮説**: 温度センサを増やすより、変位センサを 1 点加える方が熱変位予測には効く可能性がある。

---

## 2. 背景と研究ギャップ

### 工作機械の熱変位問題

工作機械の加工誤差のうち **40〜75% が熱変形に起因する**。

```
モータ・軸受・スピンドル発熱
周囲環境温度・冷却条件・熱伝達率
    ↓ (不確かさが多い)
熱流体解析 (OpenFOAM 等)
    ↓ 温度場
熱変位解析 (FEM)
    ↓ 変位分布
加工誤差の推定   ← ここに系統誤差が生じる
```

**不確かなパラメータ**: 初期温度・熱源発熱量・熱伝達率

### 既存研究の状況

| カテゴリ | アプローチ例 | 状況 |
|---|---|---|
| 実用補正 (JTEKT 等) | 温度センサ値 → FEM / 近似モデル → 熱変位推定 → CNC 補正 | 広く実用化 |
| 状態推定型 | KF + 低次元 FEM で温度場補正、その後に熱変位計算 (Lang et al. 2024) | 研究レベルで存在 |
| モデルパラメータ更新型 DA | 温度・変位データで解析条件そのものを更新 | **比較的少ない ← ここ** |

### JTEKT 等との差別化の整理

```
JTEKT などの実用補正:
    温度センサ → 熱変位推定モデル → CNC 補正
    (モデルは固定。センサ入力を直接変位に写像するだけ)

本研究:
    温度・変位センサ
       ↓
    熱流体・熱変位解析モデルの「条件 (Q, h, T_init)」を同化で更新
       ↓
    更新されたモデルで温度場・熱変位を再計算
       ↓
    予測精度の改善
```

> JTEKT の事例は厳密には「データ同化」ではなく「センサ値 → 変位の写像モデル」。  
> 本研究の立ち位置は「解析モデルそのものをデータで更新する」点で異なる。

---

## 3. 研究目的と新規性

### 研究目的

温度センサおよび変位センサの観測データを利用し、  
**熱流体解析・熱変位解析モデルの不確かな条件をデータ同化によって更新**する。

更新対象パラメータ: 初期温度・熱源発熱量 Q・熱伝達率 h

さらに、温度のみと温度＋変位の2ケースを比較し、  
**熱変位予測における変位観測の有効性を定量的に検証**する。

### 新規性の整理

| 観点 | 既存研究 | 本研究 |
|---|---|---|
| DA の対象 | 状態変数 (温度場) を補正 | **解析パラメータ (Q, h, T_init) を同定・更新** |
| 利用観測量 | 温度センサのみ | **温度 + 変位の複合観測** |
| 問いの立て方 | 温度場を精度よく推定する | **熱変位予測に有効な観測量は何か** |
| 最終目標 | 状態推定 | **サロゲートモデル化によるリアルタイム予測** |

> **差別化の軸は「OpenCAE を使った」ことではない。**  
> OSS ソルバーを使うことは OpenCAE 界隈での価値はあるが、研究の差別化としては弱い。  
> 差別化は「何を明らかにするか」に置く。

## 4. 比較ケースの設計

### ポイント: センサ構成で勝負する

| ケース | センサ構成 | 目的 |
|---|---|---|
| **Case 0** | センサなし (DA なし) | ベースライン |
| **Case 1** | 温度センサ 10 点 | 温度センサを多数使った場合の上限性能 |
| **Case 2** | 温度センサ 3 点 + 変位センサ 1 点 | 少数温度 + 変位で Case 1 を超えられるか |

**もし Case 2 が Case 1 を上回ったら**: 「温度センサを増やすより変位センサを 1 点入れる方が熱変位予測には効く」という、工作機械メーカーにとっても実用的なメッセージになる。

## 6. 研究アプローチ全体像

```
アルミ丸棒片持ちはり試験体
  温度センサ (複数点) + 先端変位センサ (1点)
            ↓  観測データ
    Ensemble Kalman Filter (EnKF)
    ─ 更新対象: Q (発熱量), h (熱伝達率), T_init (初期温度)
            ↓  更新された解析条件
  ┌─────────────────────────────────┐
  │  熱流体解析: OpenFOAM           │
  │   → 温度場 T(x, t)              │
  │                                  │
  │  熱変位解析: FrontISTR/CalculiX │
  │   → 熱変位 δ(t)                 │
  └─────────────────────────────────┘
            ↓  高精度教師データ (多条件シミュレーション)
    サロゲートモデル (NN / GP)
            ↓
    リアルタイム熱変位予測
    (センサ信号のみから即時推定 → 加工補正指令)
```

## 10. データ同化手法: EnKF

**OI (現状実装) から EnKF へ移行する理由**:

| 手法 | できること | 制限 |
|---|---|---|
| OI (002-1 で実装済み) | 状態変数 (温度場) の線形補正 | パラメータ推定不可 |
| **EnKF** | 状態 + パラメータの同時推定、非線形対応 | アンサンブル数の設定・計算コスト |

**拡張状態ベクトル**:
```
z = [T (温度場);  Q (発熱量);  h (熱伝達率);  δ (熱変位)]

アンサンブルメンバー z_i (i=1,...,N) を散布し、
OpenFOAM + FrontISTR で各メンバーを時間発展させ、
観測 y (温度・変位) との差で EnKF 更新。
Q と h が観測に合うよう自動調整される。
```

## 11. 予備検証 (002-1: OI による状態補正)

EnKF の前段として実装・確認済み。

| 項目 | 結果 |
|---|---|
| 手法 | Optimal Interpolation (OI)、固定 B |
| ソルバー | OpenFOAM (FVM 480 cells) + FrontISTR (FEM 697 nodes) |
| センサ | 同化用 2 点 + 検証用 2 点 |
| OpenFOAM RMSE 改善 | **+93.8%** |
| FrontISTR RMSE 改善 | **+94.0%** |

**現状の限界 → EnKF で解決したいこと**:
- モデルパラメータ (G_model) が固定 → 発熱量・熱伝達率を推定できていない
- 変位観測が未組み込み → 熱変位解析との連成が未実装

## 14. 想定質疑応答

**Q1. JTEKT 等の実用補正とどう違うのか?**  
JTEKT 等は「温度センサ → 変位推定モデル」であり、解析モデルのパラメータは固定または経験的に設定する。本研究は観測データで熱源量・熱伝達率を動的に同定・更新するため、未知の運転条件変化に対して適応できる。

**Q2. Case 2 (温度 3 点+変位 1 点) が Case 1 (温度 10 点) を上回る保証はあるか?**  
実験してみないとわからない。これが研究の問いそのものである。もし上回れば「温度センサを増やすより変位センサを 1 点入れる方が効く」という実用的に価値の高い結論になる。上回らなくても、「温度同化で熱変位まで改善できる条件・限界」が明らかになる。

**Q3. OI ではなく EnKF を使う必要性は?**  
OI は線形かつ状態変数の補正のみ。熱源量・熱伝達率のようなパラメータを推定するには、パラメータを拡張状態ベクトルに組み込める EnKF が必要。

**Q4. 流体解析 (OpenFOAM) と変位解析 (FEM) の連成はどう実装するか?**  
OpenFOAM で得た温度場を FEM の熱荷重として与えることで一方向連成を実現する。時刻ごとの温度場ファイルを FEM に渡すインターフェース (Python スクリプト) を実装する。

**Q5. アンサンブル数はどう決めるか?**  
状態次元 + パラメータ次元に応じて決める。今回の試験体は 1D 相当で次元が小さいため、50〜200 程度から試し、推定精度と計算コストのトレードオフを実験的に評価する。

**Q6. サロゲートモデルが実時間予測に使えるか?**  
DA で較正済みモデルによる多条件シミュレーション結果を教師データとして学習させれば、推論コストは無視できる。学習データの多様性 (温度・変位の条件範囲) が汎化性能の鍵になる。
