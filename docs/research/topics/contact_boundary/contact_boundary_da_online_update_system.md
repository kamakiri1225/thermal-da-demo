# 時間応答に基づく構造モデルの接触面境界条件の逐次推定・更新システム

## 1. この文書の位置づけ

この文書は、`contact_boundary_da_cutting_response.md` の研究テーマを、実装システムとして具体化したものである。

前者の主題は「切削中の時間応答から接触部境界条件を推定できるか」である。
本書の主題は「それを逐次的に回るシステムとしてどう作るか」である。

---

## 2. 目指すシステム

目指すのは、構造解析モデルを実機応答に合わせて逐次更新するシステムである。

```text
実機センサ
  加速度・変位・主軸電流・切削力推定値
        ↓
時間応答データ
        ↓
データ同化エンジン
        ↓
接触面境界条件の推定値
        ↓
更新された構造モデル
        ↓
FRF・動剛性・びびり安定限界の再計算
```

このシステムができると、構造モデルは一度作って終わりではなく、実機の応答を見ながら更新される。

---

## 3. なぜ「逐次更新」が必要か

接触面境界条件は固定値ではない。
工作機械の状態によって変化する。

例えば、

- ボルト締結部の接触状態
- リニアガイドの予圧状態
- 摺動面の油膜状態
- 温度上昇による熱膨張
- 工具位置・テーブル位置
- 切削負荷
- 経年変化や組付け個体差

これらにより、同じCAD形状でも実効的な剛性・減衰が変わる。

そのため、事前に1回だけモデルを合わせ込むだけでは不十分である。
時間応答を見ながら、接触面境界条件を更新し続ける仕組みが必要になる。

---

## 4. システム全体の構成

システムは、次の5つのブロックで構成する。

| ブロック | 役割 |
|---|---|
| 1. 計測ブロック | 加速度、変位、主軸電流、送り位置などを取得する |
| 2. 前処理ブロック | ノイズ除去、同期、周波数帯域の切り出しを行う |
| 3. 解析モデルブロック | 構造モデルを時間発展させ、応答を予測する |
| 4. 同化ブロック | 実測と予測の差から接触面パラメータを更新する |
| 5. 出力ブロック | FRF、動剛性、びびり安定限界、モデル健全性を出す |

---

## 5. 状態ベクトルの設計

逐次推定では、何を状態として持つかが重要である。

構造応答だけでなく、接触面境界条件も状態に含める。

```math
\mathbf{z}_k =
\begin{bmatrix}
\mathbf{u}_k \\
\dot{\mathbf{u}}_k \\
\boldsymbol{\theta}_k
\end{bmatrix}
```

ここで、

- `u_k`: 時刻 `k` の変位
- `dot(u)_k`: 時刻 `k` の速度
- `theta_k`: 接触面境界条件

接触面境界条件は、例えば次である。

```math
\boldsymbol{\theta}_k
=
\begin{bmatrix}
k_{n,1} & k_{t,1} & c_{n,1} & c_{t,1} &
k_{n,2} & k_{t,2} & c_{n,2} & c_{t,2}
\end{bmatrix}^{\mathsf{T}}
```

ただし、初期段階ではここまで多くしない。
最初は次で十分である。

```math
\boldsymbol{\theta}_k
=
\begin{bmatrix}
k_{contact} & c_{contact}
\end{bmatrix}^{\mathsf{T}}
```

## 6. システムモデル

構造モデルは、次の運動方程式で表す。

```math
\mathbf{M}\ddot{\mathbf{u}}_k
+ \mathbf{C}(\boldsymbol{\theta}_k)\dot{\mathbf{u}}_k
+ \mathbf{K}(\boldsymbol{\theta}_k)\mathbf{u}_k
= \mathbf{f}_k
```

時間離散化すると、次のように書ける。

```math
\mathbf{z}_{k+1}^{f}
=
\mathcal{M}
\left(
\mathbf{z}_k^{a},
\mathbf{f}_k
\right)
+ \mathbf{w}_k
```

ここで、

- `z_k^a`: 同化後の推定状態
- `z_{k+1}^f`: 次時刻の予測状態
- `M`: 構造解析モデルによる時間発展
- `f_k`: 切削力または加振力
- `w_k`: モデル誤差

接触面パラメータ `theta` は、急激には変わらないと仮定する。

```math
\boldsymbol{\theta}_{k+1}^{f}
=
\boldsymbol{\theta}_{k}^{a}
+ \boldsymbol{\eta}_k
```

これは、「接触条件は少しずつ変わる」という仮定である。

---

## 7. 観測モデル

観測値は、センサで測った応答である。

```math
\mathbf{y}_k
=
\mathcal{H}
\left(
\mathbf{z}_k
\right)
+ \mathbf{v}_k
```

例えば、加速度センサを使う場合は、

```math
\mathbf{y}_k
=
\mathbf{H}_a \ddot{\mathbf{u}}_k
+ \mathbf{v}_k
```

変位センサを使う場合は、

```math
\mathbf{y}_k
=
\mathbf{H}_u \mathbf{u}_k
+ \mathbf{v}_k
```

ここで、

- `H_a`: 加速度センサ位置を抜き出す行列
- `H_u`: 変位センサ位置を抜き出す行列
- `v_k`: 観測ノイズ

観測は一部の点だけでよい。
データ同化では、一部の観測点から、モデル全体と接触面パラメータを更新する。

---

## 8. データ同化アルゴリズム

最初の実装では Ensemble Kalman Filter を推奨する。

理由は次の通り。

- 構造応答と接触パラメータを同時に推定できる
- 非線形なモデルでも扱いやすい
- FEMモデルや縮約モデルをブラックボックスとして使える
- 共分散を解析的に作らなくても、アンサンブルから近似できる

EnKFの流れは次である。

```text
1. 接触剛性・減衰の候補を複数作る
2. 各候補で構造応答を予測する
3. 実測応答と予測応答のズレを計算する
4. ズレが小さくなる方向へ、候補群を更新する
5. 更新後の平均値を、現在の接触境界条件とみなす
```

式で書くと、更新は次の形になる。

```math
\mathbf{z}_{k}^{a}
=
\mathbf{z}_{k}^{f}
+
\mathbf{K}_k
\left(
\mathbf{y}_k
-
\mathcal{H}
\left(
\mathbf{z}_{k}^{f}
\right)
\right)
```

カルマンゲインは次である。

```math
\mathbf{K}_k
=
\mathbf{P}_{zy,k}^{f}
\left(
\mathbf{P}_{yy,k}^{f}
+ \mathbf{R}
\right)^{-1}
```

ここで、

- `P_zy`: 状態と観測予測の共分散
- `P_yy`: 観測予測同士の共分散
- `R`: 観測ノイズ共分散

この共分散により、「観測点の応答ズレを、どの接触パラメータへどれだけ配るか」が決まる。

## 10. 段階的な開発計画

### Phase 1: 低自由度モデル

2自由度または3自由度のばね・質量・ダンパ系を使う。
ここで、EnKFで `k_contact`, `c_contact` を推定できるか確認する。

合格条件:

- 応答RMSEが同化前より下がる
- 推定された `k_contact`, `c_contact` が正解値に近づく
- 推定値が発散しない

### Phase 2: モード縮約モデル

FEMモデルをそのまま毎時刻解くと重い。
そこで、モード縮約した構造モデルを使う。

合格条件:

- 主要モードの固有振動数が実機と合う
- FRFのピーク位置とピーク高さが改善する
- センサ点応答が同化前より改善する

### Phase 3: 加振実験データ

インパルスハンマや加振器で得た実測応答を使う。
この段階では切削力が既知または制御しやすいので、接触境界条件の推定に集中できる。

合格条件:

- 実測FRFと解析FRFの差が小さくなる
- 複数の加振条件で同じパラメータが使える
- センサ位置を変えても破綻しない

### Phase 4: 切削時応答

最後に切削中の応答を使う。
切削力が未知の場合、主軸電流や加工条件から切削力を推定するか、切削力も拡張状態に含める。

合格条件:

- 切削中の加速度・変位応答が改善する
- びびり発生に近い条件で、安定・不安定の予測が改善する
- 更新されたモデルが加工条件の選定に使える

## 11. リアルタイム化する場合の課題

リアルタイム更新を目指す場合、次の制約が出る。

| 課題 | 内容 | 対策 |
|---|---|---|
| 計算時間 | FEMをアンサンブル数だけ回すと重い | モード縮約、サロゲートモデル |
| センサ同期 | 加速度、変位、主軸信号の時刻ズレ | タイムスタンプ統一、再サンプリング |
| ノイズ | 切削中の信号はノイズが大きい | 周波数帯限定、外れ値除去 |
| 推定発散 | パラメータが非物理的な値へ飛ぶ | 上下限制約、対数変換、事前分布 |
| 可観測性 | センサ位置が悪いと接触条件が見えない | センサ配置設計、感度解析 |

---

## 12. 研究成果として何を示すべきか

このシステムを研究として成立させるには、単に推定が動くことだけでは足りない。
次を示す必要がある。

1. 接触面境界条件を更新すると、時間応答予測が改善する
2. 時間応答予測だけでなく、FRFや動剛性の予測も改善する
3. 更新されたモデルにより、びびり安定限界の予測が改善する
4. 少数センサでも、接触面パラメータを安定に推定できる
5. オフライン同定から逐次更新へ拡張できる

---

## 13. 最初に実装する最小構成

最小構成は次でよい。

| 項目 | 最小構成 |
|---|---|
| モデル | 2自由度ばね・質量・ダンパ |
| 推定対象 | `k_contact`, `c_contact` |
| 入力 | 疑似切削力または正弦加振 |
| 観測 | 1点の加速度 |
| 手法 | Ensemble Kalman Filter |
| 評価 | 応答RMSE、推定パラメータ誤差 |

この最小構成で成功した後に、FEM縮約モデル、実測加振データ、切削時応答へ進む。

## 15. このテーマの位置づけ

この研究は、熱変位デジタルツインとは別系統だが、考え方は同じである。

```text
熱変位テーマ:
  温度・変位観測
    ↓
  熱源・熱伝達率・温度場を更新
    ↓
  熱変位予測を改善

構造接触テーマ:
  振動・変位・加速度観測
    ↓
  接触部剛性・減衰を更新
    ↓
  動剛性・びびり予測を改善
```

共通しているのは、解析結果そのものを補正するのではなく、解析モデルの不確かな条件を実測で更新する点である。

これは、CAEを「再現する技術」から「実機に追従して設計判断を更新する技術」へ進めるテーマである。
